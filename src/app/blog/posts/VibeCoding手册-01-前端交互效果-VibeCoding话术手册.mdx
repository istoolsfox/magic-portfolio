# 前端交互效果 VibeCoding 话术手册（附 40+ 可玩示例）

> 你对 AI 说「让页面炫一点」，它就真敢给你炫出一页廉价动画。问题不在 AI，在你没说「行话」。这篇手册给你一套查词典式的沟通方法：说术语、给参数，AI 几乎一次写对。文中嵌了一整页 40+ 个可以上手玩的交互效果演示，每个都配可直接复制的话术。

## 一、先看一个翻车现场

你想给首页卡片加个入场效果，于是对 AI 说：「让卡片动起来，高级一点。」

AI 只能靠猜。它可能给你加旋转、加弹跳、加彩虹渐变，还顺便给每张卡片安排了不同的延迟——页面瞬间变成十年前的QQ空间。你来回改五轮，越改越烦。

换个说法试试：「鼠标悬停卡片时，卡片向上移动 4 像素、阴影加深放大，过渡 0.25 秒，先快后慢（ease-out），鼠标移开恢复原状。」

几乎一次到位。两句话的差距，就是「点菜」和「说菜名」的差距：前者厨师自由发挥，后者后厨照单执行。

## 二、结论先行：说术语 + 给参数

前端发展二十多年，几乎每种常见交互都有约定俗成的名字：淡入叫 Fade In，滚到顶部固定叫 Sticky，手风琴菜单叫 Accordion。AI 的训练数据里塞满了这些术语和对应代码——**你说出术语，等于直接命中它学过的标准答案**。

所以让 AI 写动效的公式只有一行：

> **说术语（它认识的标准答案）+ 给参数（你自己的约束）**

术语负责「对得上」，参数负责「合我意」。只给参数不给术语，AI 可能造轮子；只给术语不给参数，AI 给你默认值——能用，但不是你想要的。两个都给，才是完整交付。

## 三、五步描述公式

一个让 AI 无法误解的效果描述，包含五个要素。套公式即可：

| 要素 | 回答什么问题 | 常用写法 |
|---|---|---|
| 触发时机 | 什么时候开始 | 页面加载后 / 悬停时 / 点击后 / 滚动到可见位置时 |
| 作用对象 | 谁被动 | 卡片、按钮、导航栏、背景图 |
| 变化内容 | 怎么动 | 透明度、位移、缩放、旋转、颜色、阴影 |
| 时长与缓动 | 动多快、什么节奏 | 0.3 秒、先快后慢（ease-out） |
| 收尾状态 | 动完什么样 | 停在原位 / 恢复原状 / 自动消失 / 只播一次 |

把它当成「给实习生下工单」：时间、对象、动作、节奏、验收标准，一样都不能少。少一样，实习生就自由发挥一样。

## 五、高频术语速查表（按「我想要」组织）

不用背，按场景查。看到想要的行，把话术整句复制给 AI，再替换元素名和数字。

**想要「登场感」（入场与加载）**

| 我想要 | 术语 | 一句话话术 |
|---|---|---|
| 内容慢慢浮现 | Fade In | 页面加载后卡片从透明淡入，0.6 秒，先快后慢 |
| 更有仪式感地上场 | Fade Up | 从下方 30 像素上滑并淡入，0.5 秒 |
| 一排东西排队登场 | Stagger | 列表项依次入场，每项比前一项晚 0.08 秒 |
| 数据没回来时不空屏 | Skeleton | 先显示与真实布局一致的灰色骨架占位，带缓慢明暗呼吸，数据到达后替换 |
| 文字逐个蹦出来 | Typewriter | 主标题逐字出现，字间隔 80 毫秒，末尾光标闪烁 |
| 数字有冲击力 | Count Up | 数字从 0 滚到目标值，持续 2 秒，末尾减速，带千分位 |

**想要「纵深感与引导」（滚动触发）**

| 我想要 | 术语 | 一句话话术 |

## 六、八条踩坑（前七条血泪，第八条是多数教程漏的）

1. **一页别贪多**：每页保留一两个重点动效就够。全是动效的页面，像全程重金属的餐厅——没人记得菜是什么味。
2. **手机没有悬停**：所有 Hover 效果都要补一句「移动端改为点击触发或直接静态展示」，否则触屏用户直接丢失这部分体验。
3. **只动 transform 和 opacity**：直接把这句话复制给 AI——「动画只用位移、缩放、透明度（transform 和 opacity），不要改宽高和位置布局属性」。改布局属性会触发重排，动画必卡。
4. **滚动动画记得「只播一次」**：不加这句，用户上下滚动时内容反复闪烁，像接触不良的灯管。
5. **加载等待优先骨架屏**：骨架屏让用户感觉「已经在路上」，转圈只适合 1 秒内能完成的操作。
6. **颜色别用嘴形容**：「高级感蓝紫色」是玄学。直接给色值（如 #2E8B84）或说「用我页面的主题色」。
7. **改坏了就回滚**：大改动效前先让 AI 说明会改哪些文件；不满意就说「撤销刚才的改动，回到上一版」。
8. **给晕动症用户留个开关**：加一句「尊重系统减弱动态偏好（prefers-reduced-motion），开启时关闭所有非必要动画」。一行 CSS 的事，本文的演示页就带了。

## 七、万能模板与三个示例

手册里找不到完全匹配的词条？用这个模板自己组装，能写具体数字就写具体数字：

```
给【元素】加【效果术语】效果：当【触发时机】时，【元素】【做什么变化】，
时长【X 秒】，缓动【ease-out / 先快后慢】，【收尾状态或其他要求】。
```

三个完整示例，覆盖最常见的三种时机：

- **入场**：给首页的四个功能卡片加逐条入场（Stagger）：页面加载后，卡片依次从下方 30 像素处淡入上浮，每张比上一张晚 0.1 秒，单张 0.5 秒，先快后慢。
- **悬停**：给导航栏菜单链接加下划线生长：悬停时文字下方出现 2 像素高主题色下划线，从左向右展开 0.2 秒，移开向左收回。
- **滚动**：给长页面加滚动显现（Scroll Reveal）：每个版块滚入视口 80% 位置时淡入上浮 20 像素，0.6 秒，只播一次。

还有一个作弊技巧：在别的网站见到想要的效果，直接截图发给 AI——「参考这张图的效果，做到我的页面上」，再配合术语，成功率最高。

## 八、总结与行动清单

| 一句话记忆 | 内容 |
|---|---|
| 公式 | 说术语 + 给参数 = AI 一次写对 |
| 五要素 | 触发时机 / 作用对象 / 变化内容 / 时长与缓动 / 收尾状态 |
| 参数默认值 | 入场 0.4–0.8 秒、交互 0.2–0.3 秒；缓动首选 ease-out；循环动画务必「缓慢」 |
| 克制纪律 | 一页一两个重点动效；动效为信息服务，不为炫技服务 |

行动清单（下次开新页面照做）：

1. 打开上面的演示展厅，把想要的效果卡片话术直接复制走。
2. 替换话术里的元素名和数字，一次只描述一个效果。
3. 补两句标配：移动端替代方案 + prefers-reduced-motion。
4. 大改之前让 AI 先报文件清单，留好回滚退路。

> 金句：**AI 不缺手艺，缺的是你说清楚的那五要素。说行话，一次做对。**
