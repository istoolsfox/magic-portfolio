## 背景

跨境电商的日常：订单来了要在 ERP 里核对、物流状态要逐单查询、广告和财务数据要定期汇总。
每一项单独看都不难，合在一起就是持续消耗人力的黑洞——而且人工操作必然出错。

## 方案

用 n8n 作为业务流程的中枢，把各个系统的 API 串成自动化流水线：

```text
订单产生 → ERP 自动抓取 → 状态同步 → 物流轮询 → 客户通知 → 数据统计
```

关键设计决策：

- **中间数据层**：PostgreSQL 存储订单与物流的中间状态，避免对 ERP 的高频轮询
- **幂等设计**：每个节点可安全重跑，网络抖动不会产生重复通知
- **异常出口**：无法自动处理的单据自动进入人工队列，而不是静默失败

## 踩过的坑

- ERP API 的限流没有文档说明，靠试错摸出安全频率，最终用队列削峰
- 物流商 API 返回格式不统一，中间层做了统一 schema 转换
- n8n 长流程调试困难，拆成多个小 workflow 用 webhook 串联，单元可测

## 结果

- 重复性人工操作大幅减少，运营只处理异常件
- 订单状态同步从批量人工核对变为分钟级自动更新
- 数据报表从月底突击变成每日自动产出
