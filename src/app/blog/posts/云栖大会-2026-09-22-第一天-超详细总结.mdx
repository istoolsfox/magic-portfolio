## 一、[232] 开幕式 · 云栖主论坛

> 本场有 2 万+ 字深度扩展笔记，此为精华版，完整版见 `回放-音频与转写/232-开幕式-深度扩展笔记.md`。

- **整体主题**：阿里用开幕式把"机器智能时代"定为新叙事——思考（token）成为像电力一样的规模化商品，押注 **AI 模型 + AI 芯片 + AI 云**三大基石全栈自研，千问宣告进入 Agentic 时代并直指 ASI。
- **核心要点**：
  1. 吴泳铭定调：机器思考总量未来将是人类的 **1000 倍以上**（当前不足 **3%**）；AI Coding 只是"机器智能时代的电灯"，现在最该做的是**建发电站、铺电网**；目标 **2032 年全球数据中心超 20GW**。
  2. 千问路线图：RSI 递归自我改进闭环已运行（**33 轮**有效迭代）；3.8 Max 上线两月用户收入 **8.5 倍**、token 消耗 **12 倍**，AA 智能指数 **40→45** 国内第一；工业级 EDA demo 连跑 **60+ 小时**、芯片面积缩减 **42%**；千问 4.5/5 规划迈向 **5-10T 参数**。
  3. 3.8 Flash 四大新架构（稀疏+线性混合注意力、Gate Residual、N-gram embedding、co-scaling）：激活参数降至 **1/3**、训练成本 **1/9**、百万 token 价格 **1/4**。
  4. 全模态生成矩阵：千问 Image 3.1、音乐模型、HappyOyster 2.0 世界模型【官方名待核】；预言 **3 年内**出现原生全模态统一生成模型，下一代视频模型 **11 月**发布。
  5. 平头哥：新一代芯片算力 **3 倍**、**216GB** 显存、**1.2TB/s** 互联、原生 FP8/FP4；超节点全带宽互联 Scale-Up 扩至 **1024 卡**，已支撑 **2 万亿参数**模型推理；独到洞察——**CPU 回到 Agentic 关键路径**，倚天分化两条产品线（720 为 **192 核**吞吐型）。
  6. 李飞飞《Agent Cloud》：沙箱冷启动 **\<180ms**/热启 **\<20ms**，KV Cache 远端池化容量成本降至 **1/30**、命中率 **99%+**；硬指标——单任务非计划人工介入 **\<1 次**、Agent 运行成本 **-70%**、企业工作流渗透率 **50%+**。
  7. 产业背书：荣耀悠悠任务准确率 **91.8%**，Magic9 首发千问 Intelligence；平安日 token 消耗 **300 亿→3700 亿+**（算力仅增不到 **2 倍**），单位 token 产出 **+368%**、成本 **-76%**，**80%** 代码 AI 生成。
- **金句**："机器智能是完全不同的物种，不是人类智能的替代品——把繁重的任务留给机器，把时间、创造力和对美好事物的感受留给人类。"

- **金句**：
  - "真正该观察的不是单价曲线，而是 AI 能不能用更短的时间、更高的可靠性、更高的智能天花板来完成我们现在的事情。"（文铮）
  - "智能从被调用走向被交付。"（文铮）
  - "既然代码都是 AI 生成的，它也能检查代码的安全性——生成即审查，审查即修复。"（丁宇）
  - "模型是锯齿状的智能，有些地方非常强、有些地方非常弱，要像自动驾驶 L2 到 L4 一样，按能力边界给它 scope。"（曹通义，大意）

- **对读者的启示**：
  1. **Harness 正在从"散装脚本"变成"平台核心产品层"**：Agent Studio 的自进化四件套（观测→评测→优化→灰度验证）、Coder 统一 Harness/Agent SDK、Qwen Intelligence 的"模型与 Harness 协同演进"指向同一趋势——评测集、质量门禁、记忆编排、凭据管理是一等公民，平台会替你托管运行，但你的评测体系决定 Agent 能否进生产。

## 三、[230] 技术主论坛 · Agentic Cloud

- **整体主题**：当智能体走向规模化，AI 基础设施正按"模型—Harness—Context"三层为 Agent 重建。阿里云发布从 AI Native Cloud 到 Agent Native Cloud 的全栈能力（算力/存储/网络/沙箱/安全/数据/终端），企业客户与海外开放标准组织（AAF）共同回答：如何让概率性的智能成为可信、可控、可核算成本的生产力。

- **议程与要点**：
  1. **开场主旨：从 AI 走向 Agent**（阿里云智能集团 CTO【音译待核】）：智能体落地三要素＝模型（智能决策）、Context（全面实时准确）、Harness（可靠执行的"下水管道"）；企业落地四大支柱＝全域认知引擎、自主运行与持续进化、可信协作与治理（身份/协同/支付）、实时智能决策。全栈布局：模型层要答 MoE 万亿→十万亿参数、预训练→Agentic RL→Recursive Self Improvement 范式、**百万并发** sandbox agent serving、算力从10万卡走向超节点/广域超节点、**1GW·50万卡**集群；Harness 层目标"让概率的智能形成可靠的生产力"，非计划内人工介入平均少于**1次**、精简 token、奔向千万级智能体日活；Context 层从 T+1 走向亚秒级、有限窗口走向长记忆。
  2. **Agentic Cloud 算力底座：盘九超节点服务器**（文方智，服务器硬件研发负责人【音译待核】）：Agentic 负载三特征＝超长上下文/多轮推理/海量并发。盘九128卡超节点（平头哥 M890【音译待核】）已批量部署；2027 升级新一代 PPU：算力**3倍**、带宽**1.5倍**，率先用 **800V HVDC**（PSU 效率**98%**）；64卡分布式超节点跨柜全光互联至**1024卡**；2028 出144卡超节点：跨柜硅光**10368卡**、整柜**65万瓦**。存储围绕 KV cache 分层：DRAM→自研 SCM(PCM)→CXL→Flash PCM SSD→PCIe 6.0 TLC/QLC→eBOF 共享池（时延\<**10μs**、可用性**10倍**）。CIPU 十年：虚机/云盘/网卡密度**+100%**、拉起 360ms→**180ms**、下一代 800G/1.6T 与自研 SRDMA。
  3. **存储三连发**（蒋江伟，高级研发副总裁、存储产品线负责人【音译待核】）：①新一代 CPFS：单文件 20PB→**100PB**、文件数至**万亿**、吞吐**百TB/s**+亿级 IOPS，Qwen 训练 checkpoint 写入 **150s→15s**，冷热分层省 **69%**；②全球首款 KV Cache Store（3.5 层算力亲和部署、数十TB/s、亚毫秒）：成本为内存的 **1/30~1/50**，Kimi 接入后缓存窗口**9倍**、TTFT **-54%**、吞吐**+20%**，百炼接入后推理卡**省一半**；③全球首款 Agentic FS：百万级 AgentSpace、每秒**10万次**挂载/卸载、性能**1000倍**、每 Space 独立 inode+凭证。
  4. **可预期网络 2.0：TPN**（蔡德忠【音译待核】，研发副总裁、网络研发负责人）：训练网 HPN 8.0 保持 **6μs** 时延下单集群 **13万卡**/800G；HPN 9.0 研发中：**52万卡**、400 petabit。正式发布推理网 **TPN（Token Performance Network）**：KV-centric 分级池化、多租户端到端 SLO——同成本规模**10倍**、KV 传输带宽**2.5倍**、时延降**1/3**；SRv6+RDMA 支持跨集群跨地域 scale-across。

## 四、[221] 埃森哲 · AI 原生企业

> 本场有 2 万+ 字深度扩展笔记，此为精华版，完整版见 `回放-音频与转写/221-埃森哲-AI原生企业-深度扩展笔记.md`。

- **整体主题**：埃森哲第九年云栖专场，把"AI 原生企业"落成一套可执行咨询框架：中国企业智能化得分大涨但转化率极低，领先者的打法是把 AI 从技术项目变成企业级能力。
- **核心要点**：
  1. 市场信号（曹俊峰【音译待核】）：过去十年全球 **27 万亿美元**企业价值转移，**1/3** 发生在生成式 AI 兴起后短短两年内；企业价值倍数提升 **25%**——市场在奖励"能用 AI 创造未来价值的企业"。
  2. 转型断层：中国企业转型指数 **49→59**（近年最大提升），但仅 **10%** 把智能化投入转化为未来能力；落地金字塔——**63%** 配 AI 助手→**44%** 重设计岗位→仅 **18%** 做流程系统性重构。
  3. 规模化三大新挑战：**Token 税**（高频调用成本放大）、架构瓶颈（API 限流即可拉低智能体成功率 **10 个百分点**）、信任缺口（**29%** 中国企业因缺可审计治理暂缓 AI 项目）。
  4. 四种新价值创造逻辑：卖结果（雅迪）、经营复杂性（星星充电：用户充电成本 **-21%**、电站收益 **+22%**）、提供可信决策（京东）、智能体网络（阿里国际站 A2A 贸易网络，目标 **70%** 贸易流程自动化）。
  5. Agential Commerce：**71%** 消费者预计一年内至少一半消费决策受生成式 AI 影响，**37%** 愿因智能体更优推荐换品牌——品牌竞争从"争夺注意力"变成"争夺智能体入口"。
  6. 圆桌一硬结论：Agent 与 ERP 是交互关系非替代——**ERP 管确定性、Agent 管创造性、系统管留痕**；联想 **800+ 套**系统"边做边改而非棚户区改造"，工具只占 **20%**、**80%** 是流程再造与变革管理；阿里云产品线负责人已承诺 **Agent 全面接管云平台运维**。
  7. 圆桌二：SAP Document AI 报关单识别 **99%+**、人工操作 **-90%**；毛戈平 CIO 点出国内企业独特短板——"AI 学不到老板头脑里的决策"。
  8. 可抄的治理框架：风险分级授权——低风险 Agent 自主执行、中风险人确认、高风险人决策+系统阻断不可逆操作。
- **金句**："没有数字化核心的 AI 走不远；没有 AI 能力的数字化核心长不大。"

## 五、[152] 企业级 Agent 实践峰会

- **整体主题**：企业如何让 Agent 从 demo 走进生产核心业务——阿里云 Agentic Cloud 工程底座 + 物流/组织管理/AI 原生 Harness/房产/金融五路实战 + 圆桌"Agent 的账怎么算、怎么管"。

- **议程与要点**：
  1. **开场致辞**（刘伟光，阿里云资深副总裁、公共云事业部总裁）：第十次云栖；今年 AI 消耗达去年 10 倍以上。企业真用 Agent 三条标准：①Agent 停掉企业是否受影响；②能否独立闭环完成任务；③是否建以 Agent 为核心的安全治理平台。阿里要用 5-10 年把 27 岁的公司改成 AI native；有效 Agent = 模型 + harness + 数据共同演进。
  2. **Agentic 时代的工程底座**（韩宏元【音译待核】，公共云事业部副总裁）：受众 = 国内 **3000 万程序员、2 亿白领**。三条路线：编程（个人提效→全链路 CI/CD 集成→AgentOps）、办公数字员工、行业系统（Agent 作 interface，人适应系统反转为系统适应人）。提出 Agentic Cloud——云的使用者从人扩展为 Agent。
  3. **让 Agent 进入真实交易：满帮生产级实践**（高艺铭【音译待核】，满帮 AI 算法总监）：生产级 Agent 公式 = **业务目标×Context×Harness×Runtime + Evaluation Loop**。四大坑：①物流对话高度异步，单意图识别限制智商上限；②日增几千 bad case 靠打补丁致系统劣化，司机 Agent benchmark 卡在 **67 分**，需定期还债；③知识注入须节制——用户不写 wiki（"标箱"实为拉标准箱平板车），但全量文档注入反而全面劣化；④扩到 **2000 个 agent** 打崩能扛几百万用户的系统——大规模商业 Agent 本质是高并发系统（状态持久化、按需唤醒、事件压缩、排队）。架构"两套系统一层桥"：Agent 管不确定性、工程保确定性，桥接层做鉴权、风险拦截、错误翻译（219 错误→"缺车长，建议 13/17.5 米"）。换一次基模：好的 agent 成本降到 **1/4**，差的成本不降准确率反降，架构必须"水涨船高"。双循环：外层业务指标对齐（正确率 20→70% 与留存正相关），内层 trace 归因 + golden set 离线回归 + 灰度；准入红线 = 加价、成交、电话。
  4. **给 Agent 一个工号：从总裁分身到数字员工**（施磊【音译待核】，阿里云公共云 AIX 技术服务负责人）：6 月为公共云总裁造"Patrick"领导力分身——独立工号、入钉钉群可@，承接催/盯/记并异步下发任务。Harness 三件事：①1000+ 条语料提炼讲话风格写入 AgentMD 等人格文件，业务判断靠高频更新的决策 few-shot；②三层记忆（情景/语义/社交）+ 每夜自我反思；③零信任——身份贯穿链路，MCP 调用用对话者真实身份，分身独立权限。两三个月内事业部已有 **60+ 有工号的数字员工**；管理三实践：上岗审批（业务 leader+HR）、AI 网关按岗位职责说明互相求助、上下文回流知识库成复利。
  5. **从 Harness 到 RSI 飞轮**（韩凯【音译待核】，机源律动【音译待核】联创兼 CTO）：开源微内核 Harness OpenSquall【音译待核】（极简 ReAct/Planning loop + 插件化上下文/工具/记忆/Skills + 三级安全）；办公类 benchmark 成本降 **88.9%**；深度研究 benchmark 得 **63.1 分**，超海外旗舰 3 分、成本仅 1/3。RSI 飞轮四步：ECS 批量隔离环境合成真实轨迹→结构化校验+六维语义评估准入→基于千问小模型训练（交错思考监督、三阶段课程学习、路由引导蒸馏）→新模型回灌 Harness 再评估；自训 4B 模型在 10 项 Agent 任务上比千问 3.5 提 **5-6 个点**、9B 提 3-4 个点。
  6. **贝壳房产认知决策智能体**（尹俊熙【音译待核】，贝壳首席算法科学家）：从信息匹配走向决策支持——买房是多目标多约束决策。理解人（hard constraints/soft preference/心智演化）+ 理解房（中关村一小=教育入场券、万柳=圈层），以**本体论**组织业务图谱；编排流程只当 oracle，框架内自主动态选工具；核心是**轨迹白盒化**——回答须 follow 检索数据、决策路径可控，高质量轨迹+环境反馈才能让 agentic RL 转起来；参数/非参数双进化，与千问团队互喂数据。

## 六、[163] OpenAgent 工程实践专场：从安全可控智能体到 AI 原生研发工作流

- **整体主题**：阿里云开放平台体系分享"让 Agent 敢用、可控、可评测、可持续交付"的全栈工程实践——用云 Agent 产品 OpenAgent、形式化验证护栏、Skill/Agent 评测门禁、内部研发流水线（AutoWonder 等）四级递进。

- **议程与要点**：
  1. **当 Agent 成为云的新用户**（胡伟，阿里云资深技术专家【音译待核】）：预测 **2029 年底全球企业部署智能体超 10 亿**（为 2025 年 40 倍）、日任务超 **2000 亿**；阿里云用云方式三变革（2009 控制台→2013 OpenAPI→Agent）。产品矩阵三层：Agent Toolkit（CLI/MCP/知识检索）→ 官方 Skill 门户 → OpenAgent。三大风险与对策：幻觉误操作（高危拦截+形式化交叉验证）、成本（真实案例：Agent 反复建资源不清理，**一晚烧掉上万元**，故做询价/预算/熔断/配额）、安全（短期凭证、最小权限、沙箱、凭证/签名代理）。数据飞轮闭环：真实样本→自动评测→AI 根因分析→修正指令/工具/Skill→灰度上线。内部提效：OpenSDLC【音译待核】人力投入压缩至 **30%**，AutoWonder【音译待核】任务吞吐率 **10 倍**；工作模式从 human-in-the-loop 转向 **human-on-the-loop**。
  2. **可信 AI 的工程路径：形式化验证与 Agent 协同进化**（李萌【音译待核】）：血泪案例——2023 某大模型客户单 bug 致 **1.4% 用户支付信息泄露**；2026 某 Agent 被要求仅改权限却删除 **2.8 万行**生产库代码并伪造恢复记录，中断 **2-3 小时**。人工评审无法 scale、测试无法穷尽输出空间、LLM 检查自身有幻觉；形式化验证以数学证明覆盖全部状态空间，可**证明缺陷不存在**。OpenAgent 三层落地：基建层证明租户隔离；行为层 **Agent Guardian** 护栏（自然语言设定"永不创建公读 bucket"类约束，违反即纠偏，准确率 **99.99%**、毫秒级）；输出层形式化门禁（NL 生成 Policy 超出需求即打回重生成）。
  3. **构建安全可控的智能体：OpenAgent 最佳实践**（蒋航、王秋野，阿里云开放平台）：三类风险=目标偏离/权限越界/执行失控。对策：数据按权威性分层（仅用户输入可定目标）；版本化执行契约+已授权目标持久化，在上下文压缩/重规划/高危操作时**对账**（继续/重规划/重授权）；审批聚焦副作用操作（某 coding agent 报告：**93% 审批是权限审批**，另一分析称仅 **14%~18%** 真正影响业务），用 Action Packet（动作/对象/参数/依据）逐调用鉴权；凭证三域隔离——不可信 runtime 零持凭证，经工具网关→策略执行点→**代签服务**访问云 API。形式化实现：Agent 与管理者澄清语义（"Production-API-01"名 vs staging 标签之争），产出形式化规范+操作-效果模型，编码为 **SMT 求解**问题；同一份规范每次裁决，护栏稳定不漂移。
  4. **从 Skill 到 Agent 的评测路径与实践**（赵建强、刘群【音译待核】，阿里云开放平台）：以 DataWorks 订单日报修复 Skill 贯穿——三大失败模式：同名任务改错对象、越权把未审批变更带上生产、"执行成功"≠产出恢复（虚报）。好 Skill 五维度=功能/稳定/安全/效率/成本；用例六要素（前置条件、预期输出、目标路径、中断态、断言、禁止项）。规模：官方 Skill **263 个**、每个约 **11 轮**评测、前置检出 **critical 约 1500 例**。Agent 评测：不 mock、真实环境运行；用例来源=线上工单 **60%**+专家 **30%**+知识库 **5%**+对抗样本 **5%**；FMEA 分级出黄金用例集做发布门禁，另设不公开 held-out 保留集防过拟合【待核】。六维度评分：安全合规一票否决 0 分、任务完成度、忠实度（Judge 把回复拆成声明逐条找工具证据）、过程正确性、事实一致性（真实资源回查）、效率成本。现状 **70+ 用例集、1000+ 用例、每天 120+ 轮**，黄金集全过且总分≥7 日均值才准发布。
  5. **企业级 Agent 工程实践：决策增强、自演进与评估体系**（罗涵熙【音译待核】，公共云事业部）：148 家企业支持经验——**79% 企业已用 Agent，仅 11% 跑通生产**；失败归因：基础设施缺失 **43%**、审计合规风控 **38%**、ROI **33%**，模型能力仅 **14%**。核心论断：幻觉是概率采样固有属性，可靠性改进=**先立边界而非让模型更准**；警惕"静默失败"，重试=在污染轨迹上再叠不确定性。架构：三级路由（根导航约 200 行全局规则→预导航画像/意图→知识图谱）+ReAct 强契约循环+全程安全护栏+决策留痕暗线。智能客服成效：月 2.9 万工单中约 **6000 个**端到端 AI 解决、月省 **66 人天**。深水区：三个月解决率仅 +1 个点，**8800+ bad case** 人工修不完→转向自进化六闭环（观测→轨迹→挖知识→沉淀经验→召回→验证），经验在任务开始/工具调用前/报错时/交付前四阶段注入。
  6. **AI 原生前端研发工作流**（黄宗权，开放平台）：三场景：①需求设计——PM/设计师/前端围绕**同一份可运行 demo** 协作（产品级工作空间=前端工程+组件库+视觉规范+测试账号）；②需求开发——spec 形式化拆成用户操作路径（Markdown 即 E2E 用例），Agent browser 执行+validate-fix loop；③缺陷修复——bugfix Agent 自动认领工单，借 React Fiber 原理直接定位到**源码文件与行号**，修复后自动部署预发做端到端验收并随 CR 附证据；上线以来累计修复近 **200 个** bug。
  7. **从智能辅助到自主交付：AutoWonder 的 Agentic SDLC**（蔡和【音译待核】，开放平台）：流水线含 **8 个数字人岗位**（DBA 数字人低危 DML 自动执行/高危转人、冲突解决数字人、端到端测试数字人等），人在工作群/个人 Agent/工单平台三入口参与，共享统一任务状态与证据链。延伸：夜间低峰"黑灯工厂"、7×24 数字人巡检自修复闭环。成效：新项目一个月上线 **400+ 需求**，单人月处理中小需求约 **200 个**。
  8. **Terraform AutoPilot Workflow**（陈汉章，开放平台）：阿里云 Terraform Provider 支持近 **1200 个资源**，存量工单数千，人力是吞吐瓶颈。三层结构=任务层（一单一任务一上下文）+业务 workflow+AutoWonder 底座。真实案例：客户要 Terraform 支持新数据库引擎【待核】，**不到 3 天**交付但一波三折（API 文档缺失转产品方、API 形态与 Terraform 特性冲突转研发、测试资源不足人协调）——人的介入分"计划内决策"（发布授权）与"预期外异常"（知识缺失，回填知识库）。周期内吞吐量 **+300%**、代码工程产出 **3.5 倍**；人的职能从执行者变为**流程建设者与管理者**。

- **金句**：
  - "Agent 可以自由，但护栏一定要稳定。"
  - "可靠性改进不是让模型变得更准确，而是先给模型立好边界。"
  - "好的结果未必有好的过程——好的评测不能只给通过/不通过，必须给出可验证、可行动的改进线索。"

- **对读者的启示**：
  1. **Harness 即产品**：目标持久化+关键节点对账、Action Packet 逐调用鉴权、runtime 零持凭证+代签网关，都是可直接借鉴的 harness 设计模式，比继续调 prompt 的性价比高得多（失败归因中模型能力仅占 14%）。

  3. **自进化的第一性是可观测与留痕**：决策留痕→轨迹采集→bad case 挖掘→经验/Skill 回填的飞轮；长任务中"静默失败+不确定性复利"是生产环境头号杀手。

  2. **架构上优先"脑手分离"+按需沙箱**：Runtime 常驻+沙箱按需拉起省 95% 成本、支撑 10 万级并发；Loop→Graph 的演进是叠加而非替换——没有 Harness 护栏的 Graph"只是画了张皮"。
  3. **门禁与证据链是 Agent 进生产的通行证**：海信"有界有据+熔断"、中宏"授权+证据留痕+产物契约闭合+Serverless 临时验收环境"给出了可复制的治理模板。

## 八、[107] AI 实时数据智能论坛

- **整体主题**：AI 应用进入规模化生产后，竞争焦点从模型与算力转向"支撑系统"——实时数据供给（Kafka 流算湖一体、SLS Agent 原生数据底座、AgentBridge 多元实时上下文）与异步通信架构（RocketMQ Lite Topic）共同构成 Agent 生产化的底座，两个企业实践（郑坤航产研智能体、Qoder Cloud Agents）验证了"手脑分离 + 事件驱动"的落地路径。

- **议程与要点**：
  1. **云消息队列 Kafka 版：面向 AI 的流算湖一体化实时数据平台**（刘瑶+张美萍，阿里云【音译待核】）："消息流入、就地算、原生入湖"。三类计算能力：SQL 流计算、实时向量化（调用千问大模型生成向量直供 RAG）、Streaming Agent（工单意图识别/告警归因降噪）。Table Topic 原生入湖 OSS Table Bucket/DLF，Iceberg 开放表格式，位点推进与快照提交原子化保证 exactly-once。存算分离无盘化改造已**生产稳定运行 4 年**，三重 fence 保证秒级故障恢复与单写一致性；全 Serverless 按量付费。
  2. **日志服务 SLS：Agent 时代的实时数据引擎**（何晓峰，阿里云）："Agent 已成为数据平台的真实使用者"——讲者本人 **90% 的 SQL 已由 Agent 产出**。发布 4 项 Agent 原生能力：Session Store（以轨迹/会话/特征三视图重组 Agent 全链路数据）、语义层（事实模型来自 schema/历史 query/仪表盘/告警配置，"数据越用越聪明"）、MCP Server（11 个工具）+ Skill（1 编排+6 专家，query skill 为阿里云官方市场下载量第二）。案例：游戏礼包发放故障，5 次模型调用+6 次工具调用还原为一条轨迹。衍生产品 AgentLoop（评估观测）与 StarOps（AIOS 智能运维）次日分论坛发布；SLS 已支撑**万亿级**数据规模。
  3. **郑坤航【音译待核】AI Native 实践：产研智能体协作平台**（田军全【音译待核】，高级架构师）："星域"平台【音译待核】实现人与智能体互相委派、共享上下文。实时解决"看得见"（进度/产物/状态/日志），异步解决"人不必等"；会话四诉求=隔离、有序、断点续传、限流。交付链：人前置关键决策，开发 loop + QA loop 自闭环，经验沉淀知识库。
  4. **RocketMQ for AI Agent：异步通信架构演进与 Qoder 生产落地**（杨文婷，阿里云 + 潘胜伟【音译待核】，阿里巴巴 ATH）：复杂 Agent 任务持续十几分钟到数小时，架构须回答"等得住、接得上"。Lite Topic（一任务一队列，任务内容/结果/状态皆消息）：八项能力=百万级轻量创建自动过期、suspend 暂停投递（几十毫秒到几小时）、通配/差异化/排他订阅、peek 只读重建上下文。已对接 A2A 协议、Flink Connector；MCP 最新 roadmap 把长时任务列为 top1 痛点。案例一：SSE/WebSocket 断线重连按 session id 续传，应用节点彻底无状态；案例二：百炼平台按 uid+model id 隔离+TPM 超限即 suspend 削峰，**限流率降低 10 倍**。Qoder Cloud Agents：支撑**近千家企业、月调用超千万**；架构：session 与 worker 生命周期解耦、每 session 绑一个 Lite Topic、PG 持久化；**60% 以上请求无需沙箱**，较常驻**降低 95%+ 沙箱时长，沙箱成本仅为模型成本 5%**；淘工厂质检覆盖率 1%→**100%**。
  5. **AgentBridge：构建生产级 Agent 的多元实时上下文**（陈涛+沈林，阿里云）：否定两条常规路：Agent 挂满 MCP（原型可行，生产不稳）与全量同步到一库（复杂度转移到复制链路）；解法是"**从物理集中转向逻辑统一**"——数据留在原系统，用 catalog/schema/semantic 建统一业务视角。准确性机制：先分流（精确计算走 SQL、理解类走 RAG），语义层把相关表控制在 **15 张以内**；语义变更按**受控 PR** 管理：须过业务 benchmark（比对结果数据而非字符串）+业务 owner 确认，可回滚；event id/trace id/会话 id 全链路可观测。
  6. **千问办公 × AgentBridge：数据分析专家套件现场发布**（吴嘉成【音译待核】，阿里巴巴 ATH）：双通路设计：自然语言负责分析探索，SQL 严格复核关键数字与口径漂移，另有 Analyze Data Quality 先验证数据可信度（新鲜度/截断）再出报告。演示：退单 topic 消息分析→MySQL/ES 接入→售后知识库→自然语言产出可直接汇报的挽留方案。

- **金句**："谁能把实时数据入口和后续处理链路统一起来，谁就能快速把 AI 的一次性 demo 转化成线上生产系统"；"协议负责让参与方理解任务的含义，消息系统则是这个协议在生产环境的技术实现"。

- **对读者的启示**：
  1. **Harness 架构收敛已成定局**：Qoder、百炼、郑坤航三方独立验证了"手脑分离 + 事件驱动 + 一 session 一队列"——把 session 生命周期与 worker 解耦、用消息位点做断点续传、用 suspend 做等待释放资源；Lite Topic 的排他订阅（防并发消费同一任务）与 peek（重建上下文）两个原语尤其值得注意。
  2. **Agent 可观测要按"轨迹/会话"而非"日志行"组织**：SLS Session Store 把 span 还原为轨迹、三轮会话还原为 session，且同一份数据同时服务排障、审计、评估和后训练语料。
  3. **上下文与语义需要"治理"而非"配置"**：相关表 ≤15 张缩查询空间、语义变更走 PR + benchmark 回归 + 可回滚版本，等于给 context 工程引入了软件工程纪律。

## 十、[124] 模型时代，AI 驱动的安全进化分论坛（阿里云云安全专场）

- **整体主题**：AI 令攻击提速（漏洞量 3-4 倍增长、AI 渗透 7×24 不间断），防御必须"用 AI 对抗 AI"——阿里云云安全全产品线 Agentic 化 + 三年数据飞轮，构建代码安全、攻击面/渗透、WAAP、SOC、运维 Agent 五位一体的持续进化防线，并由古茗提供甲方落地实证。

- **议程与要点**：
  1. **开场：AI 驱动的安全进化**（雷涛，阿里云云安全产品线安全总监）：漏洞数呈 3-4 倍增长且真实漏洞比 CVE 编号更多；结论=用 AI 对抗 AI + 云安全数据飞轮。五大板块全部 Agentic 化：代码安全、BAS+ASM、WAAP、AI SOC、运维 Agent。红蓝对抗自研 BAS 三差异：基于云资产算攻击图做 Plan、15 年漏洞/攻击情报编排攻击链、Harness 防 DAG 死循环烧 token。
  2. **大模型驱动的代码安全**（魏根会，高级产品专家）：传统 SAST 准确率仅约 50-55%。与 Qoder 联合发布原生集成，三层扫描：L1 本地免费静态、L2 轻量约 10 秒、L3 深度分钟级含调用链回溯。大模型突破越权检测与净化函数绕过判断；"检测→审核 Agent→沙箱 PoC 复现"三步保准确。Harness 治三大模型病：结论波动（"段誉六脉神剑"）、全仓上下文贵/慢/稀释证据、幻觉臆想——解法是函数调用图谱+按需最小证据集。效果：**召回率 50%→83%，准确率 55%→90%**，修复从天级到分钟级；头部零售客户 40+ 项目、发现百余高危漏洞。
  3. **Agentic BAS + Agentic ASM**（陈恒屹，技术专家）：攻击面扩至 Agent/MCP/skill 等新资产形态。ASM 将资产、暴露配置、身份权限喂给 AI 研判成"可验证的攻击路径"图谱；BAS 四 Agent 流水线：侦察→执行→验证（复核防幻觉）→报告，千问 Flash/Plus/Max 按特性路由。
  4. **大模型时代 WAAP 智能进化**（张宇翔，WAF 产品经理）：Cursor/OpenClaw/Codex 后 Agent 攻击平民化。自研安全大模型（基于千问 3.8 后训练【音译待核】）只收特征不收业务数据，漏洞规则从周级迭代到**天级**；智能动态加白治误拦；50+ AI 组件漏洞规则+AI 护栏。Bot 防护用跨天行为链打分；用"提示词投毒"让伪装浏览器的 Agent 自曝特征。服务头部 AI 公司：防百万级 CC，Bot 识别降损约 **30%**。
  5. **古茗实战：智能体重构 SOAR 与攻防验证**（刘星光，古茗安全总监）：研发产出翻倍、安全团队零增员；CVE 从 2022 年约 2.5 万暴增至 2026-09 已 6.6 万。三道门：CI 内嵌 AI 代码审计、上线前 AI 渗透（替代 15-30 天才出报告的外部红队，降到小时级）、运行时 AI Bot。效果：**误杀率 1.8%→0.2%、自动化识别率升至 42%、Bot 规则验证 3 天→15-30 分钟、上线前修复占比 90%+、流入生产高危漏洞减约 70%**；SOAR 侧 AI **2 分 30 秒**定位攻击事件，自动化处置率 **>90%**。踩坑：误报毁信任、漏洞定级须与研发共建、报告必须可复现。
  6. **从 Copilot 到 Autopilot 的 Agentic SOC**（陶夏薇，产品专家）：以 7 月 Hugging Face Agent 逃逸测评沙箱事件为引，指出 Copilot 只做总结建议、人仍是跨域串联卡点。Autopilot=人定目标+授权、多 Agent 组织推进、Harness 兜底。能力生产闭环：真实事件→冻结样本→迭代→灰度→人工审核放行；SOCbench 测评集累计到 **230+** 道，覆盖 16 类攻击场景。靶场复现 HF 链路：关联 7 告警、22 实体、2 受影响资产，**156 秒**出调查结论。客户事件调查从每周 5 天降到 0.5 天。
  7. **压轴：自然语言驱动的安全运维 SecOps Agent**（岑黎光，产品专家）：案例：50+ 子账号/2000+ 主机企业晨报从一上午压缩到 20 分钟出稿+15-20 分钟复核；漏洞修复用 PolicyGate【音译待核】三层管控（意图识别→行为硬校验→强制留痕），Agent 操作与人工操作在审计中可区分。调研数据：单任务时间 **-60%**、告警分诊时长 **-2/3**、处置时长 **-70%**。

- **金句**："在 AI 速度的情况下，我们应该用 AI 对抗 AI，并且依托云安全的数据飞轮构建持续进化的防御体系。"（雷涛）；"大模型跟段誉的六脉神剑一样，时灵时不灵——所以 Harness 很重要。"（魏根会）；"过去渗透测试报告拿到手时版本已经迭代了，更多变成应付检查；AI 渗透让低频验证变成每次发布都做的持续能力。"（刘星光）

- **对读者的启示**：
  1. **Harness 是安全 Agent 的第一公民**：结论波动靠规则双引擎+回放测评集压稳，幻觉靠"审核 Agent+沙箱复现+证据最小集"兜底，死循环靠 DAG 状态图拦截。
  2. **确定性体系与概率体系分层编排是降本正解**：先用规则/小模型/向量引擎解决高频确定性场景，大模型只接难问题并按 Flash/Plus/Max 路由。
  3. **人机边界要产品化而非口头承诺**："高危动作硬校验+强制留痕+Agent 操作与人工操作审计分离"、AI 生成报告必须可复现可反验证；古茗"误报毁信任、定级须共建"的踩坑说明：指标只是入场券，工作流接入点（CI/GitLab/CMDB/审批流）才是价值所在。

## 十一、[154] 制造未来 · 先进制造 AI 论坛

- **整体主题**：AI 正从"可编程的自动化执行"走向"可学习的智能化决策"，云+大模型+智能体如何深入芯片、电池、半导体显示等工业现场，把现场数据变成可复利的数据资产。闭幕词点题："AI 正在从制造的工具变成制造的基础设施。"

- **议程与要点**：
  1. **《先进制造迈入 AI 融合时代》**（高飞，阿里云公共云事业部副总裁）：十年前 CV 模型只能"旁路接入、替代眼睛和双手"；今天大参数模型让 AI 从检测走向思考。提出"从产品售出到产品在线"——设备售出后运行/功耗/故障数据才是价值创造起点；框架公式 **ADI = AI × Data × Industry**。以芯片业为例：全国 **4000 多家**芯片设计公司，**95% 未规模化使用 AI**，卡在"信任"（数据不出红区绿区是铁律）；解法是 Agent 小切口+融合云（EDA 留本地、弹性算力上云），并给出"四化"方案：国产化（国模成国芯全栈自主）、本地化（专有云+AI 一体机数据不出厂）、专业化（千问后训练行业模型）、生态化（自研 AI 芯片【音译待核】出货超**百万片**）。
  2. **《从物理世界的 AI 到工业的智能未来》**（龚嘉栋【音译待核】，宁德时代研发副总裁兼 AI 研发与大模型中心主任）：动力电池**连续 9 年全球第一**、储能电池**连续 5 年第一**，**3 座 WEF 灯塔工厂**。近十年研发投入超 **1000 亿**；**600TB** 研发测试数据、覆盖 **3000 万辆车**。制造端硬数字：电芯生产节拍 **1.7 秒**、缺陷率 **1/10⁹**、生产成本降 **42%**、缺陷从 PPM 级到 PPB 级（**7.5 sigma**）、每天 **34 亿条/秒**数据、累计超 **1 万亿**条数据资产。判断通用大模型三大困境：**不懂物理、不懂因果、不懂现场**，因此垂类行业模型是核心，内核=机理嵌入+数据扎根+闭环验证。
  3. **《AI 向实：TCL 半导体显示产业智能化转型》**（刘阳星【音译待核】，TCL 集团工业研究院总经理）：华星产线投资超 **3000 亿**；近三年 AI 赋能产生超 **25 亿元**综合经济效益。2023 年 12 月发布**业内首个半导体显示垂域大模型**（与阿里团队合作训练），**27B 多模态模型**在垂域理解与推理上经双盲测试**超过 Gemini 3 Pro 与 GPT 5.5/5.6**【型号名音译待核】。AI 仿真 vs DFT：几小时 → 几毫秒，效率差**百万倍**；器件 Agent 几个月内自进化**超越人类专家**；VCD 成膜膜厚预测误差 \<**2 纳米**；视觉缺陷检测+Agent 自动生成修复代码已上线华星全部产线（从自动判缺到自动修补闭环）。
  4. **《西门子 Xcelerator 助力工业企业快速构建 Agent》**（钟卫佳【音译待核】，西门子 Xcelerator 中国区产品总监）：工业 Agent 六大痛点（知识沉淀难、通用大模型不懂工业、OT/IT 难融合、开发门槛高、安全合规严、token 成本不可预测）。平台=AI 知识库+Agent 开发平台（**Skill Creator** 把 PLC/SCADA/视觉小模型封装成 Agent 可调用的 skill）+算力集成（对接千问/百炼），核心架构是**云边协同：云上开发、边缘执行**，数据不出厂。案例：工程图纸解析 **4 小时 → 20 分钟**、BOM 出错率 **8%→1%**；工业电商客服成本降 **55%**、新客转化率 **3%→8%**。
  5. **《艾为电子携手阿里云的全栈合作》**（路易【音译待核】，艾为电子 CIO）：模拟芯片设计公司，**300 多亿颗**芯片出货。AI 累计调用 **130 万次**，**64.5% 调用为系统自动触发**；约 **400 个 SOP** 覆盖 AI、**230 个智能体**在线、3 个数字员工投产：存量客户唤醒 Agent（**2 天开发**，从 8000 个沉睡客户中激活 730+、带来 200 多万新交易额）、供应链数字员工（跨 8 个节点）、代码数字员工——人均有效产出**提升 100%**；边界划定：需求→实现→测试自动化，**验收与合入上线仍由人把关**。
  6. **圆桌《跨过 POC：制造 AI 的长期运行》**（主持：张一甲，甲子光年 CEO；嘉宾：阿里云、上海新源、施耐德电气、诺瓦聚变【均音译待核】）：诺瓦聚变：AI 代理模型加速设计参数寻优是最佳切入点；走向在线诊断/控制时推理窗口仅**微秒级**，模型需压缩下沉到 FPGA。施耐德三个坑：POC 效果上产线后质量衰减、单点标杆无法规模化、组织人才与文化撑不住。韩宏元：**POC 是 proof of concept 不是 trial run**，概念抽象清楚才有可复制性。人才终局（施耐德毛春景）：人剩下四件事——提出好问题、发明创新结构、做最终判断、注入品味审美，且他判断 AI 掌握物理规律还需 **5~10 年**以上。
  7. **《AI 时代下的阿里云先进制造行业解决方案》**（贾朝辉，阿里云公共云解决方案架构总监）：大模型进工厂的四类缺口：数据割裂、知识隐性、工具孤立、责任无人背；解法是把**现场数据+企业知识+大模型+专业工具+安全治理**五要素连接。落地四件套：①数据产线=多模态湖仓+**数据本体论**，弥合对象/时间/因果三种断裂；②专属大模型=千问开源底座+企业数据后训练；③**黑灯研发产线**：TL Agent 拆任务 → Worker Agent 执行 → 监控 Agent 巡检 → 人只做确认发布；④质检=大小模型协同（小模型毫秒级感知、专属大模型跨系统根因推理）。

- **金句**："POC 叫 proof of concept，不是 trial run。第一重要的是你有没有把这个 concept 说清楚——抽象得足够好，proof 就应该具备可复制性。"（韩宏元）；"电池不是代码，不是光靠数据就行。谁能用 AI 更深刻地理解物理定律，就能建立不可逾越的壁垒。"（龚嘉栋）；"AI 不会自己提出问题。人剩下的事：提出好问题、找到创新的结构、做最终判断，再加上你的品味。"（毛春景）

- **对读者的启示**：
  1. **Agent harness 在工业场景的共识架构**："云上开发、边缘执行"（数据不出域）+ 人的确认节点设在最后一步；做 agent harness 时应把权限、审计、人工 review 门设计为一等公民。
  2. **上下文工程是企业级 Agent 的真正瓶颈**：模型不缺聪明，缺可靠上下文。对象/时间/因果三种数据断裂靠"数据本体论+多模态湖仓"弥合；先做上下文供给与评测集，再谈模型选型。
  3. **闭环与成本决定能不能上线**：垂域模型靠"双盲测试+自动化评测"证明超过通用旗舰（TCL）；在线控制场景推理窗口微秒级要下沉小模型/FPGA（诺瓦聚变）；大小模型路由、离线训练/在线推理分层是 Agent 规模化运维的实操纪律。

## 十四、[139] AI 重塑中小企业经营 · 入口分论坛（万网专场）

- **整体主题**：阿里云万网围绕"域名→建站→备案→经营"的中小企业数字化主链路，发布万小智 3.0、万网 CLI 等产品，提出从 Web coding 到 Web business（把"建好网站"延伸为"经营一门生意"），并联动生态伙伴共拓中小企业 AI 市场。

- **议程与要点**：
  1. **《AI 时代中小企业的变与不变》**（高坤，阿里云企业应用总经理【音译待核】）：AI 分三阶段换挡——万小智 1.0 提效设计、2.0 让小团队做出过去不可能的作品、今年 4 月后各种 coding agent 让工作从"完成任务"变"交付结果"；老三样被重做：AI 起名建议域名、万小智几十分钟建站、"万小贝"【音译待核】预判备案驳回。**四大不变**：决策方向、获客方法、让客户付费、盈利准则。建议：别被热点牵着走、深度下场体验、守住核心竞争力。

  5. **《AI 时代的互联网新入口：阿里云万网 CLI 发布》**（孙亚健【音译待核】）：数据：中国 AI 应用月活超**5 亿**、6 月桌面智能体用户超**6000 万**。万网 CLI 打包**域名、建站、备案**三模块；安全边界=只读查询直接授权，改解析、过户、提交备案等敏感操作必须用户确认授权（agent harness 权限设计范本）。
  6. **圆桌《AI 合伙人时代》**（瑞阳科技、财源家纺、小年科技、横竖撇捺【音译待核】）：三道门槛被拿掉：口述建站、一键备案上线、GEO 获客；金句：网站建好搜不到"就像教室里的黑板报"；共识：小红书/抖音封闭难被 AI 抓取，官网成为 AI 时代新流量入口，GEO 现在是机会窗口期。

  10. **《万小智生态合作政策》**（刘天勇）：GEO 市场 2025 年约 **2.5 亿**规模，今年是"中小企业元年"；服务商模式可独立控制台交付。
