# 201-AgentInfra生产级实战

> 云栖大会下午的「Infra 智能体与大模型训推生产及实战解析」分论坛（容器与沙箱专场），共十场演讲，阿里云弹性计算/容器服务团队联手百炼、千问办公、生数科技、小红书、洞察时空、智元蜜蜂、朗新科技等一线讲者完成。两条主线：Agent Sandbox 作为全新算力形态走向大规模生产验证（千万级在跑、10 万/分钟创建、冷启动百毫秒）；AI Infra 评价体系从「有没有算力」转向「同样算力产生多少有效业务结果（Goodput）」。价值：一份 Agent Infra 生产级落地的技能与数字全景图。

## 这场为什么开（背景与定位）

上午场完成 Agent Sandbox 品牌发布，下午场是配套实战交付：把概念拆成 Infra 总纲、训练评测闭环、百万级 Agent 运营、数据飞轮、具身智能、多模态推理、时空智能、小红书实践、智能运维 Agent、云端编码平台十个切片。讲者一半是阿里云弹性计算/容器服务专家（讲底座能力），一半是真实客户与联合方（讲怎么用），合起来是一份「Agent 时代 Infra 选型说明书」。

## 逐环节超详细还原

### 环节一：杨旭——企业级大规模 Agent Infra 解决方案最佳实践

开场趋势：Agent 的 TO B/TO C/TO D 界限模糊，大厂下场后「模型能力+Agent 入口」会被统一，企业要聚焦 Skills 和 MCP 沉淀；桌面助手形态（千问办公、Claude Code 类）正成主流；端云协同是必然；企业出于安全自研，但基本不再自研 Harness。Infra 要求排序：安全已是极高门槛的入场券、不是加分项；其次是数据治理与数据安全；Context Engineering 已超过 Prompt Engineering；阿里云定位是做「Agent 安全高效运行的基础设施」而非单个产品：底座是十六年弹性计算沉淀——单机 100 毫秒启动沙箱不难，难在 100 万、1000 万沙箱规模下还能这样启动并长期稳定，这是与创业型 Agent Infra 公司的根本差异。

架构五大领域：环境（沙箱、文件系统、网络控制、评估观测）、上下文（Memory、RAG）、工具（Skills、MCP）、安全（身份鉴权、防护、审计）、模型（千问+企业自有后训练模型）；沙箱分极速版（面向开发者、主打启动速度）与容器版（100% 兼容容器生态、沿用 K8s 管理），典型场景是 serving、强化学习、评测。硬数字：云上在跑沙箱超千万个，单 region 百万级并发，并发创建 10 万/分钟，完全无预热一秒启动；安全 100% 隔离（存储介质、网络出入、四七层含 IP+域名权限、集群容灾）；生态 100% 兼容 E2B 协议。文件系统三种挂载：专为 Agent 设计的新文件产品（百万级目录数、RPS 超传统 NAS）、EBS 版、对象存储（海量+低成本）；可观测集成 Agent Loop 让黑盒沙箱可控。上下文侧：Memory 把高频出现的人、组织、项目、工具自动沉淀为画像，支持记忆图谱与去重；RAG 核心是知识入库、自动分析、自净化，接入 ContextDB、知识引擎、Agent Storage 三个产品。安全四件套：Agent ID（每次访问后端临时生成凭证，而非一次授权无限调用）、AI 安全护栏（提示词扫描、注入防护、合规检测）、Skills 托管自动扫描、主机安全（0day 漏洞）。案例：MiniMax 在其上跑大几百万沙箱，核心诉求是大规模镜像拉起速度（镜像加速、带宽、插盘、网卡全链路工程），该底座现承载「全球最大的强化学习规模」；智谱另要求端到端安全——注毒检测、运营环境安全检测、乃至 0day 攻击研究沙箱。

### 环节二：洪小龙、罗自荣——Agent Sandbox 加速训练与评测闭环 × 百炼 Agent RL 规模化实践

洪小龙用学生类比分工：RL 像单元考课堂作业，靠行动奖励在循环反馈中更新参数；Eval 像中高考，固定模型+Agent 配置跑数据集打分，不更新参数但要大规模验证。沙箱四价值：真实执行、长时连续状态反馈、任务完全隔离、批量供给；按生命周期抽象四能力：极速就绪（镜像缓存、按需加载）、弹性供给（批量创建、按需回收）、环境干净（MicroVM+访问控制）、连续执行（带上下文状态）。他提出「Loop Engineering」：RL loop 的 rollout 采样与 reward 计算都跑在沙箱、完成参数更新，经 Eval 验证后发布，进生产 Agent loop（MCP server、coding、browser、computer use 同样跑沙箱），结果反馈后轨迹沉淀、难例分析、迭代——两个 loop 组成大 loop。指标：五分钟开箱即用、用完即毁；批量环境交付 10 万/分钟；5000 并发 3GB 镜像 1~2 秒就绪；综合 TCO 降低 50% 以上。

罗自荣讲百炼多租户企业级 Agentic RL 训练平台：让 RL 不再是实验室和头部玩家专属，目标「训得了、训得起、训得好」，还要求高稳定、高安全（训练数据是企业核心资产）、完整监控运维。百炼已有数据管理、调优、部署、评测四大板块闭环，覆盖 CPT、SFT、DPO、RL 与 GRPO，支持千问、万象、CosyVoice 等全模态。RL 训练以 SDK 衔接：开通可观测、Agent Sandbox、SLS 后撰写 reward 和 rollout 函数，先函数测试再 SDK/CLI 提交，在百炼看指标、轨迹与日志。架构五板块：CLI、控制面、执行面、训练面（核心：rollout 与 trainer 负责轨迹采集、损失、梯度、参数更新）、观测面；reward/rollout 抽象为「函数实体+沙箱里的函数实例」，为评测与部署复用闭环奠基。网络是关键难题：Agent 在客户侧网络、损失梯度计算在百炼，公网不安全低效且贵，遂共建沙箱化专属内建通道，用户无感内网访问；镜像依赖预推各 region 加速扩容；可绑客户 VPC 访问内部服务与工具。评测复用：reward 函数指向新部署模型，系统自动 rollout 推理再打分，「训练的飞轮就快速旋转起来」。

### 环节三：卢蒙凯、严龙——驾驭百万级 Agent：Agent Sandbox 核心能力与千问办公生产级实践

卢蒙凯回答最常被问的问题：Agent Sandbox 与 ECS、K8s 的区别？答案是全新算力形态——「云上的超级计算机」，区别有三：安全极致；弹性极致（1000 QPS 并发启动、1~2 秒拉起；单 region 一分钟 10 万，自建 K8s 或 ECS 难以满足）；Agent 专属功能（深休眠、快照）。Agent 负载三类：工具沙箱（Code Interpreter、Browser、Computer Use）、有状态长驻负载（OpenCloud、Hermes 这类）、强化学习。极速版基于 Serverless 封装复杂度，接入层有 E2B API 与原生 OpenAPI 两种形态，往下是完整生命周期管控与轻量化虚拟机运行时；展会现场从零拉起一个 DeepSeek Harness 的 Agent 只需五分钟。安全是「生产可用的前提」，分六层：运行时、网络、存储、内容、身份鉴权、安全扫描。MicroVM 每沙箱实例独占，把大模型的提权、跨实例、绕内核攻击限定在单实例；会话亲和让请求只调度到与用户绑定的沙箱，可访问内网/公网可管控；敏感 API 密钥替换——沙箱放假 key、出公网换真 key。存储动态挂载两用途：用户态数据隔离（记忆、会话以 Markdown 存本地路径，挂载到 Agent 专属存储介质按用户隔离）；有状态负载存算分离（算力无状态、随用随开用完即毁）。降本上，OpenCloud 式每员工一实例，百万人就是百万常驻沙箱，成本不可承受，于是提供浅休眠、深休眠、快照：空闲超时限休眠、一秒内唤醒、不占 CPU。快的原理是五层缓存：快照缓存到裸金属本地盘（命中百毫秒拉起）→跨机 P2P→预热到 CPFS→集群内自建 P2P root 集群（放热镜像）→远端镜像仓；命中率超 98%，最终指标：并发创建 10 万/分钟、冷启动 100~180 毫秒、热启动 20 毫秒、深休眠唤醒 600 毫秒。

严龙讲千问办公（写 PPT、周日报、一句话生成网页应用并一键部署）如何给千万级用户 7×24 在线云上沙箱，五要求：任务快速可感知、代码数据持久化、数据不泄露不越权、海量沙箱快速创建同跑、成本可控。落地四难点：快速创建——「与用户无关的提前准备、与用户相关的来人再加载」：镜像做模板、维护预热池、存储提前建来人绑身份挂载，创建从几十秒压到一秒级即开即用；三层隔离——企业间（数据凭证互不可见）、业务间（独立资源账号+集群隔离）、单任务四环节（身份校验、凭证不落沙箱出网换真、记忆按身份加载、出网黑白名单）；持久化——外挂 AntikFS 为每用户建虚拟空间与访问点；成本——临时任务用完即毁，多轮对话环境先深休眠（毫秒级唤醒、不占 CPU）再释放，阈值按线上真实会话时长定。

### 环节四：华向——以 ACK 为底座的开放产线与数据飞轮

华向讲自动驾驶与具身智能的数据飞轮：数据是核心资产但不能直接产生价值，要经处理、训练、反哺产品才成闭环——激光雷达、毫米波雷达、摄像头持续采集，回传后清洗、脱敏、挖掘、数据集重建、标注（含隐私与地理信息合规），再进训练；上车前仿真评测（软件在环、硬件在环、驾驶员在环），最后 OTA 交付车端。具身智能同构，采的是机器人操作的空间数据、位姿数据与第一视角视频。闭环是典型有向无环图，没有引擎就要自己解决：串并行编排、参数传递、动态并发度（视频切片后按切片数定并发）、大规模调度、失败处理（从失败节点重跑而非从头）。ACK 上的引擎是 Argo Workflow——CNCF 很早毕业的项目，已在 AI 数据准备、科学计算、金融量化、仿真计算落地。能力：多算力选择（ACS、ECS、EGS，CPU/GPU）；数万级并发工作流、单集群十万级 Pod；OSS 缓存优化吞吐数倍提升；集成 OSS/NAS/CPFS/ARMS/SLS；多租户配额；免运维。生态上，工作流可串行编排 Spark、Python 脚本、PyTorch、Ray Job 等 Job 式任务，存量业务不必推倒重来；还提供 K8s 原生方式用 Ray——提交一个 YAML（RayCluster/RayJob）自动拉起 Ray 集群、执行完自动释放，30 秒内提供一万节点的 Ray 集群、单 ACK 集群支持 3 万个 Ray 集群。他强调工作流用户最关心的不是并发度与错误率，而是单位时间吞吐与优先级插队。

### 环节五：赵坤、尹鑫——构建敏捷基础设施，助力具身智能加速业务创新

赵坤核心判断：具身智能资本青睐、技术百花齐放，但「敏捷的基础设施才是决定具身创业公司能跑多快、走多远的关键因素」。三条态势：模型侧从 VLA 卷向世界模型（VLA 关注操作、缺思考，两者将结合）；数据与本体强绑定、泛化差；真机 vs 仿真之争正被第一人称无本体采集改写。结论：范式未共识、业界还在等具身的 ChatGPT 时刻，此时敏捷基础设施「不是一个成本项」，而是加速交付、降低试错成本的杠杆。底座：灵骏供世界模型与 VLA 训练海量算力；RTX PRO 5000 适合具身仿真推理——2.3 倍非阉割算力、5GHz 主频、显存最高 72G、ERDMA；免费 LongKey 加速套件零侵入、一条命令使能，在派林、OpenVLA 等带来 50% 以上 VLA 提升。方案在客户处三统一（创建使用、运维管理、纳管调度），云上云下混合，已服务智元蜜蜂与「苏度科技」等头部客户。总结：竞争表面是模型算法算力，深一层是数据，最底层是基础设施——范式变化快，基础设施一绑定，路线一变企业可能万劫不复。

尹鑫代表智元蜜蜂讲数据供给：使命「让全世界的数据为 AI 所用」，定位平台供给，标准「又好又全又快」——全=真机、仿真、无本体三大数据全覆盖，好=工业级质量管控，快=规模化产能。产品矩阵覆盖二指夹爪（毫米级轨迹重建）、头戴摄像头（全景+腕部双视角）、自动化质检引擎（标注效率提升约 10 倍）与 G2 Air 一体化本体（采完即训）；联合上电科与国家数据标委会推「蜂巢行动」统一标准。布局：国内约 20 城创新中心、海外 5 国节点，目标千万小时产能；当天发布众包 App「蜜蜂派」（租设备、领任务、传数据拿收益）。三大基建挑战：其一脉冲式弹性——对标友商 Figer Index 上线 4 个月覆盖 108 国、4.4 万日活、1600 万视频、支付 1500 万美元（每秒 30 分钟视频、每天约 4.9 年人类操作量），要算力存储带宽秒级伸缩，方案为 ACK Pro 弹性节点+Serverless 容器+全托管 Argo，压测峰值并行 1.6 万 Pod、CPU 利用率近 100%；其二规模——京东宿迁发动 10 万市民叠加 60 万人力、两年 1000 万小时目标，某头部玩家未来 12 个月数据算力投入 10 亿美元量级，全球缺口千万小时与现有十万至百万小时产能差两个数量级，需 PB 级存储与湖仓、一次生产多次复用、全流程自动编排防质量衰减，OSS+湖仓+Argo 验证稳定 958 小时/小时吞吐（约每天 2.3 万小时）；其三边缘到中心——采集点散到家庭、餐厅、工厂、社区，要就近接入、断点续传、加密回传、分级授权、全程审计。技术栈：真机与智云两条链路（OSS→切分打标质检→入湖仓）→定制交付算子走测试/生产与人工质检；ACK Pro 把采集、处理、训练放同一底座，虚拟节点 Serverless 万核/分钟弹性、按秒计费；Argo 对比开源自建：单工作流最大节点 3000→2 万、并发工作流 5000→5 万（十倍）、调度小于 50 毫秒、资源省约三分之一；现每日调度约 10 万工作流、数百万 CPU 核。

### 环节六：张凯、姚铮——容器智算底座助力多模态 AI 业务稳、省、快

张凯把视角拉宽：容器团队从 ACK 云原生 AI 套件（预训练）、AI Serving Stack（推理）、Data on ACK（数据管线）到 Agent Sandbox，用统一容器底座让快速演进的 AI 业务稳省快。AI Infra 双向挤压：向上覆盖预训练、推理、后训练、多模数据管线、安全沙箱，向下调度通算智算与异构网络存储，解法是把调度、数据加速、推理网关、可观测、故障自愈等原子能力下沉云原生公共层。硬件侧第一时间纳入阿里自研 AI 芯片新一代 M890：SCN64 超节点互联架构，超节点=8 节点 64 张 PPU 卡、卡间互联 800G；以拓扑感知、Gang、Binpack 调度把任务 Worker 收敛进同一高速互联域；超节点内结合 K8s 最新 DRA 架构分配独立通信 channel，再配 80 多项监控、AI profiling 与超节点故障自愈——分得准、看得清、恢复得快。推理侧与 SGLang 社区联合推出 RBG（Role Based Group）：用 Segment 划分推理实例组，组内 PD 拓扑亲和+Gang 调度，KV cache 经 GDR 直传；以 Segment 为单元横向弹性、滚动升级、原地更新。ACK 推理网关综合前缀命中、队列深度、KV cache 使用率做智能路由——千问 3.8 Max 在 M890 实测：启动端到端 34 分钟→2 分 20 秒、TTFT 缩短 75%、KV cache 命中率 40%→90%、同算力吞吐较开源提升 3 倍。本场最重要概念 Goodput：真正有效工作时长占比（成功完成业务耗时/资源总占用时长）；利用率回答 GPU 忙不忙，Goodput 回答多少工作形成有效业务结果。冷启动连续剧：去年 DeepSeek R1 从 OSS 到显存分钟级（10 倍加速）；今年自动寻找集群内已有同版本模型显存的实例、GDR 短路直传，否则回退 RDMA 加速的 ModelStore——千问 3.5 397B 约 400G 冷启动降到 63 秒、再提升 2.5 倍。运行时优化（NUMA 亲和、NCCL 配置、KV cache 独立服务）让 coding 吞吐提升 2.69 倍、其他 1.4 倍以上。针对 MaaS 长尾模型「不适合独占 GPU、反复扩缩加载慢」，推出多模型共享 GPU 热切换：进程容器不重启、显存内换权重，权重多级预热，网关先排空再切换；CUDA Graph 自适应 reuse/recapture 策略——实测 8B 到 235B 全部秒级热切换，较重启引擎加速上百倍、某些 size 达 400 倍。最后 Agentic RL on ACK：基于 Ray on ACK 拉起整套 RL 系统，trainer 与 router 分离、与推理分离式扩缩容，探索基于 Harbor 数据集格式的标准 rollout 流程，可从 GitHub 原始数据自动转 Harbor 数据集+沙箱镜像+缓存加速。

姚铮代表生数科技（自研 U-ViT 架构融合 Diffusion 与 Transformer，世界模型底座长出商用视频生成模型 Vidu 与将发布的世界动作模型）讲实战。讯推平台四层：算力底座→统一控制面（ACK Pro+ACS）→自研调度决策与 AI 网关层→模型服务运行时。四痛点：弹性——全球几十国用户，南美娱乐用户要求低、国内商用短剧要求高，白天数万卡在线凌晨掉到几千卡：TO B 稳定性 99.9%、采购成本降约 20%、弹性从十几分钟到 15 秒；数百模型长尾（历史模型因用户在用不能下线），基于 ACS 镜像缓存把 100G 模型切换从约 10 分钟压到 15 秒内；GPU 多达 10 种（国产、英伟达、AMD）故障各异，ACK 事件转换+节点异常探测→按预设规则自动重启或隔离换机，硬件故障自愈率超 99%；20 多个节点分布多云与 IDC、用户遍布全球，ACK One 一个控制面统一管理北京、上海、乌兰察布及线下 IDC，全局 HPA+全局调度器：优先稳态资源、不足跨地域拉弹性，按付费/免费/VIP 做优先级抢占——GPU 利用率+20%、成本-15%。未来四方向：训推一体统一算力池；全球一张算力网（海外仍需 Cloudflare/AWS 接入）；显存级热切换；从硬件自愈走向业务自治运维。

### 环节七：沈健——时空智能 Infra：构建感算觉一体化的技术架构

沈健少讲技术、多讲业务 context：时空智能是整个物理世界 AI 的基础。大语言模型起点是人类符号世界；物理世界模型起点是真实世界状态，学习对象、时间、空间、运动、因果、物理约束与状态演化。尺度上：微观是生物医药；中观是自动驾驶与具身；宏观假设——一切具备可观测状态、时空演化特征、受物理因果约束的复杂系统都可成为研究对象，拓展到海洋渔业、矿产勘探、远洋物流、城市管理等行业。评测靠观测而非人打分（物理世界客观、人的认知有限）；大尺度观测靠卫星。商业航天让数据井喷：中国对地观测数据约 10 PB，十年末保守估计 300 PB；光学、SAR、红外、微波等多模态传感器像人的五官。Planet 星座例：每天约 13 万亿个独特 8 波段像素，人工分析约 7 年、AI 查找 2 分钟、全流程节约 95% 以上。算力侧：18 年前训练计算量万匹（PFLOPs 级）量级，GPT-4 已达十亿匹。洞察时空基于 ACK 与原生 AI 套件组装场景化作业平台——向下统一异构基础设施、向上提供标准化 AI 工程能力；统一卫星调度与空间分析、数据处理与 AI 训推流水线化、预测决策到结果闭环——回答的不是「把模型训出来」，而是观测、获取、处理、分析、决策、验证全闭环。观测密度靠自研「数算一体 AI 星座」：一期 576 颗低轨和超低轨卫星，天地一体算力协同多模态异构感知网，星间组网、分布式处理、高速星间中继，高频重访形成客观规律；数算一体为降回传带宽——部分数据星上预处理甚至推理、仅回传结果。地面三件事：实时化、闭环化（模型持续被真实世界验证纠偏）、智能观测调度（用 Agent 和 Skills 反向决定下一步观测什么、哪里、何时、怎么观测）。案例：星雀气象模型在百米风速、辐照度、降雨上优于行业主流，台风「白海豚」中长期路径平均误差较行业低两到三成、提前 9 天预判核心降水区；能源场景做新能源功率预测与电力现货一体化预测，电价引擎 14 天前瞻、15 分钟滚动，短期较行业基准收窄 25%，负电价提前预警、让机组躲开中午光伏大出电的收益塌方，赋能虚拟电厂。

### 环节八：车样、熊峰（奥可）——容器服务携手小红书：大模型推理与 Agent RL 生产实践

车样先立北极星指标：推理落地已从「能不能做」变成「做得好不好」，业界共识（英伟达口径）是每百万 token 成本（Cost per token）而非 TFlops——分子是每小时 GPU 成本，分母是吞吐乘 GPU 利用率。降本两条路径：向推理引擎要性能，向时间要效率（潮汐低谷把闲置算力给强化学习、数据处理等离线任务）。今年两个新增强：ModelScale 权重高效分发、InferenceKit 运行时深度扩展。收益：SGLang TP8 下千问 3.5 的 397B、400 多 G 模型，去年已优化到约 120 秒加载，今年 ModelScale 压到 20 秒、加载从 3GB/s 到 20GB/s，大规模推理服务第一次具备真正弹性；InferenceKit 在 Agentic coding 吞吐提升近 3 倍、写实 1.28 倍、RAG 1.44 倍，全部自动注入、一行引擎代码不改。推理网关融合优先级与公平调度、端点实时负载、KV cache 亲和性——真实客户装上网关后 TTFT 降 75%、TPOT 降 40%、吞吐提升 3 倍。ModelScale 解决权重搬运瓶颈：传统链路 TCP 打不满带宽、缺 GDR 要过 host 内存中转、副本不能互传；新方案 RDMA/eRDMA 原生+GDR 直达显存+Mooncake Transfer Engine 的 P2P 分发，自动选冷/温/热存——冷加载后权重存入 Mooncake 温层，二次扩容直接从运行中实例 GDR 拉取，缩容为 0 权重仍在。实测千问 3 32B（65G）从优化后 45 秒降到 GDR P2P 的 3 秒（1/15）、纯 RDMA 6 秒（1/9）。InferenceKit 处理启动的隐形大头（编译、CUDA Graph 捕捉、进程初始化）与静默坑（NUMA、NCCL 配错只降速不报错），三级进程内注入，一个 annotation 获得启动加速、拓扑亲和、权重选路；注入非静默、用户显式配置优先。实测：TP4 跨 NUMA 约 15% TTFT 开销；PPU 1.5 不开域内互联走 RDMA 吞吐损失 40%，默认开启后吞吐+40%~55%。总结：100% 开源、适配 vLLM/SGLang、大规模生产验证。

奥可讲两件事。其一推理编排调度：部署形态从单 Pod 多机、PD 分离到专家并行、Attention/FFN 拆分长期共存——K8s 擅长管 Pod，但仅 Pod 声明不足以表达一组推理角色如何协同。抽象出按组创建升级扩缩、整组资源齐备再准入、注入角色与设备拓扑、继承限流删除防护等机制。发布侧：预热分发、尽量原地发布（只重启容器不重建 Pod）、必要时 PodGroup Cache 回原节点复用镜像层与编译产物，每批次发布从几十分钟降到几分钟。角色负载不同步时把 Role 升为一等编排单元（Router、Prefill、Decode 独立扩缩，RBG 声明协同策略）；segment 把 P/D 成段准入放进超节点、优先段内配对让 KV cache 局部化。落地：已在小红书绝大部分核心业务与内部 MaaS 规模化，同 SLO 大服务吞吐 2~3 倍提升；并与 ACK、科大讯飞、南京大学共建贡献进 RBG 开源项目。其二面向 Agentic RL 的基础设施：Agent 围绕任务反复调用模型、工具、环境并多轮改变现状——管理对象从服务实例扩展到任务与执行环境；训练评测经 harness 驱动大量 rollout 并行采轨迹，两类场景都要沙箱但生命周期与交付诉求不同。内部 Agent Infra 平台三层：上层统一接入治理，中间编排、访问与状态管理，底层池化沙箱。探索一 checkpoint+WAL：快照统一保存 rootfs、外挂存储与内存，WAL 记录命令、结果与提交进度，实现断点续训；中间态当训练种子——公共前缀执行一次，从同一 checkpoint fork 大量沙箱各试不同后续动作，减少前缀重跑。统一 rollout 托管：task 描述任务、环境与验证方式，Rollout 组织 harness 与沙箱完成创建到清理全流程，模型经 proxy 对接、轨迹与奖励回传。

### 环节九：胡光——智能体自治时代：容器服务 Agent 全场景最佳实践

胡光用三个数字立论：66% 的组织用 Kubernetes 托管 GenAI 应用，82% 的客户已在生产部署 K8s——「AI 跑在 K8s 上已经成为新姿势，K8s 不是选做题而是必答题」；同时 97% 的组织近一年至少一次安全事件。判断：「当复杂度超过一个人的极限的时候，智能运维就不是一个可选项，而是必须要去做的一件事情。」产品底料是容器服务多年运维专家经验+基模、零售、智驾等 Agentic 场景沉淀，基于 Agent Harness 规划自主决策执行中枢、多智能体协作、任务编排、安全护栏、自动测评与数据飞轮。拟人化四阶段：Plan 全生命周期（部署模板、ECS 实例与弹性配置推荐）；Sense 主动感知（定时巡检给修复方案）；Think 定位根因生成方案；Act 安全可信执行（生产变更需客户 approve，执行代码拉起沙箱隔离，审计日志全程可追溯）。按 Day 0 到 Day N：Day 0 辅助集群创建；Day 1 辅助写 YAML 并做安全分析、把问题挡在上线前；Day 2 批量化异常监测+钉钉、飞书 IM channel 远程处理；Day N 把客户运维经验沉淀为 skills 喂给 Agent、定时任务走向自治。两个案例：头部客户临时存储超限触发驱逐，告警 5 秒触达手机钉钉，客户还没打开手机 Agent 已秒级推送根因，手机端查验后 approve、两分钟恢复；客户在 ACK 跑 SWE-bench 类 Agent RL 训练，大规模 rollout+GPU 池对稳定性要求极高，内置 Skills+客户扩展 Skills 实现分钟级根因定位、小时级恢复压缩到分钟级，多次训练任务失败率从 1% 降到万分之五。公测数据：每天主动发现异常累计 3.6 万次以上、诊断准确率 85% 以上、约 80% 现有客户已开始使用——「让你的集群也有一个 7×24 小时随叫随到的值班 Agent」。

### 环节十：张栋——朗新 AI 时代生产力：基于 Agent Sandbox 的云端 Agent 平台

张栋介绍朗新：聚焦能源领域的 AI 科技公司，客户有国家电网、南方电网、中国移动、阿里云、蚂蚁等，C 端有支付宝水电燃缴费与聚合充电平台星电途；约 6000 人、技术约 3000。转型三段：创始人自 ChatGPT 时刻推动拥抱 AI；DeepSeek 后组织级推动，产研先做通义灵码等 vibe coding，发现「个人提效不等于组织提效」后转 SDD 范式推广；今年年初受 OpenClaw 类产品爆火启发，搭建「九宫数字分身」云端编码平台。定位最哲学：传统软件组织以人为中心，做个人助手=生产关系不变只提生产力——「我们在初中二年级的政治课上就学过，生产力决定生产关系，生产关系要适应生产力的发展」；因此分身定位为新质生产力本身，人围绕 AI 生产力在外围做规划、审查、验证、决策，「重构 AI 时代的生产关系」。架构四层：底层 Agent Sandbox；运行时用最好的编码 Agent CLI（阿里的 Cuda、Keras、Claude Code 等，转写音）；资产层用 Rules、Knowledge、Skill、MCP、Memory 沉淀项目资产；执行层由任务生成 Plan 并以流程与技能执行；上层包装研发、运维、运营、业务分身。选 Sandbox 四理由：安全隔离、秒级弹性、状态保持（唤醒后与休眠前完全一致，休眠期间 CPU 内存不收费）、K8s 生态兼容。需求智能分流：中小需求分身全自动闭环，仅留两个人工卡点（Plan 审核防走偏、MR 合码前人工审核）；复杂与探索型需求由分身纳管本地算力、自研 pilot 接本地 runtime，云端与本地实时资产回流——云端分身始终拥有项目最全知识资产，人员变动或新项目可快速复制分身。愿景「白天规划，晚上执行」：开发者主要审核 Plan 入队，分身夜间执行，次日人审。现状：约 100 多个常驻分身、200 多个动态分身，CPU 内存约一比二；上线以来零生产级问题。

## 这场的意义

对行业而言，这场论坛宣告了「Agent 专用算力层」正式成形：沙箱不再是 Demo 玩具，而是有 SLA、有产品分版（极速版/容器版）、有协议标准（E2B）、有专属存储与观测体系的新算力形态——千万级在跑、10 万/分钟创建、百毫秒冷启动、600 毫秒深休眠唤醒，意味着「给每个用户、每个任务、每次 rollout 一个干净沙箱」在成本上首次可行。更深的信号是评价体系迁移：Goodput、Cost per token、模型切换 15 秒、发布分钟化，指向同一共识——Infra 的竞争力不再是你有多少卡，而是每一份算力沉淀出多少有效业务结果。

对个人而言，这就是一份 Agent Infra 岗位的技能图谱与面试题库：沙箱生命周期与休眠唤醒、MicroVM 隔离与假 key 出网、E2B 协议、reward/rollout 函数抽象、KV cache 亲和与 GDR 直传、CUDA Graph 热切换、Gang 调度与 PDB 容量底线、checkpoint+WAL 断点续训、Goodput 指标设计——每个名词背后都有可复现的工程细节和实测数字，值得直接收进技术弹药库。而对正在企业里推 AI 的人：工具层提效很快触顶，真正决定上限的是敢不敢把任务交给 Agent 跑在安全隔离的环境里、并围绕它重建流程与分工——沙箱就是那条「敢交出去」的信任底线。
