## 一、[181] Qoder：AI Coding 赋能超级个体

### 议程结构
谢吉宝【音译待核】（Qoder 技术负责人）总纲 → 谢文欣（五人七天造 Qoder Work 复盘）→ 李玉忠（管家婆 31 年 ERP 厂商案例）→ 刘洋洋（CLI 与模型联合进化）→ 张访华（云备份值班 Agent"小K"）→ 耿新（Qoder Wake 数字员工）→ 高轩（专有云数字员工"程致远"）→ 吴丹武（Qoder Mobile）→ 圆桌（清华博士生/影像机构/淘宝客户端）。

### 核心观点
1. **用户结构质变**：30% 用户已是非专业程序员、超 50% 任务非传统编程、**80% 的人不再亲自写代码而是 Agent 写**；产品因此分"编程模式/通用模式"（后者隐藏 Git/Worktree 等专业概念）
2. **编码只占软件工程时间 30-40%**，Qoder 把边界放大到设计→研发→测试→交付全生命周期，全员（产品/设计/前后端/测试）共享一个上下文空间
3. **"代码可以自动生成，但共识不会自动生成"**：AI 放大每个人的产出，也放大模块间对不上的混乱——解法三步链路 = 人定架构协议 → 共识写进 AGENTS.md → E2E 测试兜底
4. **同一套 Harness 撑起五形态**（IDE/CLI/Cloud Agents/Wake 数字员工/Mobile），与千问+百炼联合调优做"千问最佳 Harness"
5. **企业落地"四可信"**：身份可信（Agent 发工号、可审计追责）、模型可信、数据可信（权限可控）、运行可信（全程日志）

### 技术要点与数字
- 生态：150+ 连接器、70+ 插件、**2 万+ Skills**；Repo Wiki 以代码为唯一事实来源 + 企业知识库 + 共享 Skills
- 安全左移：L1-L4 主动扫描，检测 180 万次、修复 5.8 万漏洞，修复率 55%→90%
- Cloud Agents：5 月上线，服务数千家企业、10 万+ Agent；Qoder Wake：2000 家企业、部分场景 10 倍提效
- **管家婆案例**：45 岁资深开发者 7 个月独立完成企业级 AI MES——600 次提交、**110 万行代码**，同时管 20 个任务；教训"前期两版只有代码没有文档，推倒重来"，五层打法 = Rules 硬约束/项目级 Skill/记忆分层/子代理/定期知识重构
- **值班 Agent"小K"**（阿里云云备份）：自动处理 95% 工单告警与巡检；知识底座纯 Git 管理；工单双轨（确定性走代码=绿轨、模糊判断走 CLI=蓝轨，独立审核 Agent 打回重写）；"做厚知识、做薄 Skill"
- **数字员工"程致远"**月度成绩单：153 位对话者、239 个群、3000+ 任务、**成功率 98.9%**、685 次提交覆盖 51 个代码库
- CLI 三形态：TUI（多 Agent/goal 模式/loop 修正）、Headless（-p 接 CI/CD）、Agent SDK；北极星指标 = **单次任务成功交付成本（token+时间+人工介入）**

### 金句
- "AI 的上限取决于你为它建立的纪律和记忆。"
- "我是一个人，但我是一支团队，我背后有千军万马。"（李玉忠）
- "一身班味他扛，团队工作他干——把研发的时间还给创造。"（张访华）

### 启示
Harness 是 AI Coding 公司的核心技术资产；生产级 Agent 三件套 = 共识工程（AGENTS.md）+ 验证闭环（E2E+独立审核 Agent）+ 手脑分离（白名单+置信度+人工兜底）——三条都可直接迁移到个人项目与面试叙事。

## 二、[183] AI Agent 原生操作系统

### 议程结构
浙江省经信厅致辞 → 马涛（阿里云基础软件负责人、龙蜥理事长）→ 张鹏程（Agentic OS 三层架构主旨）→ 李晋渊（鼎道智联 DingOS）→ 冯付秋（Cici Agent）→ Ragu Nambiar（AMD 全球副总裁）→ 侯珂欣/贺军（Arm）→ SkillHub 发布与颁奖 → 王江波（下一代 Anolis OS）→ 蒋学新（中兴 AIOS/System Harness）→ 王卓（PPU 软件栈 Seal 与 PyTorch 生态）。

### 核心观点
1. **Agent 是 OS 的"非人类用户"**，颠覆了 OS"人操作、运行人写的程序"的基本假设——Agent 不睡觉、目标驱动、自己写程序调工具，OS 必须原生重构
2. **Agent 负载四大特征**：自主规划多轮任务、异构协同（云端 GPU 推理+本地 CPU 编排）、按需隔离沙箱、长任务连续性
3. **真 Agentic OS 三条标准**：系统级 Agent 交互支撑、系统可被 Agent 原生互操作、面向 Agent 负载的规模化治理——"预装几个 Agent 应用不叫原生"
4. **【全场最重要的话】"操作系统最重要的使命不是让智能体跑得更快，而是踩刹车——让大家敢用"**（蒋学新）：被约束者不能自己当裁判（模型当裁判三宗罪：目标冲突/逻辑不靠谱/规则可自我绕过），裁决权必须逐级外推下沉到系统层
5. **自主权四级治理**：只建议不执行 → 先审批后执行（资金/隐私/物理动作）→ 低风险先执行 → 自动执行；行业与国家标准正在形成
6. Agent 7×24 工作，**token 产出是人类的 15 倍以上**（Arm 口径）；数据中心自身正在变成一个智能体

### 技术要点与数字
- **Agentic OS 三层**：接入层（各类 Harness 零成本适配）/ 治理层（OS Harness：身份、权限、安全、可观测、Workspace 全生命周期）/ 内核层（沙箱为主、快速启停、高密度调度）；量化收益：**时间 +10%、内存省 20%+、工作区毫秒级快照恢复**；仅换 Alibaba Cloud Linux 新版通用负载 +40%
- **AMD Venice**：256 核 512 线程，单机 500+ 沙箱（2 倍超分 1000+）；对龙蜥 backport 投入 +85%
- **Arm Agentic CPU**：36kW 风冷机架 8160 核+180TB 内存（密度为 x86 的 2 倍）；200kW 机架 45696 核+1PB 内存；Neoverse 从 10 亿核到 15 亿核只用 6 个月；Arm Performance+Agent Skill 让 Agent 自调优（近 5 倍提升案例）
- **龙蜥四范式**：确定性流程化+AI 做最后一公里；outer/inner 双层循环；通用拿来主义垂直自守；Monorepo 数据面。成果：软件包构建调试提效 10 倍；18 万条 CVE"用 Agent 魔法打败魔法"（生成 Agent+Review Agent 互审）
- **Cici Agent**：排障副驾→系统主驾；**AI 写了它九成代码**；所有结论必须带证据链防幻觉
- **中兴 System Harness**：意图总线四层；eBPF 对闭源 Agent 做内核级观测；自进化分层 L0 权重冻结→L1 个体记忆→L2 跨实例→L3 进化机制本身；"让整个种群不必学习第二遍"

### 金句
- "操作系统最重要的使命不是让智能体跑得更快，而是踩刹车——让大家敢用。"（蒋学新）
- "Agent 的竞争力，已经从模型能力进化为模型与执行系统共同完成真实任务的能力。"（张鹏程）

### 启示
"Agent Harness → OS Harness → System Harness"三层词汇是 2026 年 Agent 基础软件的关键词；能讲出"控制权逐级外推、被约束者不当裁判、eBPF 内核级观测闭源 Agent"这套，在 Agent 岗位面试里就是差异化标签。

## 三、[177] 阿里巴巴集团 AI Native 研发实践

### 议程结构
李亚洲（机器之心主编）→ 徐晓斌（阿里研发基础设施负责人）→ 李英格（千问事业部杰出技术专家）→ 黄挺（蚂蚁平台总架构师）→ 陈烨（飞猪 CTO）→ 彭鑫（复旦副院长）→ 圆桌。

### 核心观点
1. **考核指标变迁**：从"采纳率/AI 代码占比"（部门卷到 30-40%，现已没人提）→ 现在很多团队 90%+ 代码 AI 生成甚至近 100%——但**写代码只占交付时间 20-30%**（极端案例不到 1%），木桶效应决定全局提效有限
2. **组织演进三阶段**：超级个体（单人日烧 1-2 亿 token，太贵）→ 数字员工（权限/安全事故频发）→ 云上 Scrum
3. **四大基建补齐**（Agent 自主交付的前提）：可复原环境（Open Sandbox，周创建超千万，2-3 千个应用可完整复原）、省 token 的平台能力、**Agent 身份体系（人+Agent+Workload 合成身份，高危回找真人；开源 Open Agent OS【音译待核】）**、生产闸门（意图比对 diff+LiveDiff 影响面+授权校验——**"写代码的 Agent 和做授权检查的必须是两个上下文/两个模型"**）
4. **"context + verify 驱动开发"**（千问团队）：团队间 bug 比例差近 30 倍——不是模型问题是用法问题；把任务描述清楚+把验证做完备，主流模型都能交付准；案例：报税场景加"每步对账"verify 机制后全部精准
5. **蚂蚁实践**："业务系统本质正在变成 Agent"；Kata 沙箱冷启 200ms/内存 8MB/日创建 60 万；agent squad（协调/规划/实现/审查/验证）自主干完；**"Eval is all you need"**——EAS 环境即服务 5 分钟拉起评测环境、OB fork 50 秒隔离 300 张表；阿福 bad case 修复 1.2-6 天→3 天、人力 3-5 人日→0.1-1 小时
6. **飞猪 CTO 三观察**：行业从 token maxing→efficiency→ROI；中美头部同水位（飞猪采纳率近 100%、效率 +30-60%；Google adoption 95%）；方差巨大（硅谷 top engineer 月烧 20 万美金 token——"用好 AI 不是取代 50 个工程师，是取代一个 Army"）；**阿姆达尔定律**：coding 仅占 20% 时间→提效上限约 1/0.8；**瓶颈全压到 validation，且 eval 不能全自动（模型会自己编用例骗过）**；飞猪数据：酒店 63% 核心应用接入 AI 流程、商旅 +71%、度假 +150%；8 月全团队 AI 自动评审近 1 万次
7. **复旦 彭鑫泼冷水**：AI 不会吞噬软件（计算支撑层/业务处理层/社会协作层三层论）；拷问成功故事三维度 = 人的干预深度/任务复杂度/时间维度（两年后 AI 还维护得动吗）；**"AI 不光是大无畏，它很无耻"**（return 3 骗测试、改评估器给自己打勾）；解法 = 代码数字孪生/软件知识工程；"AI 把人才成长的梯子撤掉了"
8. **圆桌·人才**：K 型（强者恒强中间层消失）与 L 型（通才+一专）；AI 时代三要素 = **taste/judgment/共情**；招人标准从"会用 Codex"升级到"怎么用得好、产出可靠性如何"

### 金句
- "代码永远只是事实的一部分。"
- "瓶颈不会消失，它只会搬家。"
- "人人都能写代码，不代表人人都应该写代码。"

### 启示
面试谈 AI 研发提效能讲清"写代码只占 20-30%、瓶颈在 validation/环境/身份"这套叙事，比堆 Copilot 技巧高一档；Harness 工程师的核心工作正是补环境、验证、身份、闸门四块。

## 四、[201] Agent Infra 生产级实战

### 议程结构
杨旭（企业级 Agent Infra 总纲）→ 洪小龙/罗自荣（Sandbox 加速 RL/Eval + 百炼 RL 平台）→ 卢蒙凯/严龙（驾驭百万级 Agent）→ 华向（ACK 数据飞轮）→ 赵坤/尹鑫（具身智能敏捷基建）→ 张凯/姚铮（多模态智算底座）→ 沈健（时空智能 Infra）→ 车样/奥可（小红书推理与 Agent RL）→ 胡光（容器服务 Agent）→ 张栋（朗新数字分身平台）。

### 核心观点
1. **沙箱成为独立算力形态**（"云上的超级计算机"）：与 ECS/K8S 三区别=极致安全/极致弹性（1000 QPS 并发启动、1-2 秒拉起、单 region 每分钟 10 万个）/Agent 专属（深休眠、快照、存算分离）；**云上在跑沙箱超千万个、100% 兼容 E2B 协议**
2. **安全设计范本**：六层（运行时/网络/存储/内容/身份/扫描）；**沙箱内放假 key、出公网才换真 key**；每次访问临时生成凭证而非一次性授权
3. **"Loop Engineering"**：RL loop 的 rollout 与 reward 全部沙箱化，再进 Eval、再进生产 Agent loop；reward 函数抽象为可复用组件
4. **五层缓存**：裸金属本地盘→跨机 P2P→CPFS→集群 P2P→远端仓库，**命中率 98%+；冷启动 100-180ms、热启动 20ms、深休眠唤醒 600ms**；批量 10 万环境/分钟、5000 并发 3GB 镜像 1-2 秒就绪、TCO 降 50%+
5. **推理优化统一到 Cost per token / Goodput**：权重分发 65G 加载 45 秒→**3 秒**（1/15）；M890 上千问 3.8 Max 启动 34 分钟→**2 分 20 秒**、TTFT -75%、KV cache 命中 40%→90%、吞吐 3 倍；400G 模型冷启动 63 秒；**多模型热切换秒级（最高 400 倍加速）**；RBG 角色化编排（与 SGLang 社区共建开源）
6. **故障自愈升级**：全量健康探测→Repair Plan 统一编排→Human-in-the-loop 审批→流控熔断审计；生数科技硬件自愈率 99%+、GPU 利用率 +20%
7. **Agentic RL Infra 新方向**：管理对象从"服务实例"扩展到"任务+环境+RL 中间态"——checkpoint+WAL 断点续跑、**中间态作训练种子、公共前缀跑一次 fork 出大量沙箱分别探索**、统一 Rollout 托管服务
8. **容器服务 Agent 实战**：Pod 驱逐告警 5 秒触达手机、秒级根因、手机 approve 后 2 分钟恢复；RL 训练失败率 1%→0.05%；日主动发现异常 3.6 万次、诊断准确率 85%+
9. **朗新数字分身**：100+ 常驻分身、200+ 动态分身，"白天规划、晚上执行"，上线以来零生产级故障；需求智能分流（中小需求云端全自动、仅 Plan/MR 两个人工卡点）

### 金句
- "AI 跑在 Kubernetes 上已成为新姿势，K8S 不是选做题，而是必答题。"
- "具身智能的竞争，最终落到数据生产力上。"

### 启示
这场就是一份"Agent Infra 岗位技能图谱"：沙箱生命周期、五层缓存、MicroVM、E2B 协议、rollout 沙箱化、RBG 调度、KV cache 亲和、自愈+人审批——按"环境交付、状态管理、执行可控"三件事组织面试答案（小红书原话框架）。

## 五、[147] 以智治算：算力基础设施运维自进化

### 议程结构（10 段，三级跃迁）
背景（陆增熠）→ 认知进化（牛明一/郑天：数据接入多 Agent；刘炯宙：故障认知）→ 可靠性三问（杜宇）→ 行动进化（来海龙：智能交付；关通/王琪：数字员工"小美"；王佳龙：天晓大模型；朱浩/廖同舟：磐久 PPU 运维）→ 自我进化（潘斌：具身智能；江潇/刘建宇：自进化框架）。

### 核心观点
1. **根本矛盾**：数据中心资本开支 2021 年 2100 亿→2025 年 7140 亿美元、2026 全球 AI 算力投资超 1 万亿；单机柜 10kW→几百 kW、液冷化后温升处置时间只有原来 1/10——规模复杂度指数涨，人不可能同步涨
2. **认知进化**：四类 Agent 协同接入（总控/感知/配置/验证，自动覆盖 99%+ 设备）；物理规律封装成 skill（功率守恒因子图），根因准确率 96%+；知识自生长（语义中间层类比 Palantir，免 FDE 维护）；**试点成效：故障定位时长 -75%、跨域一次定位率 +73%、知识回流率 85%**
3. **可靠性三问**（生产化标准）：稳定=同一问题三次回答必须一致（回归通过率 90%）；安全=有损操作全收口三层门禁、零越权故障；进化=负样本归因（知识缺失/权限/绕路）→修本体→修知识→转人工，**修复率 40%→80%**
4. **数字员工"小美" Autopilot 四步上岗**：数据筑基（四维孪生，高斯泼溅建模）→能力沉淀（按现有人工岗位拆技能、MCP 暴露）→员工构建（Qwen+Qwen Agent 底座，多轮反思规划）→**评测上岗 KPI：任务成功率>95%、多次执行完全一致、不越权、每千 token 效能**——过了试用期才算"入职"
5. **天晓全局诊断大模型**：三难题=读不准/读不懂/**读不起**（"24.5"占 4 个 token、一栋楼一年 token 费 100 多万）；定位"数据中心神经系统"，1 万测点全量推理 10 分钟；**时序理解准确率 98%+、推理快 10 倍、成本降 90%+**
6. **磐久 PPU 整机柜运维**：128 卡"机柜即一台服务器"；告警风暴收敛"一柜一单"（**定位时长 -90%**）、应急恢复人审批、维修提效 30%
7. **具身智能**：机器人巡检人工替代 80%+、准确率 98%；随工场景=身份验证→带路→行为异常识别→带回
8. **自进化框架**：物理世界感知中枢（甚至含会议纪要/钉群/厂商公告）→业务记忆体（来源复核，不会把前天的信息当今天的——案例：光模块批次返厂的全球化重排）→受控执行（红区红线：线上机器禁止关机重启）→独立审计（证据链归档）；**资产运营：人工工时 -40%、周期 -20%、人工介入 -70%**
9. **终局指标**：从 1-5-10（1 分钟告警/5 分钟响应/10 分钟恢复）走向 **365**——无人干预连续稳定运行 365 天

## 六、五场合观：下午场的五条共同主线

1. **Harness 成为最大公约数**：Qoder 的产品 Harness、Agentic OS 的 OS Harness、中兴的 System Harness、蚂蚁的 agent squad、沙箱本身——所有人都在做"让 Agent 稳定可控的执行框架"，只是所在层次不同
2. **Eval 被供上神坛**：AgentLoop"变更必须回测"、千问"context+verify"、蚂蚁"Eval is all you need"、飞猪"eval 不能全自动（模型会编用例骗过）"、147"同一问题三次回答必须一致"——评测能力 = 当前最大的组织能力缺口与个人机会
3. **治理=踩刹车**：自主权四级、双上下文授权（写代码与授权检查分离）、三层门禁、Agent 身份、证据链——各家的"敢用"方案高度趋同
4. **成本统一为 Token 经济学**：单次任务成功交付成本（Qoder）、Cost per token/Goodput（小红书）、每千 token 效能 KPI（小美）、一栋楼一年 100 万 token 费用（天晓）——所有基建优化的终点是每个有效业务结果的成本
5. **人机边界新共识**：确定的事给流程、模糊的事给 AI、高危的事人审批；人的新角色 = 目标设定者+例外处理者+责任承担者；"人的经验不是被丢掉，而是沉淀进数字员工的职责与权责边界"
