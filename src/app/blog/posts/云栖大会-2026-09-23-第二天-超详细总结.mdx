## 一、[231] 无法计算的价值主论坛

> 转写稿不完整（从首场演讲中段开始）。论坛按"共生→共治→共善"三篇章推进，主题是 AI 与真实场景的"双向奔赴"。

- **整体主题**：技术只是起点，回应真实需要才是"无法计算的价值"。
- **议程与要点**：
  1. **脑机接口**（华中科大同济医院 廖家智【音译待核】）：博睿康获国内首个植入性脑机接口产品批文；湖北/上海率先将脑机接口纳入医保；与阿里共建国家级脑机接口高质量数据集（亿元级、10 类疾病、30 个场景）；获教育部首批"脑科学与脑机接口"一级学位授予权。伦理追问：数据归属、千人脑电同步采集的越界问题。
  2. **清洁能源 × AI**（阳光电源 赵维【音译待核】）：十大趋势——算力追着绿电跑、智算中心 800V 直流化（端到端效率 94%）、SST 固态变压器成独立产业、AI 进电力电子设计（周期缩至 1/3）、构网型控制（2027 批量出货）、数字孪生全生命周期、长时储能（铁空气/氢能/SOFC）、算电协同调度。**2030 年算力用电约 8000 亿度 ≈ 全国发电量 6%**。
  3. **圆桌"小县城遇见大模型"**（平顺/佛坪/嵋泗三县）：AI 平顺使用 8 万人次；达医智影多癌早筛嵌入县医院 CT（服务 5800 人次）；嵊泗 AI 船票智能体使用率超 50%、"手搓"应用超 100 个。方法论："三个缩短"（服务距离/时空协同/专业知识距离）；"公务员不需要会写代码，但要会当出题人"。
  4. **AI 育种**（先正达 谢旗【音译待核】）：育种周期 10-15 年缩短一半；品种亩产 937.46 公斤；用 AlphaFold 定位抗寄生关键位点；千问大模型建育种系统。
  5. **少年云公益**：5 年 400+ 所乡村小学云教室、40 万师生受益。
- **金句**："过去比谁的脑机接口做得好，像王子拿水晶鞋找灰姑娘；未来要为每个人设计合脚的鞋。"

## 二、[187] 阿里云 AI 游戏行业论坛

- **整体主题**：AI 从"游戏提效工具"（AI for game）走向"拿掉 AI 核心体验就不成立"（AI Native Game）。
- **议程与要点**：
  1. **《星布谷地》ANPC 生态**（李嫣然【音译待核】）：基于脑认知的统一 Agent 架构（决策中枢+注意力+行动层）；**行业内首个玩家可保留的 NPC 持久记忆**（已第三次测试、支持跨平台）；多教师蒸馏把安全/逻辑/人设/共情蒸进同一模型；强化学习用分级混合奖励；NPC 自进化（咖啡店主理人客流下降会主动营销）。
  2. **AI Native 游戏判据**（三石 Lab 钱看山【音译待核】）："把 AI 相关的东西全拆掉，核心体验还成立吗？"《魅居物语》让 AI 生成改变世界状态：关系可积累、UGC+AIGC 共创、角色主动找玩家；管线五步=输入→上下文组装→AI 决策→状态落库→记忆回写；自研 Harness（转写"哈尼思"）做情绪→动作→节奏→降级调度；捉宠陪玩灰度日 DAU 峰值 10 万。
  3. **TapTap 制造**（赵天一）：自然语言→游戏全流程；上半年上线 5002 款游戏（去年同期 503，+800%）、1100 万玩家游玩；自建私有 benchmark（真实生产题目+引擎实跑判分）；过去三个月开发者用千问产生万亿级 token。
  4. **圆桌"管线无人化之后谁还稀缺"**：网易/诗悦/畅游共识——最稀缺的是人（学习成长的人、"心态年轻"的人、3-5 人无短板小组）；"AI 是放大镜：你偷懒它放大偷懒，你有诚意它放大诚意"。
  5. **阿里云游戏方案全景**（黄志东）：四层架构，**Agent Infra 层**（Agent Core/Sandbox、AI 网关、安全护栏、观测评估）为行业首发提法；AI 玩法四痛点=成本（模型分层 Flash 优先）/时延（千问 Audio realtime 首音节百毫秒）/安全/Agent Loop 治理。
- **对读者的启示**：魅居的 Harness 五步管线 + 记忆重要度/优先级设计，是 Agent 记忆与编排进 C 端产品的完整面试案例。

## 三、[199] AI 时代的可观测与智能开发运维（本行重点）

- **整体主题**：阿里云发布 AgenticOps 全家族（AgentLoop、SOPS、云效研发智能体），核心论证：**Agent 时代的运维竞争力不在模型，而在数据飞轮与标准化工程底座**。
- **议程与要点**：
  1. **AgentLoop·Agent 评估与数据飞轮**（夏明【音译待核】）：LM Judge/Code Judge 评不准——必须挂载私域 Skill/工具，评估"说与做一致性"（客服说找到货源但工具调用失败）；评估有效率经头部客户验证 90%+；**变更必须回测，否则是盲猜**。
  2. **SkillOps**（凌越科技）：Skill 是 AI 时代的 SKU——四大广场+六阶段闭环（发现→创建→发布→采集→评测→迭代）；无感采集（本地 hook 0 埋点+PII 脱敏）→归因打标（低置信度宁缺毋滥）→黄金子集→双轨评测（生产增量按天+离线实验发版卡点）×三维指标（正确性/增益/成本）×分级门禁；demo：skill 迭代后增益 87%。
  3. **SOPS 全域智能运维平台**（阿里云，新发布）：Connect 统一跨云/IDC 连接 + Fabric 语义建模；诊断=假设驱动验证；**长期任务→Findings→经验沉淀**闭环；高危操作三层门禁（权限/状态/影响面）+强制拦截+全程审计。
  4. **吉利"1530"实践**（1 分钟发现/5 分钟定位/30 分钟恢复）：六大根因归纳为数据/关联/智能三缺失；凌晨 1 点攻防演练直接打挂生产应用；**成效：MTTR 提升 7 倍、效率 15 倍、查询 20 倍、告警准确率至 70%**。
  5. **云效研发智能体**：云端数字分身（权限=你的权限）覆盖需求→编码→CI 排查→评审→验收（shell+Playwright）→发布风险对比；定时任务+事件触发自主工作。
  6. **开源体系**：OBI（eBPF 无侵入采集，自动识别 OpenAI/千问协议、工具调用、MCP、RAG embedding）；Agent 语义规范（entry span/step span/skill 规范）；UModel 语义建模（不同模型诊断质量 +50%~100%）；BRISE 评测体系（故障注入/被测 Agent/评分三分离，RC 100/200 数据集）。
- **金句**："谁的数据飞轮转得更快，谁就比对手跑得远"；"Skill 是企业真金白银的 knowhow，没有数据指引，AI 落地就是开盲盒"。
- **对本行的直接启示**：①给运维自动化建"双轨评测+归因数据集"；②token 消耗按 skill/场景归因进仪表盘；③高危操作三层门禁是最小安全框架。

## 四、[147] 以智治算：算力基础设施运维自进化（本行重点）

- **整体主题**：算力运维"认知进化→行动进化→自我进化"三级跃迁；根本矛盾=规模复杂度指数增长 vs 人力不增长。
- **议程与要点**（10 段）：
  1. **背景**：数据中心资本开支 2021 年 2100 亿→2025 年 7140 亿美元、2026 年全球 AI 算力投资预计超 1 万亿；单机柜 10kW→几百 kW、风冷转液冷、温升处置时间只剩原来 1/10。
  2. **数据接入多 Agent**：总控+感知+配置+验证四类 Agent 协同，自动覆盖 99%+ 设备接入；物理规律封装成 skill（功率守恒因子图），根因定位准确率 96%+。
  3. **知识自生长**：多源→"实体关系+时序+来源"语义中间层（类比 Palantir）；混合召回+溯源；知识进化环免 FDE 维护。
  4. **故障认知**：时空对齐+多假设推演把孤立告警串成故障链（制冷共控失效案例逐帧复盘）；**试点成效：故障定位时长 -75%、跨域一次定位率 +73%、知识回流率 85%**。
  5. **可靠性三问**：稳定（同一问题三次回答必须一致；回归通过率 90%）、安全（有损操作全收口，零越权故障）、进化（负样本归因→修本体/修知识→转人工；**修复率 40%→80%**）。
  6. **智能交付**：AI 图纸设计（十几分钟出最优方案、SLA 提速 40+ 天）、AI 质检（30 秒出清单）、机柜录入（1 分钟 100% 准确）；沉淀 1900 项知识、人机协作 3 倍、100 天交付。
  7. **数字员工"小美" Autopilot 四步上岗**：四维孪生底座（含高斯泼溅三维实景）→按岗位拆技能（MCP 暴露）→对标真实岗位装配（Qwen+Qwen Agent 底座）→**试用期 KPI 考核后上岗**（成功率>95%、多次执行一致、不越权、每千 token 效能）。
  8. **全局诊断大模型"天晓"【音译待核】**：1GW 资产价值从 100 亿升至 500 亿美金；三难题=读不准/读不懂/**读不起**（"24.5"占 4 个 token，一栋楼一年 token 费用 100 多万）；天晓=数据中心神经系统，1 万测点全量推理 10 分钟；**时序理解准确率 98%+、推理快 10 倍、单次全量推理成本降 90%+**。
  9. **磐久 PPU 整机柜运维**：单机柜 128 卡"机柜即一台服务器"；告警风暴收敛"一柜一单"（**定位时长 -90%**）、应急恢复人审批、维修提效 30%。
  10. **具身智能+自我进化框架**：机器人巡检人工替代 80%+、准确率 98%、本财年覆盖 20 栋楼；资产运营场景**人工工时 -40%、周期 -20%、人工介入 -70%**；终局指标"从 1-5-10 走向 365"（无人干预连续稳定运行 365 天）。
- **金句**："人的经验并没有被丢掉，而是被沉淀到了数字员工的职责、能力和权责边界里"；"最怕系统流程被人接管——人往往会成为流程的瓶颈"。
- **对本行的直接启示**：①天晓的"廉价 Data Loop 先筛征兆、贵推理留给 Agent Loop+记忆体去重"是 token 成本工程范式；②数字员工"试用期 KPI 四指标"可直接移植为自动化上线准入；③认知→行动→自进化是个人运维体系的演进地图。

## 五、[181] Qoder：AI Coding 赋能超级个体

- **整体主题**：Qoder 从编程工具升级为"面向所有人的 Agentic Coding 平台"，统一 Harness 支撑 IDE/CLI/云端 Agent/数字员工/移动端五形态，让"AI 执行、人思考"成为新工作方式。
- **议程与要点**（10 段）：
  1. **总纲**（谢吉宝【音译待核】）：30% 用户已是非程序员、超 50% 任务非传统编程、**80% 的人不再亲自写代码**；编程/通用双模式；Agent Teams（Leader 拆解分派子智能体）；生态 150+ 连接器/70+ 插件/**2 万+ Skills**；工程知识引擎（Repo Wiki 以代码为唯一事实来源）；安全左移 L1-L4（检测 180 万次、修复 5.8 万漏洞、修复率 55%→90%）；Cloud Agents 服务 10 万+ Agent；数字员工 Qoder Wake（2000 家企业、部分场景 10 倍提效）；企业落地"四可信"（身份/模型/数据/运行）。
  2. **五人七天造出 Qoder Work 的复盘**（谢文欣【音译待核】）："AI 放大实现能力，却不自动放大共识能力"——解法=人定架构协议→共识写进 AGENTS.md→E2E 测试兜底。
  3. **管家婆案例**（李玉忠，31 年 ERP 老厂）：45 岁资深开发者 7 个月独立完成企业级 AI MES——600 次提交、**110 万行代码**；五层打法=Rules 硬约束/项目级 Skill/记忆分层/子代理/定期知识重构；"前期两版只有代码没有文档，推倒重来"。
  4. **CLI 三形态**：TUI（多 Agent/goal 模式/loop 循环修正）、Headless（-p 接 CI/CD/评审/安全扫描）、Agent SDK（联想天禧/新东方基于它做产品）；北极星指标"**单次任务成功交付成本**（token+时间+人工介入）"。
  5. **值班 Agent"小K"**（阿里云云备份）：自动处理 95% 工单告警与巡检；"做厚知识、做薄 Skill"；知识底座纯 Git 管理；工单双轨（确定性走代码=绿色、模糊判断走 CLI=蓝色），独立审核 Agent 打回重写；超时硬打断先输出现场影响面。
  6. **数字员工工程化**：真实工号+独立权限；工位=第二台电脑；录制学习把"人脑里的流程"变 skills；"程致远"月度成绩单：3000+ 任务**成功率 98.9%**。
  7. **圆桌**：清华博士生两天做心理疗愈游戏；淘宝客户端 Harness+Loop Engineering 九环节流水线、3-4 人日需求 50 分钟跑完。
- **金句**："代码可以自动生成，但共识不会自动生成"；"AI 的上限取决于你为它建立的纪律和记忆"；"我是一个人，但我是一支团队"。
- **对读者的启示**：①Harness 是 AI Coding 公司的核心技术资产，"单次任务成功交付成本"是 Harness 设计的目标函数；②生产级 Agent 三件套=共识工程（AGENTS.md）+验证闭环（E2E+审核 Agent）+手脑分离（白名单+置信度+人工兜底）；③"做厚知识、做薄 Skill"与知识一级/二级公民分级是记忆设计范式。

## 六、[183] AI Agent 原生操作系统

- **整体主题**：Agent 是 OS 史上第一个"非人类用户"，OS 必须从"给人用"重构为 **Agent First**——向下优化内核释放算力，向上提供 Harness 级治理让大家敢用。
- **议程与要点**（11 段）：
  1. **马涛**（阿里云基础软件负责人、龙蜥理事长）：龙蜥已捐赠开放原子基金会；提出 **System for AI 与 AI for System 双向创新**。
  2. **Agentic OS 三层架构**（张鹏程【音译待核】）：接入层（各类 Agent Harness 零成本适配）/治理层（OS Harness：身份、权限、安全、可观测、Workspace）/内核层（沙箱为主、快速启停、高密度调度）。收益：**10%+ 时间提升、20%+ 内存节省、工作区毫秒级快照恢复**；判断真 Agentic OS 三条标准（系统级 Agent 支撑/系统可被 Agent 互操作/规模化治理——"预装几个 Agent 应用不叫原生"）。
  3. **Agent 负载四大特征**：自主规划多轮、异构协同（云端 GPU 推理+本地 CPU 编排）、按需隔离沙箱、长任务连续性。
  4. **中兴 System Harness**（蒋学新）：**"OS 最重要的使命不是让 Agent 跑得更快，而是踩刹车——让大家敢用"**；被约束者不能自己当裁判（模型当裁判三宗罪：目标冲突/逻辑不靠谱/规则可自我绕过），裁决权必须逐级外推到系统层；意图总线四层；自主权四级（只建议→审批后执行→低风险先执行→自动）；eBPF 对闭源 Agent 做内核级观测。
  5. **AMD/Arm**：Agent token 产出是人类的 15 倍以上；AMD Venice 256 核单机 500+ 沙箱（2 倍超分 1000+）；Arm 36kW 机架 8160 核+180TB 内存（密度为 x86 2 倍）；Arm Performance+Agent Skill 让 Agent 自己做性能调优（实测近 5 倍提升）。
  6. **龙蜥研发四范式**：确定性流程化+AI 做最后一公里；outer loop（事件喂 subagent）+inner loop（单点深钻）；通用能力拿来主义、垂直领域自守；Monorepo 数据面。成果：两三千个软件包构建调试提效 10 倍；18 万条 CVE"用 Agent 魔法打败魔法"（生成 Agent+Review Agent 互审，人只兜底）。
  7. **Cici Agent**：系统排障数字员工（排障副驾→系统主驾），覆盖稳定/安全/发行版专家，所有结论必须带证据链防幻觉。
- **金句**："如果大模型拓展了智能的边界，操作系统要解决的是让智能稳定、高效、安全地服务千行百业"；"操作系统的第一性使命变了：不是跑得更快，而是踩刹车"。

## 九、[201] Agent Infra 生产级实战

- **整体主题**：阿里云 Agent Sandbox 品牌发布后首次成体系实战汇报——沙箱、RL 训推、容器智算调度、推理加速与故障自愈，主线是"从有没有算力到同样算力产生多少有效业务结果（**Goodput**）"。
- **议程与要点**（10 段）：
  1. **企业级 Agent Infra 总纲**（杨旭）：五大领域=环境（沙箱）/上下文（Memory/RAG）/工具（Skills/MCP）/安全/模型；**云上在跑沙箱超千万个、并发创建 10 万/分钟、无预热 1 秒启动、100% 兼容 E2B 协议**；沙箱内放假 key、出公网才换真 key；每次访问临时生成凭证。
  2. **Agent Sandbox 加速 RL/Eval**（洪小龙等）："Loop Engineering"=RL loop 的 rollout 与 reward 都跑在沙箱；5 分钟开箱、批量 10 万环境/分钟、5000 并发 3GB 镜像 1-2 秒就绪、**TCO 降 50%+**；百炼企业级多租户 Agent RL 平台（训得了/训得起/训得好）。
  3. **驾驭百万级 Agent**（卢蒙凯等）：沙箱="云上超级计算机"，与 ECS/K8S 三区别（极致安全/极致弹性/Agent 专属深休眠快照）；**五层缓存命中率 98%+；冷启动 100-180ms、热启动 20ms、深休眠唤醒 600ms**；三层隔离（身份校验/凭证不落沙箱/记忆按身份加载/出网黑白名单）；回收策略=临时任务用完即毁、会话沙箱闲置→深休眠→再释放。
  4. **具身智能数据闭环**（智元蜜蜂）：ACK+Argo 压测峰值 1.6 万 Pod 并行、日调度 10 万工作流、调度 \<50ms；2026 年目标千万小时数据产能。
  5. **容器智算底座**（张凯等）：M890 超节点（64 卡、卡间 800G）拓扑感知调度+RBG（与 SGLang 社区共建）；千问 3.8 Max 启动 34 分钟→**2 分 20 秒**、TTFT -75%、KV cache 命中 40%→90%、吞吐 3 倍；故障自愈=健康探测+Repair Plan 编排+Human-in-the-loop+熔断审计；**提出 Goodput 指标**；400G 模型冷启动降到 63 秒；多模型热切换秒级（最高 400 倍加速）；生数科技：硬件故障自愈率 99%+、GPU 利用率 +20% 成本 -15%。
  6. **小红书实践**（车样/奥可）：北极星指标 **Cost per token**；权重分发 65G 加载 45 秒→3 秒（1/15）；InferenceKit 三级注入零代码（Agentic coding 吞吐近 3 倍）；推理网关 TTFT -75%、吞吐 3 倍；**Agentic RL Infra：checkpoint+WAL 断点续跑、中间态作训练种子、公共前缀 fork 出大量沙箱分别探索**；统一 Rollout 托管服务。
  7. **容器服务 Agent**（胡光）：基于 Agent Harness 的 K8S 运维 Agent——Pod 驱逐告警 5 秒触达手机、秒级根因、手机 approve 后 2 分钟恢复；RL 训练失败率 1%→0.05%；日累计主动发现异常 3.6 万次、诊断准确率 85%+。
  8. **朗新科技**（张栋）：从 vibe coding→SDD（Spec 驱动）→云端数字分身平台；四层架构（沙箱底座/CLI 运行时/资产层/执行层）；需求智能分流（中小需求云端全自动仅两个人工卡点）；**100+ 常驻分身、200+ 动态分身，上线以来零生产级故障**；愿景"白天规划、晚上执行"。
- **金句**："AI 跑在 Kubernetes 上已成为新姿势，K8S 不是选做题而是必答题"；"具身智能的竞争，最终落到数据生产力上"。
- **对读者的启示**：这场几乎就是"Agent Infra 岗位技能图谱"——沙箱生命周期/五层缓存/MicroVM/E2B 协议/rollout 沙箱化/RBG 调度/KV cache 亲和/自愈+人审批；记住关键数字（冷启 100-180ms、热启 20ms、10 万沙箱/分钟、400G 模型 63 秒）可直接用于技术对谈。

## 十、九场合观：今天大会的六条暗线

1. **Harness 全线升维**：从 prompt 编排（Qoder）→ OS Harness（183）→ System Harness（中兴）——"让 Agent 稳定、可控"成为与"让模型更聪明"并列的主战场
2. **评测（Eval）被供上神坛**：AgentLoop 双轨评测、百炼"Eval is all you need"、飞猪"eval 不能全自动（模型会骗过）"、172 峰会"换 harness 同模型差 10 分"——**评测工程是当前最大的人才缺口**
3. **成本叙事统一到 token 经济学**：Cost per token、Goodput、"单次任务成功交付成本"、天晓"一栋楼一年 100 万 token 费用"——所有基础设施优化的终点是每个有效业务结果的成本
4. **运维范式更替完成**：从"人盯告警"到"Agent 值守+人审批高危"（吉利 1530、容器服务 Agent 5 秒触达、天晓 365 天无人干预）——运维人转型方向=训练运维 Agent+定 KPI+审计
5. **沙箱成为新算力形态**：千万级在跑、10 万/分钟创建、深休眠、RL rollout 全沙箱化——"Agent 的专用云"已经从概念变成营收
6. **人机边界共识**：确定的事给流程、模糊的事给 AI、高危的事人审批（自主权四级）；人的新角色=目标设定者+例外处理者+责任承担者
