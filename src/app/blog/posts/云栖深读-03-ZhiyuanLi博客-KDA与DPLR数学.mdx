## 《KDA（Kimi Delta Attention）的数学原理：从矩阵乘法到 Affine 变换》（02-17，2952 字）

**动机**：softmax 注意力 O(N²) 且要缓存全部历史 KV；线性注意力换成固定大小状态矩阵 S，O(N) 复杂度 + 常数显存，推理期无增长的 KV Cache。

**KDA 三要素**：Delta Rule（只按预测误差更新状态）+ 逐维衰减（向量值遗忘率，推广 GDN 的标量衰减）+ chunk-wise 并行训练。

**推导骨架**：三个引理（外积累积=矩阵乘法 / 下三角矩阵求逆 / 衰减对数分解）→ WY 表示解耦状态依赖的残差 → 核心定理：**一个 chunk 的状态更新是仿射映射 S′ = M·S + B**。

**并行的根基**：仿射映射可复合——多卡（Context Parallel：AllGather + 前缀扫描）与单卡（SM-parallel 子序列切分）都建立在复合性上。

## 《DPLR（Diagonal Plus Low Rank）的数学原理》（02-21，1892 字）

**定位**：广义 Delta Rule 变体，转移矩阵**显式**给出：P_t = diag(exp(g_t)) + b_t aᵀ（对角衰减 + rank-1 更新）。目标同样是把 O(t) 顺序递推变成 chunk-wise 并行。

**关键结果**：
- 乘积封闭性：累积转移 P_\{t:1\} 保持"对角+低秩"结构（引理 2）
- WY 表示定理的推广：P_\{t:1\} = 纯对角累积衰减 + Σ(衰减 b_i)·(递归权重向量 w_i)ᵀ；矩阵形式 W=(I+A_ab)⁻¹A^gate、U=(I+A_ab)⁻¹A_ak·V，其中 A_ab/A_ak 是严格下三角注意力型矩阵
- Chunk 末状态 S′ = M·S + B：M = diag(exp(g_last)) + B_decayedᵀW，B = K_decayedᵀV + B_decayedᵀU；chunk 输出 = QS + 两个 masked 注意力项
- 工程细节：下三角求逆 O(C³)、相对衰减 exp(−g+g_last) 保数值稳定、fp32 计算 bf16 存储

**统一框架（本篇最有价值的视角）**：IPLR（无衰减，Identity+LowRank）⊂ KDA（隐式 Delta 残差，减号）⊂ DPLR（显式对角+低秩，加号）——三者都是仿射变换，同一套并行框架通吃。实现基于 Flash Linear Attention（FLA）框架。

**与 RWKV-7 的关系**：RWKV-7 的 Dynamic State Evolution 是 DPLR 的实例化；理论上模拟梯度下降更新，表达力声称超出 TC0（Transformer 电路复杂度类）达 NC1。

## 我的扩展

1. **这条线的家谱**：Linear Transformer(2020) → DeltaNet(2021, 误差修正思想) → GDN(2024, 标量门控衰减) → KDA(2025, 逐维衰减, Kimi Linear 采用) / RWKV-7(2025, DPLR 实例)。共同基因="用可并行训练的状态机替换 KV Cache"。
2. **为什么"显式 vs 隐式"重要**：隐式（KDA）chunk 形式更省算；显式（DPLR）表达力强但要多存中间变量（HBM 压力）——数学结构与显存带宽的 trade-off 直接写在公式里，这是"算法=硬件预算"的教科书案例。
3. **与 Marconi（03 文件）的呼应**：混合架构（线性层+全注意力层）正是 Marconi 要解的缓存难题的来源——这两篇数学文解释"为什么混合架构省 KV"，Marconi 解释"混合架构怎么缓存"，一币两面。
4. **进一步阅读**：Kimi Linear 论文 arXiv:2510.26692；FLA 框架 github.com/fla-org/flash-linear-attention；RWKV-7 论文（Delta Rule 的 NC1 表达力论证）。
