# 神经网络江湖前传：从感知机到 Transformer 之前（及败给它的对手们）

> 2026-09-23。承接"KV Cache 与注意力机制"的讲解——注意力 2017 年登场前，语言建模的主角是 RNN 家族；本文把整个"NN（神经网络）家族谱系"理一遍：谁在什么时候登场、强在哪、死在哪。
> 收录于 03-resources/references/2026云栖大会/。

## 序章：什么是"NN"（神经网络）

**神经网络 = 一堆简单的数字运算单元分层连接，通过调参数学会输入到输出的映射。**

最小单元是"神经元"：把几个输入乘上权重、加总、过一个非线性函数，输出一个数。单个神经元什么都干不了，但**亿万个神经元分层堆起来**，就能逼近几乎任何复杂函数——这是 1943 年就有的思想（McCulloch-Pitts 神经元），比计算机普及还早。

关键洞察只有一条：**"学"= 看大量例子，猜答案，错了就把每个权重往"错得更少"的方向微调一点**（反向传播，1986 年LeCun/Bengio/Hinton 他们复兴的方法）。这套"调参学艺"的范式一直没变，变的是**网络的结构**——结构决定了它适合处理什么形态的信息。下面按信息形态过一遍整个家族。

## 一、按"数据形态"分的 NN 家族

### 1. 全连接网络（FC / MLP，多层感知机）——始祖

- **年代**：1958 感知机 → 1986 多层复兴
- **处理什么**：固定长度的向量。输入 10 个数、输出 2 个数这种。
- **结构**：每层的每个神经元连接上层的每个神经元。
- **强项**：万能函数逼近器，简单直接。
- **死穴**：①参数爆炸（1000×1000 的全连接就是 100 万连接）；②**没有"结构先验"**——它不知道输入是图像还是文本，全部当数字堆处理；③根本无法处理变长序列。
- **现状**：没有独立处理过任何大任务，但**活在所有架构的夹层里**——Transformer 的 FFN 层本质就是 MLP。
- 锚点：**万能但没特长的"普通工人"**。

### 2. CNN（卷积神经网络）——图像王朝的建立者

- **年代**：1998 LeNet → 2012 AlexNet（ImageNet 一战封神）→ 2021 被 ViT 逼宫
- **处理什么**：图像、空间结构数据。
- **核心思想**：**小窗口滑着看**。一个 3×3 的小滤镜在整张图上滑动扫描，每个位置执行同样的运算——"滤镜"就是卷积核。
- **为什么牛**：①**参数共享**：一个 3×3 滤镜只有 9 个参数，却能扫全图——参数量暴跌；②**平移不变性**：猫在左上角还是在右下角，滤镜都能认出来；③**层级抽象**：浅层滤镜认边缘 → 中层认纹理 → 深层认"猫耳朵""狗鼻子"→ 顶层认"这是一只猫"。
- **历史地位**：2012-2021 图像识别的绝对霸主，AlphaGo 的棋盘网络也是 CNN。**它证明了"结构先验 + 参数共享"的威力，这套思想后来被 Transformer 全盘继承。**
- **败给谁**：ViT（Vision Transformer）——把图像切成 16×16 的小块当 token 喂 Transformer，发现"喂够数据，无结构先验反而更强"。CNN 的归纳偏置从优势变成了枷锁。
- 现状：小数据/边缘设备/实时检测（YOLO）仍是 CNN 地盘。
- 锚点：**拿放大镜逐块扫描图片的侦探**。

### 3. RNN（循环神经网络）——序列的旧王（本文主角的对手）

- **年代**：1990s 概念 → 2013-2017 王朝（LSTM/GRU 时代）
- **处理什么**：**序列**——文本、语音、时间序列，以及一切"有先后顺序"的数据。
- **核心思想**：**读一个字，更新一次记忆，把记忆传给下一步**。

```
h₁ = f(x₁, h₀)     读"我"，形成初始理解 h₁
h₂ = f(x₂, h₁)     读"爱"，结合之前的理解 → h₂
h₃ = f(x₃, h₂)     读"北"，……
```

h 是"隐藏状态"（hidden state），**一个固定长度的向量，就是模型对"到目前为止读到的一切"的压缩记忆**。理论上这个记忆可以无限传下去，任意长的序列都能处理。

- **为什么会赢过当时的所有对手**：①**天然处理变长**——句子多长就读多长；②**有顺序感**——"我打你"和"你打我"读进去的记忆更新顺序不同；③**参数共享**——每一步用同一套权重；④当时没有更好的选择。
- **两大死穴**（这就是注意力 revolution 的起点）：

  **死穴一：传话游戏（长程遗忘）。** 记忆是不断压缩传递的，h₅₀ 里 h₁ 的信息已经被稀释了 N 轮。数学上表现为**梯度消失/爆炸**——训练信号从第 100 步传回第 1 步，一路上不断乘以小于 1 的数，传到头就没了。句子超过几十字，开头基本白读。

  **死穴二：串行诅咒。** h₅₀ 必须等 h₄₉ 算完——**一步依赖一步，GPU 几千个核只能用一个**。训练 GPT 量级的语料（万亿 token）在 RNN 上需要的时长是天文数字。

- **两个著名的续命尝试**（都失败了，但失败得很有价值）：

  **LSTM（Long Short-Term Memory，1997）**：给记忆加了"门控"——遗忘门（该忘的忘）、输入门（该记的记）、输出门（该说的说），用三条通道分别管理长期记忆、短期记忆和输出。缓解了梯度消失，把有效记忆从十几个字拉长到上百字。**2013-2017 年机器翻译、语音识别的霸主，Google 翻译 2016 年的底座就是它。** 但门控只是续命，串行问题一个字没解决。

  **GRU（2014）**：LSTM 的精简版，两个门代替三个门，效果接近速度快一截——王朝末期的性价比优化。

- **怎么死的**：2017 年《Attention Is All You Need》。注意力让每个字**一步直达**任意历史（不用传话），**全并行**（不用串行）。两个死穴被一次性解决，RNN 王朝三年内终结。2017 年之后新训练的语言模型几乎无人再用 RNN。
- 锚点：**传话游戏里疲惫的信使——接力传话，传到远处话就变了，还只能一个接一个慢慢传**。

### 4. 其他按数据形态分的家族（快速过）

- **R-CNN / YOLO 系**：CNN 的"目标检测"特化（不只认图，还要框出物体位置）。YOLO 至今是实时检测之王。
- **GAN（生成对抗网络，2014）**：两个网络对抗——生成器造假币、判别器验钞，互相进化。2014-2021 图像生成之王（deepfake 就是它）。死因：训练不稳定、模式坍塌（只会生成几种脸），被扩散模型全面取代。
- **Autoencoder / VAE**：压缩再重建，学数据的"精华编码"。VAE 至今活在扩散模型管线里（潜空间的压缩器）。
- **GNN（图神经网络）**：处理"图结构"数据——分子结构、社交网络、推荐系统。一直没大出圈但在化学/推荐领域活得好。
- **强化学习网络（DQN/PPO）**：AlphaGo 的另一半；今天大模型 RLHF/GRPO 训练用的就是它的现代版。
- 锚点速记：**CNN 侦探（放大镜扫图）、GAN 造假币的与验钞的、VAE 压缩大师、GNN 社交网络分析师**。

## 二、Transformer 赢家通吃之后（2021-2026 的"新江湖"）

注意力统一江湖的过程分两步：**先吃掉语言（2017），再吃掉图像（2021 ViT）**。之后所有新架构都在"注意力母体"上改造，江湖变成三条战线：

### 战线一：改良 Transformer（主流正营）

- **稀疏注意力 / 滑窗 / FlashAttention**：注意力 O(N²) 的计算/显存账太贵 → 少看点、算快点、省着存。
- **MoE**：每个 token 只叫醒部分专家 → 大容量低成本。
- **MLA / KV 量化**：攻 KV Cache 显存账。
- 这条线就是你前面那两场云栖演讲的全部内容——**今天的工程创新 90% 发生在"改良注意力"上**。

### 战线二：彻底替换注意力的挑战者（线性注意力复兴）

- **逻辑**：注意力的平方级账单是原罪；RNN 的"固定状态"思路其实没死——只是当年的 LSTM 记忆更新太笨。用可学习的、数学上可并行的状态更新重做一遍：
- **谱系**：Linear Transformer（2020）→ S4/Mamba（2021-2023，状态空间模型，选择性机制）→ RWKV（2023-2025，RNN+Attention 杂交）→ **Gated DeltaNet → KDA/Kimi Linear（2025）**。
- **现状**：Kimi Linear 论文证明混合架构（KDA 线性层 + MLA 层）**同配方下全面超过纯注意力，KV 省 75%、1M 上下文解码快 6 倍**——这是 2017 年以来第一次有架构在公平比较下正面击败全注意力。RWKV-7 理论表达力超 TC0 Transformer。
- **判词**：不是"回到 RNN"，而是**"RNN 的状态思想 + Transformer 的并行训练数学"的合体**。你拍的演讲里 Reference 页那篇 KDA 数学博客，正是这条战线的核心理论。

### 战线三：非注意力世界的残余领地

- **时间序列预测**（金融/气象）：专用架构仍有优势。
- **图数据**（分子/芯片设计）：GNN 仍在进化。
- **超低功耗端侧**：TinyML 用极小的专用网络。
- 这些领域数据形态特殊、规模有限，注意力的"数据饥渴"反而是劣势。

## 四、对小白的三条收束

1. **"NN"不是一种网络，是一个家族姓氏。** 问"什么 NN 好"就像问"什么动物好"——要看它处理什么形态的数据：图（CNN）、序列（RNN/Transformer）、图结构（GNN）、任意（MLP 打底）。
2. **架构王朝的更替规律：不是旧架构"错了"，而是新数据规模让它"不够用了"。** RNN 的传话设计在千万字语料前崩溃；CNN 的小窗先验在亿级图片前反成枷锁；今天注意力的 O(N²) 在 agent 的百万 token 面前吃紧——**每个王朝的衰亡都写在它登基时的优势里**。
3. **你现在活在"Transformer 王朝的中期 + 挑战者复辟"的交界点。** 2026 云栖那两场演讲（vLLM 改良服务、Kimi Linear 改良架构）恰好各代表一条战线——看懂它们，就看懂了当下。
