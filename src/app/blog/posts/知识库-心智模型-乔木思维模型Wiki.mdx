# 乔木思维模型 Wiki（Mental Models）

> 专家思维的可视化解剖台。向阳乔木（Vista）的开源项目，收集整理全球顶级思维模型，在线版 [mm.qiaomu.ai](https://mm.qiaomu.ai/)。

## 基本盘

| 项 | 值 |
|---|---|
| 模型 | 114 个，按 7 学科组织（物理 13 / 生物 15 / 经济 17 / 博弈 14 / 心理 21 / 系统 16 / 战略 18） |
| 关联 | 496 条模型间连接（构成知识图谱） |
| 人物 | 232 位（每位一页：简介、趣事、年表、代表作） |
| 授权 | **MIT License**（Copyright 2026 Joe）——允许复制、修改、再发布、商用，需保留版权声明 |

## 每条目的 8 区块结构

1. **场景钩子**：一个具体的真实故事（如马斯克拆电池成本）
2. **原理图**：Mermaid 流程图
3. **数据证据**：ECharts 图表，数据分三级标注（一手核实 / 可靠二手 / 草稿示意）
4. **交互演示**：可拖滑块看参数如何改变结果（部分条目）
5. **怎么用**：3~5 步操作清单
6. **失效边界**：模型什么时候坑人（情境 → 模型说 → 现实 的反例表）
7. **关联模型**：与其他模型的连接
8. **出处**：可核对的来源列表（tools/resolve_links.py 走 Crossref / Google Books 核实过链接）

## 工程亮点（值得抄的）

- **单数据源多形态**：`data/models/*.json` 是唯一真实来源，网页/图谱/视频全部从它生成（tools/build.py，纯 Python 标准库，零 Node 依赖）。
- **schema 校验守门**：tools/mm.py 校验 + check.py 条目级校验，生成不过关就不入库。
- **出处链接机器核实**：标题高度吻合才采信，查不到退回搜索链接——防幻觉的内容纪律。
- **版式由数据决定**：条目区块按领域气质排序（心理先看反例，物理系统先动手，经济战略先看数据）。
