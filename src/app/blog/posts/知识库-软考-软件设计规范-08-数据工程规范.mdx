# 08 数据工程规范

> 来源：《系统集成项目管理工程师教程（第3版）》第6章

## 1. 数据采集和预处理

### 1.1 数据采集
采集系统需要的数据源（业务系统、传感器、日志、第三方等），保证采集的完整性、及时性、准确性。

### 1.2 数据预处理
对采集到的原始数据进行清洗、转换、去重、补齐、格式标准化等，为后续存储与分析做准备。

### 1.3 数据预处理方法
包括但不限于：数据清洗（去除噪声、纠正错误）、数据集成（多源合并）、数据变换（规范化、离散化）、数据归约（降维、抽样）等。

## 2. 数据存储及管理

| 环节 | 说明 |
|------|------|
| 数据存储 | 选择合适的存储技术（关系型、NoSQL、分布式文件系统、对象存储、数据湖等） |
| 数据归档 | 对不常访问的历史数据进行归档，降低存储成本、保证合规留存 |
| 数据备份 | 制定备份策略（备份频率、方式、介质），保障数据可恢复 |
| 数据容灾 | 建立容灾机制（同城/异地、主备/双活），保证业务连续性 |

## 3. 数据治理和建模

### 3.1 元数据
描述数据的数据（数据的定义、结构、来源、血缘、质量等），是数据治理的基础。

### 3.2 数据标准化
制定统一的数据标准：命名规范、编码规范、格式规范、口径统一，保证跨系统数据一致可用。

### 3.3 数据质量
从准确性、完整性、一致性、及时性、唯一性、有效性等维度度量与管理数据质量，建立数据质量监控与改进机制。

### 3.4 数据模型与数据建模
- 数据模型：对现实世界数据的抽象（概念模型、逻辑模型、物理模型）；
- 数据建模：采用 E-R 建模、维度建模（星型/雪花）等方法构建模型；
- 建模步骤通常：需求分析 → 概念模型 → 逻辑模型 → 物理模型。

## 4. 数据仓库和数据资产

| 概念 | 说明 |
|------|------|
| 数据仓库 | 面向主题的、集成的、相对稳定的、反映历史变化的数据集合，支撑分析决策 |
| 主题库 | 按业务主题组织的数据集合（如客户主题、产品主题） |
| 数据资产管理 | 对数据资产进行盘点、评估、确权、运营，实现数据价值变现 |
| 数据资源编目 | 对数据资源进行统一编目，形成数据目录，便于查找与使用 |

## 5. 数据分析及应用

| 环节 | 说明 |
|------|------|
| 数据集成 | 将分散数据按统一标准汇聚（ETL/ELT） |
| 数据挖掘 | 从数据中发现模式与知识（分类、聚类、关联、预测等） |
| 数据服务 | 将数据能力封装为服务，供应用按需调用（API、数据接口） |
| 数据可视化 | 以图表、大屏等形式直观呈现数据，支撑决策 |

## 6. 数据脱敏和分类分级

### 6.1 数据脱敏
对敏感数据（个人信息、账户、信用、行为数据等）进行变形处理（掩码、替换、加密、泛化等），在非生产环境或分析场景中保护数据安全，同时保持数据可用性。

### 6.2 数据分类
根据数据所属维度分类，例如：按业务行业（金融、能源、交通）、按业务特点（研发、生产、维护）、按管理视角（经营、财务、产品）等。

### 6.3 数据分级
对数据进行分级（如核心、重要、一般），制定差异化的安全保护措施与访问控制策略。

## 7. 数据工程检查单

- [ ] 是否建立数据采集与预处理流程？
- [ ] 是否制定备份与容灾策略并演练？
- [ ] 是否建立元数据管理与数据标准化机制？
- [ ] 是否有数据质量度量与改进机制？
- [ ] 是否完成数据建模与数据仓库/主题库建设？
- [ ] 是否对数据资产编目与运营？
- [ ] 是否落实数据脱敏与分类分级？
- [ ] 数据全生命周期是否符合安全与合规要求？
