# 05 区块链行业地图

> 一句话结论：区块链 = 让互不信任的各方共同维护一份无法单方篡改的账本的技术。厂家多是因为它本质是"共识底座"，各行业都想拿它记账，且开源可 fork、发币有财富效应。格局类似 2000 年互联网：协议层赢家通吃，应用层少数真需求，长尾大量泡沫。

## 一、四块积木

1. **P2P 网络**：每个节点持有全量账本副本，无中心服务器。
2. **密码学**：哈希把区块锁成链（改一笔，后面全穿帮）；数字签名证明操作者身份。
3. **共识机制**：全网约定"谁说了算"——PoW（算力竞选）、PoS（押金竞选）等。
4. **智能合约**：写在链上、条件触发自动执行的程序（"代码即合同"）。

它解决的唯一核心问题：**没有银行/支付宝/政府做中间人，陌生人也能确认"这笔记录是真的、没被改过"**。能记账就能记任何需要"防篡改、可追溯、多方互信"的账——这是它价值所在，也是被吹过头的原因。

## 二、不可能三角（新链层出不穷的理论根源）

去中心化、安全性、性能（TPS）三者最多取二：

- Bitcoin/Ethereum：去中心化+安全 → 慢且贵
- Solana：安全+性能 → 节点集中（中心化程度高）
- 各种新链：永远在宣称"我找到了更好的权衡点"

## 三、六层产业地图

| 层 | 代表 | 干什么 | 现状 |
|---|---|---|---|
| 1. L1 公链（底座） | Bitcoin、Ethereum、Solana | 谁的账本最安全/最快/最去中心化 | 协议层赢家通吃，长尾链大量死去 |
| 2. L2 扩容 | Arbitrum、Optimism、Base、zkSync | 链下处理交易，摘要写回 L1，解决贵和慢 | 活跃，以太坊生态主战场 |
| 3. 应用层 | Uniswap（换币）、Aave（借贷）、USDT/USDC（稳定币）、NFT、RWA（资产代币化） | 金融与非金融应用 | 稳定币是当前最大真实用途 |
| 4. 联盟链/许可链 | 蚂蚁链、腾讯至信链、长安链、FISCO BCOS、Hyperledger Fabric | 不发币、节点准入，企业/政府记账 | **中国主力层**；"区块链+政务/司法存证/供应链/身份"全在这层 |
| 5. 基础设施 | MetaMask（钱包）、Infura/Alchemy（节点API）、Chainlink（预言机）、IPFS（存储）、跨链桥 | 给开发者和用户供水供电 | 卖铲子生意，最稳 |
| 6. 交易与配套 | Coinbase、Binance、做市商、矿机矿场、托管 | 交易/流动性/算力 | 行业最赚钱、离技术理想最远 |

另有 **身份赛道**（DID、可验证凭证、Worldcoin、ENS）横跨 1/4 层——本课题主线，见 docs/03、docs/06。

## 四、为什么厂家和技术这么多

1. 底座通用性：每个行业都想用它记自己的账（金融、供应链、政务、版权、身份）。
2. 准入门槛低：开源协议 fork 一下就能起一条新链；发币融资的财富效应吸引投机者。
3. 不可能三角：永远有"更好的权衡"可讲，新链叙事不断。
4. 结果：头部集中（Bitcoin/Ethereum 网络效应碾压）、中长尾泡沫化、基础设施和应用层淘金式洗牌。

## 五、中国的特殊性：禁币不禁链

- 禁：加密货币交易、挖矿（2021 起）。
- 不禁并主推：联盟链、区块链政务服务、BSN（区块链服务网络）、数字人民币（注意：数字人民币是央行数字货币，**不是**区块链加密货币，走中心化架构）。
- 对本课题：中国的链上身份只能在联盟链/BSN 体系内做 → docs/03 RealDID。
