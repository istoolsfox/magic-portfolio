# 06 三条现实路径与四层架构（课题主结论）

> 调研日期：2026-09-14。"唯一身份认证"不是单一技术，而是一套分层体系。本篇给出 2026 年全球三条主流路径的对照，以及业界正在收敛的"四层架构"——它就是"真正只属于你的认证"的当前最优解。

## 一、三条现实路径（2026 现状）

### 路径 A：中国——BSN RealDID（政府唯一性 + 链上凭证）

- 组成：公安部一所 CTID 数字身份链（唯一性来源）+ BSN（凭证层），2023-12 上线。
- 2026-06 网信办《促进分布式数字身份互通互认应用规定（征求意见稿）》——DID 上升为国家推动互通互认的基础设施方向。
- 特点：唯一性最强（国家身份库）、合规唯一解、实名锚定由政府背书。
- 详见 docs/03。

### 路径 B：World ID——专用硬件 + 零知识（全球人格层实验）

- 流程：Orb 专用硬件扫虹膜 → 虹膜码全球查重（一人一份）→ 签发零知识凭证 → 链上可验证。
- 2026 进展：便携版 Orb Mini 推进；第三方接入（Tinder、Razer 等用 World ID 做"真人验证"对抗 bot）[二手，官方博客/媒体]。
- 价值：证明了"全球唯一人格"技术上走得通；争议：一家公司掌管全球虹膜数据、多数主权国家不接纳（中国不可用）。

### 路径 C：欧盟 eIDAS 2.0 + EBSI（法律强制的 DID）

- eIDAS 2.0（Regulation (EU) 2024/1183）要求成员国 2026-12 前部署 EUDI 数字身份钱包 [实锤]。
- 底层：W3C DID + 可验证凭证 + EBSI（欧洲公共服务区块链）。
- 特点：政府签发 + 私人钱包持有 + 公共链验证，"主权身份"范式的最大规模落地。

### 对照表

| 维度 | 中国 RealDID | World ID | 欧盟 EUDI |
|---|---|---|---|
| 唯一性来源 | 公安人口库 | 虹膜查重（专用硬件） | 成员国政务系统 |
| 隐私哲学 | 对商家匿名/对监管实名 | 全匿名（ZK）、无实名 | 属地政务+最小披露 |
| 驱动力 | 国家基础设施规划 | 一家公司+加密资本 | 立法强制 |
| 硬件门槛 | 低 | 高（铺 Orb） | 低 |
| 对中国人可用 | ✅ | ❌ | ❌ |

## 二、四层架构（业界收敛中的答案）

```
第 4 层 区块链/DID 网络 —— 信任底座：不依赖任何一家公司活着、不被单方篡改
第 3 层 DID + 可验证凭证 —— 通行证：跨系统出示，出示什么属性自己决定
第 2 层 密码学密钥(passkey/私钥) —— 身份证：真正出门出示的东西，可轮换可撤销
第 1 层 生物特征 —— 钥匙：留在设备安全芯片本地比对，永不外传，只负责解锁密钥
```

每一层的职责与理由：

1. **生物特征=钥匙**：AI 时代"远程出示生物特征"已失效（docs/01），但它作为"本机解锁因子"依然好使——你很难偷走一个人的手指。关键：特征数据永不离开安全芯片（TEE/Secure Enclave）。
2. **密钥=身份证**：唯一性靠"只有你能出示的密钥"而非"不可更改的身体"。可轮换、可撤销、绑定域名防钓鱼（WebAuthn origin binding）。
3. **DID+VC=通行证**：身份不锁死在任何公司账号里；选择性披露（证明"已成年"不露生日）靠 ZK/匿名凭证。
4. **区块链=底座**：验证方不回连发证机构也能验真；发证机构倒闭/作恶不摧毁你的身份。

## 三、核心观念转变（本课题的"道"）

- **从"证明你的身体"到"证明你的控制权"**：身体会老化、会泄露、不可补办；密钥可以换、可以注销、可以恢复。
- **生物特征降级为本地解锁因子**——身体解锁密钥、密钥代表身份、身份可以补办。
- **唯一性是注册问题，不是验证问题**：所有验证都是"与第一次的记录比对"，AI 攻击的是比对现场；真正的防线在第一次注册（专用硬件+权威库查重）。

## 四、遗留未解难题（诚实清单）

1. **注册端软肋**：第一次采集怎么保证是你？任何系统的"第一天信任"都要靠线下/权威，无法纯线上解决。
2. **密钥-人的绑定松动**：密钥可被盗用、被继承、被胁迫交出；"凭证体系里的你"≠"生物学上的你"，法律与伦理框架未跟上。
3. **全球唯一 vs 主权边界**：World ID 出不了主权国家的门，RealDID 出不了国门；跨国互认是十年级工程。
4. **唯一性与匿名性天然矛盾**：越唯一越可追踪，所有方案都在两端之间找位置——ZK 是缓和剂，不是解药。
5. **排斥问题**：任何依赖硬件/官方凭证的方案都会排除边缘人群（无证件者、无智能设备者）。
