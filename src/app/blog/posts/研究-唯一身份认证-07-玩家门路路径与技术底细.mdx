# 07 玩家门路、路径与技术底细

> 调研日期：2026-09-15。一句话结论：全球玩家收敛出五条门路——①专用硬件+代币激励（World）、②复用存量护照芯片做 ZK（Self/ZKPassport）、③国家户籍库直接签发（中国网证/RealDID）、④法律强制钱包（欧盟 eIDAS）、⑤OS 入口（Apple/Google）；而 2017-2021 那代"社会化验证"路线（BrightID/Idena/Proof of Humanity）几乎全部阵亡。五条活路的共同点：都找到了"唯一性来源"的现成锚（硬件虹膜 / 国家护照 / 国家户籍 / 国家法律 / 设备安全芯片），**没有一个是从零发明的**。

## 一、五条活路 vs 一片坟场

| 门路 | 代表 | 唯一性锚 | 冷启动手段 | 2026 状态 |
|---|---|---|---|---|
| 专用硬件+代币 | World ID | Orb 虹膜查重 | WLD 代币激励+运营商付费招募 | 1800 万验证用户，160 国 [二手，官方口径] |
| 复用存量护照 | Self / ZKPassport | ePassport NFC 芯片的国家签名 | 开源 SDK+以太坊基金会/PSE 孵化 | Self 1.3k star 活跃；ZKPassport 被 Aztec 收购 [实锤，GitHub/官方博客] |
| 国家户籍库 | 中国网证/CTID/RealDID | 公安人口库 | 行政推动+平台接入义务 | 2025-07-15 管理办法生效；2026-06 网信办征求意见稿 [实锤] |
| 法律强制钱包 | 欧盟 eIDAS 2.0/EUDI | 成员国政务系统 | 条例法定大限（2026-12） | 部署进度落后（\<1/3 成员国 on track【待核实】） |
| OS 级入口 | Apple Digital ID / Google Wallet | 设备安全芯片+护照/驾照 NFC | 预装系统入口 | Apple 护照版 Digital ID 2025-11 上线，全美可用 [实锤，官方新闻稿] |
| ~~社会化验证~~ | BrightID / Idena / Proof of Humanity | 人际担保/验证仪式 | 无强激励，靠理念 | 全部边缘化：BrightID 休眠（2025-10 后无提交）、Idena 日交易量约 \$36、PoH 已停摆 [实锤，GitHub/行情] |

**坟场教训**：社会化验证（"找三个已认证的人给你作保"）败在冷启动——人际担保网络无法跨出初始社区，且 UX 极重（视频验证派对、定时 captcha 仪式）。Vitalik 2023 年就指出它的可及性比 Orb 更差：不在信任图里的人根本进不来。这条路线的遗产是思想（quadratic voting、Dsociety 论文），不是产品。

## 二、逐条门路拆解

### 1. World：硬件+代币的激进扩张路径

- **路径时间线**：2019 创立（Sam Altman 联合 Max Novendstern、Alex Blania，运营主体 Tools for Humanity，融资约 \$250M，a16z/Khosla 等）→ 2021-10 首轮部署 → 2023-07-24 正式发布 → 2024-05 虹膜码迁入 SMPC 并删除旧版 → 2024-10 更名 World Network → 2025-05 进美国（同步推 Visa 借记卡、与 Match Group/Tinder 合作）→ 2025-09 官方口径 3300 万 App 用户/1500 万 Orb 验证 → 2026 Orb Mini 便携化 [实锤，维基百科+官方博客交叉]
- **门路本质**：用代币把"生物特征采集"外包给全球独立运营商（operator 按成功注册付费），在监管宽松的低收入地区快速堆用户，形成既成事实后回头与监管谈判。MIT Tech Review 2022 年即揭露其在低收入社区付费招募的问题 [二手]。
- **监管一路撞墙**（均 [实锤，官方公告/主流媒体]）：印度暂停线下验证（2023）、肯尼亚暂停且 2025-05 命令删除全部生物数据、香港搜查 6 处场所并认定违反私隐条例（2024）、西班牙 AEPD 禁令（2024-03，GDPR 紧急条款）、葡萄牙 CNPD 同月跟进、巴西/印尼暂停（2023/2025）、菲律宾认定"金钱激励=无效同意"（2025-10）、泰国命令停止虹膜扫描并删除 120 万人数据（2025-11）。
- **悖论**：用户数与监管打击同步上涨——打击反而证明需求（"证明你是真人"在深伪时代是刚需），但"哪家主权国家肯让一家美国公司掌管全球虹膜库"仍是死结，中国/美国本土长期缺席。

### 2. ePassport ZK：借国家存量基础设施的密码学路径

- **核心洞察**：140+ 国的电子护照（ICAO 9303 标准）里已经躺着一个国家背书的唯一性锚——NFC 芯片上的国家数字签名。不需要采集任何新生物特征，不需要建任何新数据库，只需要用 ZK 把"验证"这一步从海关挪到手机上。
- **技术信任链**（源自 zkpassport/circuits README，[实锤]）：
  1. 手机 NFC 贴护照，MRZ（机读区）的证件号+出生日期+有效期派生对称密钥解锁芯片（所以偷扫不了——必须物理翻开护照）；
  2. 芯片内存数据组（姓名/国籍/生日/照片等）+ DSC 证书的签名（文件签名者，各国轮换）；
  3. DSC 又被 CSCA（国家签名证书总局，每国一个根）签名，构成信任链；
  4. CSCA 公钥从 ICAO 官方 PKD 目录下载——和机场 e-gate 验证完全同源；
  5. ZK 电路内完成整条 RSA/ECDSA 验签，只输出承诺的命题："此护照由国家有效签发且出生年份>2008 / 国籍=FR / 这是本人第一次注册"。
- **核心工程难题**：RSA-2048/ECDSA 验签在 ZK 电路内极其昂贵（大数模乘），各团队用 Noir/Circom+查表技巧硬啃了数年——这就是这代团队的护城河，也是技术含量所在。
- **玩家归宿**：OpenPassport（PSE 孵化）→ 并入 Self（selfxyz/self，1.3k star，Celo 生产部署，支持护照+欧盟电子身份证+Aadhaar 二维码）；Obsidion/ZKPassport → 2026 被 Aztec Labs 收购、承诺保持开源、成为 Aztec 网络的身份证层；Rarimo 另有一套开源电路。**独立小团队无一存活，全部被基础设施方收编**。
- **软肋**：①护照未普及人群（无证件者、护照过期者）被系统性排斥；②多人共照/家属代持无法防；③"第一次注册时是谁"仍靠人审——源头唯一性问题依旧（见 docs/04 子问题④）。

### 3. 中国路径：户籍库+网证+链（详见 docs/03，此处补门路逻辑）

- **路径**：网证/网号 App（刷脸+身份证开通）→《网络身份认证公共服务管理办法》2025-07-15 施行（明确"自愿"原则）→ 2026-06 网信办《促进分布式数字身份互通互认应用规定（征求意见稿）》打通 DID 互通 [实锤，官方规章]。
- **门路本质**：唯一性由几十年户籍制度免费提供，技术只是"把身份证投影到网络"。国家不需要 ZK 来保护隐私——平台方拿不到完整身份信息本身就是制度设计（只能拿到"核验通过/不通过"）。
- **防蹭信号**：CTID 官方（anicert.cn）郑重声明"与任何组织均无分布式数字身份商业合作"——市面上大量"RealDID 合作""数字户口本"项目是蹭概念 [实锤，官方声明]。
- **学界争议点**：清华劳东燕等学者公开质疑法律依据与"自愿是否会滑向事实强制" [二手，媒体/社交媒体]。

### 4. 欧盟 eIDAS 2.0：法律强制路径

- 条例 (EU) 2024/1183 要求成员国 2026-12 前提供 EUDI 钱包——用立法倒逼基础设施，这是其他路径没有的"强制力杠杆"。底层：W3C DID+可验证凭证+SD-JWT/mDL(ISO 18013-5) 格式+EBSI 链验证。
- 现实阻力：成员国部署普遍落后；一个钱包要兼容 27 国行政体系，集成复杂度极高。

### 5. Apple/Google：OS 入口路径

- Apple 2025-11 推护照版 Digital ID（不依赖各州 DMV 逐州推进，全美即时可用），Google Wallet 同步支持护照 ID Pass、并在印度接入 Aadhaar VC（2026-04）[实锤，官方]。
- **门路本质**：不发明身份，只抢占"出示"的入口。硬件安全芯片（Secure Enclave/TEE）+ 预装分发 = 零获客成本。与 ePassport ZK 路线的差别：数据格式由政府钱包标准定义，Apple/Google 只做安全容器——**他们再次只做平台，让别人做脏活**。

## 三、共同的技术骨架：ZK 包装的"一人一号"机制

Vitalik 2025-06《Does digital ID have risks even if it's ZK-wrapped?》给出了当前所有方案的机制抽象（[实锤，一手]）：

1. 用户手机持有秘密 `s`；全局注册表只存 `H(s)`；
2. 访问某应用时生成应用专属 ID `H(s, app_name, session)`；
3. 用 ZK 证明"该 ID 源自注册表里的某个 s"——应用知道你是唯一真人，不知道你是谁，甚至不知道你在同一应用内两次操作是同一人；
4. World 的虹膜码与 Self 的护照验签只是"谁来保证 s 只注册一次"的不同答案。

五条门路共享这个骨架，差别只在**唯一性来源**（虹膜/护照/户籍/法律/芯片）与**信任治理**（公司/开源社区/国家/法律/平台）。这印证 docs/06 四层架构：上面的层已高度趋同，真正的分野在最底层。

## 四、给本课题的三个增量认知

1. **"从零造唯一性"全部失败，"锚定现成唯一性"全部存活**——个人/小团队若入场，唯一可行姿态是第②条（复用存量护照做 ZK）生态的集成/贡献者，因为它的锚（ICAO 体系）和电路（Noir 开源）都是公共品。
2. **中国路径缺的不是技术是"出示层"**：网证有国家唯一性，但没有像 Apple Wallet 那样的日常出示入口（小程序/SDK 体验远逊），这正是 2026 征求意见稿要推动的"互通互认应用"缺口。
3. **ZK 包装解决隐私，不解决权力**（Vitalik 2025 的核心论点，详见 docs/08）：一人一号若成为唯一登录方式，伪匿名、强制披露、错误排斥三大风险全部复活——这是评价任何"唯一身份"系统的第三把尺子（前两把：防女巫、保隐私）。
