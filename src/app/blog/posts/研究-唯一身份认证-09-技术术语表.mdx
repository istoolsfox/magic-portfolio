# 09 技术术语表

> 整理日期：2026-09-15。收拢 docs/01-08 出现过的全部技术名词。分两部分：**第一部分按"一层层往上搭"的逻辑串联**（适合通读建立整体认知），**第二部分分类速查**（约 60 词条，适合遇到生词时翻查）。每条力求一句人话讲清，配类比。

## 第一部分：分层串联导读

整个课题的技术体系可以按"从登录到密码学到各路线专属"一层层往上搭。

### 第 0 层：记忆锚点（先记住这三句）

整个课题其实就三句话——**密码学三件套**（哈希/签名/承诺）负责"可信传递"，**ZK 家族**（证明/电路/匿名凭证/SMPC）负责"只证明该证明的"，而**唯一性**本身（Orb 查重/护照芯片/公安户籍）始终在物理世界，密码学碰不到它——这正是 docs/04 核心结论的技术版。

### 第 1 层：登录是怎么回事

- **三因子**：所有登录方式就三类——"你知道什么"（密码）、"你拥有什么"（手机/U盾）、"你是什么"（脸/指纹）。
- **KYC**：开户时"拍证件+刷脸+证明活人"那套流程。深伪攻击打的就是它。
- **活体检测（Liveness/PAD）**：判断镜头前是活人还是照片/视频。"眨眨眼摇头"那代已被深伪攻破；iPhone 的 3D 结构光活体强得多。
- **SIM swap**：骗子冒充你补办 SIM 卡，你的短信验证码全归他——这就是"短信是最弱的持有因子"的原因。
- **TEE / Secure Enclave**：手机芯片里的"隔离舱"，有自己的密钥，连手机系统自己都读不出里面存的私钥。passkey 的私钥就锁在这里。

### 第 2 层：密码学三件套

- **哈希函数**：把任意数据压成固定长度"指纹"。像绞肉机——肉末拼不回肉（单向），改一个字指纹全变（雪崩）。SHA-256 就是一种。
- **密钥对**：数学上成对，私钥保密、公钥公开。类比信箱：地址（公钥）人人可投信，只有你手里的钥匙（私钥）能开箱。
- **数字签名**：用私钥给消息盖"签章"，任何人拿公钥就能验证"确实是他发的、没被改过"。那串算法名（ECDSA/Ed25519/Schnorr/BLS）只是不同的盖章工艺；**RSA-2048** 是老工艺（护照芯片在用），它的验证在 ZK 电路里极贵——这正是 ZKPassport 团队的护城河。
- **信任链 / X.509 证书**：HTTPS 网站证书由中间 CA 签、中间 CA 由根 CA 签。护照芯片用的是**完全同构**的一套（见第 5 层）。

### 第 3 层：零知识证明（这个课题的心脏）

- **ZKP 一句话**：证明"命题为真"而不泄露任何别的。最好的比喻是**数独**：我声称填出了答案，你随机挑一行或一列让我翻开，全对；重复一百次，你确信我有答案，但你始终没看到完整答案。
- **ZK-SNARK vs zk-STARK**：SNARK 证明小（几百字节）、验证快，但要"可信设置仪式"；STARK 不要仪式、抗量子，但证明大。**Groth16 / PLONK** 是 SNARK 家族里两种具体证明系统（PLONK 的仪式一次通用，更省事）。
- **ZK 电路（Noir/Circom）**：把"要证明的逻辑"写成程序的专用语言——ZKPassport 的"在电路里验护照签名"就是用 Noir 写的。
- **选择性披露**：只给"年满18"，不给生日和姓名。**SD-JWT** 和 **BBS+ 签名**是实现它的两种轻量办法（不用完整 ZK）；**匿名凭证**是 Chaum 1985 年提出的祖师爷思想。
- **SMPC（安全多方计算）**：把一份数据撕成 N 片分给 N 方，谁单独都拼不出原件，但能合作算结果。World 2024 年把虹膜码库迁进了 SMPC。
- **Nullifier**：由秘密派生的公开"已用"标记——像投票盖章，章上不写名字，但同一张票盖两次章会被发现。防双花/防重复投票的核心，World ID 的 H(s, app) 和 Semaphore 都用它。
- **MACI**：反贿选工具——你的票可随时被自己覆盖作废，外人分不清哪票是终票，所以"卖票"无法验证交货，贿选就没了意义。

### 第 4 层：协议与标准

- **FIDO2 / WebAuthn / passkey**：三位一体（联盟协议族 / 浏览器 API / 产品名）。网站发**挑战**（随机数）→ 芯片里的私钥对"挑战+域名"签名 → 公钥验签。三大杀器：私钥不出芯片、**域名绑定**（origin binding，假网站自动失效）、一站一钥（无撞库）。
- **DID / VC**：DID 是"自己注册、自己持钥匙的网络身份证号"（`did:bsn:xxx`）；VC 是"数字钢印证件"——签发方对"某 DID 拥有某属性"签名。DID 管身份，VC 管资格。
- **eIDAS 2.0 / EUDI 钱包**：欧盟法律强制的"政府签发+手机持有+选择性披露"钱包，2026-12 大限。底层就是 DID+VC+SD-JWT/mDL。
- **mDL（ISO 18013-5）**：手机驾照的国际标准，苹果钱包里那个驾照就按它做。

### 第 5 层：两条主线各自的技术栈

**ePassport 路线**（Self/ZKPassport）：

- **ICAO 9303** = 140+ 国护照都遵守的芯片标准
- **NFC** 贴护照 → **MRZ**（资料页下方两行机读码，含证件号+生日+有效期）派生密钥解锁芯片——所以必须物理翻开护照才能读，隔包偷扫无效
- 芯片里的 **DSC**（文件签名证书，像"网站证书"）签数据 → **CSCA**（国家根证书，像"根 CA"）签 DSC → 验证方从 **PKD**（ICAO 官方公钥目录，像"系统预装根证书库"）拿信任锚
- ZK 电路把这条验证整个搬进电路，只输出"年满18/首次注册"这类命题

**World 路线**：

- **Orb** = 定制虹膜采集球；**虹膜码** = 虹膜纹理经 **Gabor 滤波器**量化成的比特串（同人两次扫码差异小、不同人大，比对=数不同的比特数），存的是"模糊哈希"不是原图；**WLD 代币** = 注册送币的冷启动激励，也是各国监管的靶心（"金钱换生物数据=同意无效"）。

### 第 6 层：机制层的名词

- **二次方投票/资助**：出钱开方计票——1 人出 100 元=10 票，100 人各出 1 元=100 票，防止富人线性买断影响力。Vitalik 的"N 个身份成本应为 N²"就与此同构。
- **L2**：交易在链下批量算、摘要写回主链，又快又便宜还继承主链安全。

## 第二部分：分类速查表

### 一、认证基础

- **三因子（认证因子）**：所有登录方式归三类——你知道什么（密码）、你拥有什么（手机/U盾）、你是什么（脸/指纹）。安全系统一般要求至少两种不同因子组合（MFA 多因子）。
- **KYC（Know Your Customer）**：金融机构开户时的身份核验流程（拍身份证+刷脸+活体）。深伪注入攻击打的就是这个环节。
- **OTP（一次性密码）**：30 秒一变的 6 位动态码（Google Authenticator 那种），基于共享密钥+时间窗生成。短信验证码是它的退化版（码经运营商网络，可被 SIM swap 截获）。
- **SIM swap（换卡攻击）**：骗子冒充你向运营商补办 SIM 卡，你的号码被转移到他的卡上，所有短信验证码归他。
- **U盾/硬件密钥**：私钥存在独立硬件里、永不出芯片的认证设备。U盾是银行版，YubiKey 是通用版，手机安全芯片是内置版。
- **TEE / Secure Enclave（可信执行环境/安全隔区）**：手机主芯片里划出的一块"隔离舱"，有自己的密钥和操作系统，连手机主系统都读不出里面存的私钥。iPhone 的叫 Secure Enclave，Android 常见的是 TEE（Trusty/高通 SPU）。passkey 的私钥就住在这里。
- **活体检测（Liveness / PAD）**：判断镜头前是活人还是照片/视频/面具。PAD=Presentation Attack Detection，ISO 30107-3 是其测评标准。动作活体（眨眼摇头）已被深伪视频攻破，3D 结构光活体强得多。

### 二、攻击名词

- **注入攻击（injection）**：不骗算法、直接换输入源——用虚拟摄像头（OBS Virtual Camera）把深伪视频"喂"给 KYC 系统，系统收到的就是假流。算法再准也白搭，因为输入是假的。
- **Deepfake（深度伪造）**：用生成式 AI 换脸/克隆声音。生成一次突破全网可用（自回归），检测要持续追赶（判别），经济学上防御方永远吃亏。
- **女巫攻击（Sybil Attack）**：一个实体伪造大量身份冒充多个独立参与者。Douceur 2002 定义：零成本准入的开放系统里"一人一票"必然退化成"一身份一票"。
- **钓鱼（Phishing）**：做个假网站骗你输入密码。passkey 靠域名绑定天然免疫。

### 三、密码学基础

- **密钥对（私钥/公钥）**：数学上成对——私钥保密、公钥公开。私钥签的名只有对应公钥能验；公钥加密的内容只有私钥能解。类比：一个信箱（公钥地址人人可见可投信），只有你持有钥匙（私钥）能开。
- **数字签名**：用私钥对消息生成一段"签章"，任何人可用公钥验证"确实是私钥持有者发的、内容没被改"。不可伪造（无私钥造不出）、不可抵赖。算法家族：
  - **ECDSA**：椭圆曲线签名，Bitcoin/以太坊在用；
  - **Ed25519**：更现代的椭圆曲线签名，更快更难做错，SSH/Signal 新版在用；
  - **Schnorr**：签名可线性叠加，Bitcoin Taproot 启用；
  - **BLS**：多个签名可压缩成一个（聚合），以太坊验证者集体签名用它；
  - **RSA-2048**：老牌大数签名（护照芯片在用），密钥长、验证在 ZK 电路里极贵——这就是 ZKPassport 们的工程难点。
- **哈希函数（SHA-256/Keccak）**：把任意数据压成固定长度"指纹"。单向（由指纹反推原文不可能）、抗碰撞（找两个同指纹的原文不可行）、雪崩（改一个字指纹全变）。类比：绞肉机——肉进去肉末出来，肉末拼不回肉。
- **Merkle 树**：把大量数据两两哈希、逐层向上归并成一棵树，树顶一个根哈希代表全部。验证某条记录只需"该记录+通往树根的一条路径哈希"，不用下载全账本。区块链和证书透明日志的骨架。
- **承诺（Commitment）**：先公布 H(x)（把值"锁进信封"），之后揭示 x，大家验证信封没被调包。性质：绑定性（不能再换值）+隐藏性（信封期看不出值）。
- **X.509 证书 / 信任链 / 信任锚**：证书=公钥+身份+签发者签名的打包。HTTPS 网站证书由中间 CA 签，中间 CA 由根 CA 签——这条链就是信任链，链顶的根就是信任锚（预装在你的操作系统/浏览器里）。护照芯片用完全同构的体系（见"CSCA/DSC"）。

### 四、零知识证明（ZK）

- **零知识证明（ZKP）**：证明"某个命题为真"而不泄露任何其他信息。经典比喻：**数独**——我声称填出了答案，你随机挑一行或一列让我翻开，全对；重复一百次，你确信我有答案，但你没看到完整答案。三个性质：完备（真必可证）、可靠（假必被拆穿）、零知识（验证者除"命题为真"外一无所获）。
- **ZK-SNARK**：简洁非交互式知识论证——现代实用形态。证明是几百字节、验证毫秒级，且不需要证明者验证者来回对话（非交互）。缺点：设置阶段需可信仪式（trusted setup，Groth16 每个电路一次）。
- **zk-STARK**：不需要可信设置、抗量子（基于哈希），代价是证明更大。**Groth16/PLONK** 是 SNARK 家族内不同证明系统：Groth16 证明最小但每电路要仪式；PLONK 一次仪式通用（universal setup）、电路编写更灵活。
- **ZK 电路（Noir/Circom）**：把"要证明的逻辑"写成约束系统的语言。Circom 是老一代（配套 snarkjs），Noir 是 Aztec 推的新一代（可编译到多种后端）。ZKPassport 的护照验签电路用 Noir 写。
- **选择性披露（Selective Disclosure）**：出示证件时只透露必要属性——只给"年满 18"，不给出生日期和姓名。ZK 包装的标准玩法。
- **匿名凭证（Anonymous Credentials）**：Chaum 1985 年提出的思想：签发方给你凭证，你能证明"我持有某签发方的有效凭证"而不暴露是哪一张（不可追踪、不可关联）。现代实现即 ZK 身份证明。
- **SD-JWT（选择性披露 JWT）**：把 JWT 里的每个属性单独哈希+加盐，出示时只揭示需要的字段。eIDAS/EUDI 钱包的候选格式之一。非 ZK（签发方仍可追踪），胜在工程简单。
- **BBS+ 签名**：一种原生支持选择性披露+多次出示不可关联的签名方案（基于 BBS 群签名）。W3C VC 生态的另一个格式候选，比 SD-JWT 更隐私，比 ZK 电路更轻。
- **SMPC（安全多方计算）**：N 方各持秘密，合作算出函数结果但谁也看不到别人的输入。World 用它存虹膜码：把虹膜码拆成分片分给多方，单人/单方拿不到完整数据，只有 Orb 网络限速合作查询"是否重复"。
- **模糊提取器（Fuzzy Extractor）**：从"每次读略有差异"的生物特征里稳定提取密钥的技术——先纠错再提取。Vitalik 提议用它减少虹膜码发布的数据量。
- **Nullifier（作废符/一次性标记）**：由秘密派生的公开标记，用来防双花/防重复投票，但反推不出秘密。Semaphore 的核心：成员集合是 Merkle 树，成员匿名证明成员身份时生成 nullifier，同一事件重复出示两个 nullifier 就会被发现。World ID 的 H(s, app) 应用专属 ID 同理。
- **MACI（最小反贿选基础设施）**：以太坊投票工具——投票可被密钥持有人随时覆盖作废，且外界分不清哪票是最终票，使"卖票"无法验证交割，贿选失去意义。

### 五、协议与标准

- **FIDO2 / WebAuthn / passkey**：三位一体——FIDO2 是联盟定的协议族，WebAuthn 是浏览器 API 标准，passkey 是消费级产品名。流程：网站发随机挑战 → 手机安全芯片里的私钥对"挑战+网站域名"签名 → 网站用事先登记的公钥验签。三大杀器：私钥不出芯片（木马偷不走）、签名绑域名（假网站自动失效）、一站一钥（无撞库）。2026 年全球 50 亿把在用。
- **挑战（Challenge）**：验证方每次随机发的数，签名必须针对它生成——重放旧签名无效。"挑战-响应"是一切认证协议的心跳。
- **域名绑定（Origin Binding）**：passkey 签名对象里包含网站域名，A 站的密钥对 B 站的挑战签不出有效签名——钓鱼站拿不到你能用的凭证。
- **DID（去中心化身份标识符）**：W3C 标准，形如 `did:bsn:xxx` 的字符串+一份 DID 文档（含公钥、验证方法）。私钥在用户手里，DID 文档可挂在链上或任意可验证位置。类比：自己注册、自己持钥匙的"网络身份证号"。
- **VC（可验证凭证）**：W3C 标准，数字版的"证件+钢印"——签发方（政府/机构）对"某 DID 持有某属性"签名，出示时验签即可信。DID 管身份，VC 管资格。
- **eIDAS 2.0 / EUDI 钱包**：欧盟条例 (EU) 2024/1183，要求成员国 2026-12 前给公民发 EUDI（European Digital Identity）钱包——政府签发、公民手机持有、选择性披露出示。底层即 DID+VC+SD-JWT/mDL。
- **ISO 18013-5（mDL）**：移动驾照国际标准，定义驾照怎么存手机里、怎么 NFC/QR 出示。苹果钱包里的驾照就按它做。

### 六、ePassport 路线专属

- **ICAO 9303**：联合国国际民航组织的电子机读旅行证件标准，140+ 国护照遵循。定义了芯片里存什么、怎么签名、怎么验证——e-gate 和 ZKPassport/Self 都按它读护照。
- **NFC**：近场通信，手机贴一下就能和护照芯片对话（10cm 内）。
- **MRZ（机读区）**：护照资料页下方两行机器可读码。其中证件号+生日+有效期被用来派生对称密钥解锁芯片——所以必须物理翻开护照才能读芯片，隔着包偷扫无效。
- **DSC（文件签名证书）**：签署护照数据的中级证书，国家定期轮换。对应 HTTPS 里的"网站证书"。
- **CSCA（国家签名证书总局证书）**：每国一个的根证书，签 DSC。对应 HTTPS 里的"根 CA"。护照信任链：数据←DSC 签名←CSCA 签名。
- **PKD（ICAO 公钥目录）**：各国上传 CSCA/DSC 公钥的官方目录，验证方从这里拿信任锚。类比操作系统预装的根证书库。
- **被动认证（Passive Authentication, PA）**：ePassport 三大验证之一（另两个是主动认证 AA 与芯片认证 CA）——验证数据组上的签名+证书链，保证数据未篡改且国家签发。ZK 护照电路做的主要就是 PA 的电路内复刻。

### 七、World 路线专属

- **Orb**：World 的虹膜采集球，定制硬件：活体判定+虹膜成像+本地提取虹膜码。争议核心=硬件构造无法被外界验证（可能藏后门）。
- **虹膜码（Iris Code）**：虹膜纹理经 **Gabor 滤波器**（一族方向/频率选择性滤波器，Daugman 1993 发明）量化成的比特串。同人两次扫码比特差异小、不同人差异大——所以存的是"模糊哈希"而非原始图像，比对=算汉明距离。泄露面：可被反向查询"此人是否注册过"，可能含性别/族群弱信号。
- **WLD 代币**：World 的激励代币，注册送币——冷启动手段，也是各国认定"金钱换生物数据同意无效"的监管靶点。

### 八、区块链层

- **智能合约**：部署在链上、条件触发自动执行的程序，"代码即合同"，无人可单方篡改。
- **PoW / PoS**：共识机制——谁有权记账。PoW（工作量证明）=比算力烧电，PoS（权益证明）=押币竞选。分别对应 Bitcoin / Ethereum(合并后)。
- **L2（二层扩容）**：交易先在链下批量处理，摘要写回主链（L1）。既继承 L1 安全性又提速降费。World Chain 基于 OP Stack（Optimism 系）的 L2。
- **二次方投票/资助（Quadratic Voting/Funding）**：Gitcoin 发明的机制——出资额开方计票，1 人出 100 元=10 票，100 人各出 1 元=100 票，把"多数人的弱偏好"和"少数人的强偏好"折中。与 Vitalik"N 个身份成本 N²"理想同构（防止少数富人线性买断影响力）。

### 九、其他

- **IPFS**：内容寻址的分布式存储（按文件哈希找文件，不按服务器地址）。
- **预言机（Chainlink）**：把链外真实世界数据（汇率、天气）喂进智能合约的桥梁。
- **TEE 远程证明**：向外界证明"我的芯片里确实在跑某段没被篡改的代码"——AI 时代"专用硬件不可验证"焦虑的现有解法方向。
