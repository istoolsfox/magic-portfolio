# 用连接组做模型训练：三种范式、证据与入手路线

> 深挖日期：2026-09-20 ｜ 背景：本项目用途定位为"模型训练"（用果蝇连接组训练模型）
> 纪律：关键数字带来源；[实锤]=读到论文/仓库原文，[二手]=转述

## TL;DR

用连接组训练模型不是"能不能"的问题——**Nature 2024 的 flyvis 已经给出了正面答案：固定果蝇视叶的真实接线（45,669 神经元 / 151 万突触），只训练 734 个参数，模型就学会了从自然视频估计光流，并正确预测了 32/32 种实验表征神经元的对比度选择性、T4/T5 的方向选择性，与 26 项既往实验吻合** [实锤，Nature s41586-024-07939-3]。

社区已沉淀出三种训练范式，证据强度递减：

1. **连接组约束训练**（冻结接线，训练逐突触增益 + 读出层）——flyvis（Nature 2024）已证有效；
2. **储层计算**（动态也冻结，只训读出层）——能跑通但优势未证（有项目报告普通 MLP 反而更强）；
3. **连接组当训练数据**（GNN 基准、神经递质预测、性别二态分类）——工具链成熟，属常规图学习。

对训练设计最重要的三条科学结论：**接线与任务训练缺一不可**（随机权重+真接线只够预测对比度选择性，预测不了方向选择性）；**稀疏性是连接组约束的价值来源**（10% 连接强度下活动相关 0.85，80% 时反降到 0.38）；**必须带洗牌对照和普通网络 baseline**（社区标准做法，也是"接线到底重不重要"的唯一证明方式）。

---

## 1. 范式 A：连接组约束训练（证据最强）

**做法**：连接图的拓扑（谁连谁、突触数、正负号）完全固定为实验测得的真实值；可训练的只有——每突触一个标量增益、每神经元一个阈值/时间常数、一个小的读出层。用 BPTT/消息传递端到端训练。

### 标杆：flyvis（TuragaLab，Lappalainen et al., *Nature* 2024）[实锤]

- **模型**：视叶运动通路 DMN——45,669 神经元、1,513,231 突触、64 细胞类型、721 列六角格子；阈值线性电压动力学 + 分级释放突触，PyTorch 可微实现。接线来自 EM 重建（FIB-25/FIB-19 数据集），突触正负号来自神经递质/受体表达谱。
- **只训 734 个参数**：每细胞类型 2 个膜参数 + 每细胞类型对 1 个突触强度尺度；任务是在 Sintel 自然视频上估计光流，外加一个小卷积解码器。
- **成绩**：
  - 32/32 个已实验表征的细胞类型对比度选择性（ON/OFF）全部预测正确（最佳单模型 30/32）；
  - 正确预测 T4（ON）/T5（OFF）是第一级方向选择性细胞，且其输入（Mi1、Tm3、Tm9 等）无方向调谐——与已知生物学一致；
  - 空间感受野、闪光时间响应（仅 Tm4 错）、T4/T5 null 方向抑制等与 **26 项既往研究**吻合；
  - 任务误差越低，调谐预测越准（r=0.60, P=2.6×10⁻⁶）——"为任务优化"和"还原大脑"正相关。
- **消融（对训练设计最有价值的部分）**：
  - 随机参数 + 真接线：能预测对比度选择性，**但方向选择性预测失败** → 结构携带信息，但结构 + 任务训练缺一不可；
  - 只有细胞类型级接线（去掉单神经元细节和突触数）：活动预测显著变差；
  - 无约束 CNN：任务误差更低，**但没有任何神经元对应关系**——这正是"连接组约束"的意义：用一点任务性能换完整的神经对应；
  - 合成实验：仅 10% 连接稀疏度时活动相关 0.85，80% 时反降到 0.38；加入强度估计后不论稀疏度都 >0.9 → **稀疏结构本身是信息载体**。
- 代码 + 预训练模型开源：github.com/TuragaLab/flyvis。

### 同范式的其他证据

- **train-your-fly**（eudald-seeslab）[实锤，README]：FlyWire 全脑连接组 + 解剖保真复眼模型，包成 PyTorch Geometric 模型做图像分类。"接线永不改变；学习的是每突触一个标量增益、（可选）每神经元一个阈值、蘑菇体 Kenyon 细胞上的线性读出"。配套论文 *Structure alone supports efficient visual computation in the Drosophila visual system*（Correig-Fraga, Guimerà, Sales-Pardo）——标题本身就是结论：**结构本身支撑高效视觉计算**。附带随机化连接组集成对照，数据存 Zenodo（10.5281/zenodo.21549559）。
- **fly_ocr / Fly Dino / FLYT3 等**：同一范式的玩具化版本（固定子回路 + 训练小读出层）。

## 2. 范式 B：储层计算（冻结动态，只训读出层）

**做法**：跑全图 LIF 仿真（连接与动力学全冻结），把瞬态活动当特征，只训练一个浅层读出（logistic / CEM / REINFORCE / PPO 训练下行神经元读出）。门槛最低——Shiu et al. 全脑模型代码拿来就能跑——但**优势尚未被证明**：

- FLYT3（井字棋 + 卫星火灾分类）自带对照：同一输入下池化像素 MLP 得 85.7%，果蝇读出层只有 60.8% [二手，awesome-fly 条目]；
- doomfly 明确报告"未学会存活"；FlyPong 的多巴胺可塑性实验为负结果；
- 社区把这类项目标为 "full retained graph; only readout is trained" 并要求公布负结果——这是对的：**储层范式的价值目前是"演示与科普"，不是"性能"**。真正的科学问题是"真接线的储层是否优于同统计量的随机储层"——这恰好需要范式 A 的洗牌对照来回答（见 §4）。

## 3. 范式 C：连接组当训练数据

不把连接组当网络结构，而是当**样本**：

- 图学习基准：MaleCNS（166,691 节点 / 千万级边）是带真实标注（细胞类型、脑区、神经递质预测）的稀疏有向图黄金数据集；
- 下游任务示例：Wired Different——从接线预测性别二态细胞类型，用度保持零图做验证 [二手，仓库自述]；
- 反方向（AI 造连接组）：3D 分割/突触检测模型本身以连接组为训练数据（docs/02 的 FFN、T-bar 检测器）——连接组既是产物也是燃料。

## 4. 训练设计的四条军规（由证据直接推出）

1. **冻结拓扑、只训低维参数**（增益/阈值/读出）是首选——flyvis 证明这条路科学上最干净：参数少（734 个）、结果可与生物学逐项对照。
2. **必须做度保持洗牌对照**（shuffle 连接但保度序列分布）：这是回答"接线本身是否携带计算"的唯一干净方法。现成参考：drosophila-brain-mlx 的 "Does the wiring matter?" 对照、train-your-fly 的随机化连接组集成 [实锤，仓库]。
3. **必须做普通网络 baseline**：任务性能上你大概率打不过 MLP/CNN（flyvis 也打不过）——你的卖点是对应关系、可解释性和参数效率，实验设计要围绕这些组织。
4. **注意稀疏性**：连接组约束的价值随稀疏度上升（0.85@10% vs 0.38@80%）——如果做图稀疏化/剪枝实验，这个现象是现成的研究切口。

## 5. 入手路线（按本机环境）

本机为 Apple Silicon（macOS ARM），恰好有人做过原生移植：

| 步骤 | 选择 | 说明 |
|------|------|------|
| 1. 数据 | MaleCNS v1.0（male-cns.janelia.org / neuPrint，**CC-BY 4.0**，署名即可自由使用）+ FlyWire v783（codex.flywire.ai） | 两性全 CNS 图谱均可下载 [实锤] |
| 2. 跑通全脑基座 | drosophila-brain-mlx（MLX/Metal 原生，含洗牌对照）或 mps-malecns-model（PyTorch MPS） | Apple Silicon 免 CUDA [二手，仓库自述] |
| 3. 上任务 | flyvis（PyTorch + 预训练模型，教程齐全）——CPU 也能跑视叶子图 | 最稳的科研入口 [实锤] |
| 4. 自定义训练 | train-your-fly（PyG，图像分类流水线）或 AxonWeave（NumPy/PyTorch/TF 可训稀疏基底） | "自带环境"模板 [二手] |
| 5. 加速 | FastFly（NVIDIA CUDA 实时全图，需 N 卡） | 浏览器 WASM 方案可做演示 |
