# 07 · 搭建指南：回家清单（Windows 真机）+ 完整协议

> 2026-09-23 盲写完成配套文档。目标机器：家里的 Windows 游戏机（Steam 版空洞骑士）。
> 本文档=「回家从零到陪玩开黑」的操作顺序 + 所有接口协议。Mac 上已自测的部分见文首。

## 0. 现状：哪些已验证，哪些要回家才知道

| 组件 | 状态 |
|------|------|
| hk-gateway 全链路（transport/事件/反射层/MCP/HTTP/网页） | ✅ Mac 上用 `--sim` 假 mod 完整自测通过 |
| CompanionMod（C#） | ⚠️ 盲写，未经编译——回家第一件事 |
| volc-asr 协议 | ✅ 从已验证的 volc-asr skill 移植（Mac 上凭证已确认存在） |
| hooks/MCP 在 ZCode 里实际生效 | ⚠️ 配置已写好，schema 与官方文档核对过，需真机确认 |
| TTS（edge-tts）/音频依赖 | ⚠️ 代码就绪，回家装依赖后验证 |

## 1. 前置准备（10 分钟）

1. **拷凭证**（从 Mac 到 Windows，两选一）：
   - `~/.volc_asr.json`（volc-asr 语音凭证，Mac 上确认存在）→ 拷到 Windows `C:\Users\<你>\.volc_asr.json`
   - 或设环境变量 `VOLC_ASR_APP_ID` / `VOLC_ASR_ACCESS_TOKEN`
2. **（可选，Tier-2 速答用）** `HK_LLM_API_KEY`：OpenAI 兼容 API key（GLM/DeepSeek 均可）。不配则语音输入只转文字显示，主对话不受影响。
3. **装 Python 3.11+**（勾 Add to PATH）、**.NET SDK 8+**。
4. **确认 Windows 版 ZCode 可用**（如果 Windows 上没有 ZCode 客户端：先用 `--sim` + 网页端跑陪玩骨架，ZCode 大脑放 Mac 通过局域网连 gateway——`config.json` 的 `http_host` 改 `0.0.0.0`，Mac 的 hooks 里写 Windows 的 IP）。

## 2. 游戏与 Modding 环境（对应 M0，30 分钟）

1. Steam 装空洞骑士（1.5.x），进一次游戏确认能跑。
2. 下载 [Lumafly](https://themulhima.github.io) → 安装 **Hollow Knight Modding API**（顺手装 DebugMod，随时开调试面板验证注入生态）。
3. 用 Lumafly 启动一次带 mod 的游戏，确认 Mods 目录生成：
   `C:\Users\<你>\AppData\LocalLow\Team Cherry\Hollow Knight\Mods`

## 3. 编译 CompanionMod（联调清单见 src/CompanionMod/README.md）

```powershell
cd src\CompanionMod
# 游戏不在默认路径就：dotnet build -c Release -p:HkManagedDir="D:\...\Managed"
dotnet build -c Release
copy bin\Release\net472\CompanionMod.dll "$env:USERPROFILE\AppData\LocalLow\Team Cherry\Hollow Knight\Mods\"
```

启动游戏，另开一个终端：

```powershell
cd src\hk-gateway
python -m hk_gateway dump-mod
```

**应该立刻看到 hello + 每 0.5s 一条 state JSON**。这就是 M0/M1 的核心验收。报错对照
mod README 的「联调清单」表（7 个预判风险点）。

## 4. 启动 gateway（先假后真）

```powershell
cd src\hk-gateway
python -m pip install -r requirements.txt
copy config.example.json config.json

python -m hk_gateway --sim      # 先无游戏自测：浏览器开 http://127.0.0.1:8088/ 看假剧本
python -m hk_gateway            # 真游戏模式（游戏开着、mod 加载着）
```

## 5. 接上 ZCode 大脑

1. Windows 上 clone/copy 本仓库，ZCode 打开该目录。
2. 编辑 `.zcode/config.json`：把 `mcp.servers.hk.cwd` 的 `C:/CHANGE_ME/...` 改成实际路径（正斜杠即可）。
3. 确认 `python` 命令可用（hooks 也靠它）。
4. 重启会话 → Settings → MCP 应看到 `hk` 已连接，出现 `mcp__hk__*` 工具。
5. 验证注入：随口问一句「我现在血多少」——回答前上下文里应出现【游戏实时状态】。

## 6. 语音（最后开）

```powershell
# 单测 ASR：按住 F9 说句话
python -m hk_gateway.voice_asr
```

- **TTS**：默认 edge-tts 出声；若自动降级（依赖缺失），网页端点「取消静音」由浏览器朗读。
- **PTT**：按住 F9 说话（key 可在 config.json 改）。识别文本进聊天记录；
  配了 `HK_LLM_API_KEY` 且 `inline_brain.enabled=true` 则 2–5 秒内语音回答（Tier-2 速答，
  与 ZCode 大脑共享 brain/ 人设记忆）。

## 7. 整局验收（对应 05 路线图 M1/M2）

- [ ] dump-mod 连续输出，进游戏转场有 `scene` 事件
- [ ] 故意死一次：网页事件流秒出 ☠、反射层 1 秒内开口安慰
- [ ] ZCode 里问「我在哪」→ 正确回答场景/血量
- [ ] 让陪玩主动说话（「鼓励我一下」）→ `hk_speak` 朗读
- [ ] `hk_do_action heal` 先征得同意 → 游戏内血量回满
- [ ] PTT 说「往哪走」→ 转写正确；Tier-2 开启时得到语音回答
- [ ] 打完一场 boss：战报 + 死亡统计在 /api/history 正确

## 8. 故障排查

| 现象 | 原因 | 修法 |
|------|------|------|
| dump-mod 连不上 | mod 没编译/没拷进 Mods/API 没装 | 回第 2/3 步 |
| 连上但没有 state | `PlayerData.instance` 取值异常 | 看游戏日志（Player.log）里 [CompanionMod] 输出 |
| MCP 工具没出现 | cwd 路径错 / python 不在 PATH / SDK 版本 | 逐项查；手动 `python -m hk_gateway mcp` 看报错 |
| hook 不注入 | 配置文件 hooks 未生效或 python 报错 | 手动 `python hooks/inject_state.py`（gateway 开着时应打印 JSON） |
| 35516 端口占用 | 旧进程没退 | `netstat -ano \| findstr 35516` 杀掉 |
| TTS 无声 | 音频依赖没装成 | 网页端朗读兜底；或重装 sounddevice/miniaudio |
| ASR 报凭证错 | ~/.volc_asr.json 没拷 | 回第 1 步 |

## 附录 A · Mod ↔ Gateway 协议（TCP，NDJSON，127.0.0.1:35516）

**上行（mod→gateway，UTF-8 JSON 每行一条）**

```jsonc
{"type":"hello","mod":"CompanionMod","version":"0.1.0","game":"hollow-knight","ts":0}
{"type":"state","data":{"scene":"Crossroads_05","x":1.0,"y":2.0,"hp":5,"max_hp":5,
 "geo":120,"soul":33,"in_boss":false,"paused":false,"boss_name":"?","boss_hp":0,"boss_max_hp":0},"ts":0}
{"type":"event","event":{"kind":"death","scene":"...","hp_before":5},"ts":0}
{"type":"cmd_result","id":"abc123","ok":true,"error":null}
```

事件 kind：`scene{name,from}` `damage{amount,hp,scene}` `death{scene,hp_before}` `heal{hp,scene}`
`boss_start{name,hp,max_hp}` `boss_end{name}`

**下行（gateway→mod，管道格式，避免 mod 侧 JSON 解析）**

```
cmd|<id>|heal|
cmd|<id>|set_hp|hp=3
cmd|<id>|give_geo|amount=500
cmd|<id>|teleport|scene=Crossroads_47
cmd|<id>|nop|
```
