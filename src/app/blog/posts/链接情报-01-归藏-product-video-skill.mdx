# 归藏 product video skill：复用真实产品组件和设计语言，用代码制作软件更新宣传片

## 一句话

把代码仓库交给 AI 编程工具（Claude Code / Codex），说明这次更新了什么，它负责整理卖点 → 写文案 → 接入你项目里的真实组件和设计语言 → 代码驱动动画 → 配乐用代码合成（原创）+ 11 个内置音效（关键音效出现时音乐自动让位 ducking）→ FFmpeg 导出 MP4 + 可继续修改的视频工程。

## 安装

```bash
npx skills add https://github.com/op7418/guizang-product-video-skill --skill guizang-product-video-skill
```

或手动 clone 到 `~/.claude/skills/`（Claude Code）或 `~/.agents/skills/`（Codex）。

## 依赖

Node.js ≥ 22、Python ≥ 3.9、FFmpeg/ffprobe、Playwright Chromium（WebGL 走 SwiftShader）、React+GSAP+Three.js（装在视频工程内）。

## 三种风格

- `repo`（推荐）：沿用产品已有设计，一眼像自己的软件
- `default`：CodePilot 暖白/炭黑/卡片层次默认样式
- `hybrid`：保留真实界面，外层文案与节奏更适合传播

默认起点：45–60 秒、横版、中文。英文标题与中文说明分字体指定，可全中或全英。

## 7 步工作流

1. **定范围**：产品、更新范围、受众、平台、画幅、语言、风格、参考视频
2. **找真实内容**：查版本与代码，核对功能状态，挂载真实组件并放大上镜
3. **定方向**：拆解参考、提出三个差异明显的方向，视觉手法要能归因到产品特质；字号、界面倍数、镜头表写成具体数字
4. **逐镜头搭建**：GSAP 主时间轴编排，Three.js/canvas 做背景层，真实组件由真实点击与输入驱动，每镜头出静帧对照
5. **配声音**：按分镜编曲、选音色，音效先找素材（记录来源与许可），实测落点后对齐动作，混音并处理音乐让位
6. **审片导出**：看联系表、每个转场、信息密集全尺寸帧
7. **可选封面**：3:4、4:3、16:9 三比例，仅用片中真实渲染画面

## 配乐与音效

- **音乐优先级**：用户给的曲子 → 本机可运行的音乐生成模型 → 代码原创合成
- 代码合成保留编曲源码，按镜头边界排段落、按产品气质选音色；仓库含两种气质示例（轻快键盘、电影感电子）
- **音效**：先搜可用素材库并记录来源与许可，缺的类别用随包 11 个代码合成 WAV 或调参数
- 点击、弹出、切换、完成提醒等有独立音效事件；关键反馈时音乐短暂降低（ducking）

## 案例手法（同一流程，三支片子完全不同）

- CodePilot：暗色舞台、粒子汇成标志、120 BPM 电子
- Zed：浅色一镜到底、代码注释标题、128 BPM 马林巴
- T3 Code：3×3 控制台面板、每章换主题色、96 BPM lo-fi 电钢琴

同一工作区会自动避开上一支片子的手法。

## 目录结构

```
SKILL.md                 工作流、硬约束和工具入口
references/              影片方向/视觉手法/组件接入/分镜文案/音频/审片/封面/依赖/验收
scripts/                 初始化、环境检查、音效落点测量、合成、混音、交付检查
assets/starter/          可运行起步工程（无风格底座）
assets/fx-lab/           可改写视觉手法样例（流线场、粒子汇聚、字符场等）
assets/fallback/         CodePilot 默认样式与展示组件（BSL 1.1！）
assets/audio/            配乐合成示例、11 个内置音效
tests/                   脚本回归测试与组件接入测试
```

## 许可证注意

- 主体 AGPL-3.0：工作流、文档、脚本、起步工程、原创音频
- `assets/fallback/` 中改编自 CodePilot 的组件与样式继续适用 **BSL 1.1**，不因主许可证改为 AGPL；混合工程不能宣称仅受 AGPL 约束
- 生成的视频不自动变为 AGPL 作品；闭源集成/白标需单独商业授权（COMMERCIAL_LICENSING.md）
