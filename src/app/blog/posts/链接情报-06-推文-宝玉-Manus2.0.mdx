# Manus 2.0（宝玉报道要点）

## 发布背景

Manus 是通用 AI Agent（2025-03 走红，中国团队 Butterfly Effect 蝴蝶效应/肖弘出品）。Meta 20 亿美元收购被中国监管安全审查叫停 → 拆分 → 2026-09 初创始团队重新独立运营。**2.0 = 独立后第一次大更新**（09-28 发布）。

## 五大更新

### 1. Cascade agent harness 换代

- 底层智能体框架完全换代，自研 Cascade
- 核心思路：项目保持轻量，**按需加载专业能力**（简报/页面/视频/自动化留在同一关联项目），不背全套工具跑
- 官方自测数据（同一配置对比旧系统）：**token -23.2% / 完成时间 -28.2% / 运行成本 -32%**
- 注意：官方自测口径，第三方深度实测当时还少

### 2. Cloud Computer 云电脑

- 付费常驻云端专属环境（以前沙箱随任务结束销毁）
- 场景：多人游戏服务器（笔记本合上仍在线）、24h 自动化驻留
- 硬件规格与价格公告未披露

### 3. Automations 事件触发自动化

- 旧版只能定时启动；新版事件触发：新邮件、广告数据变化、日历事件、Slack 消息、Notion 更新
- 一句话 prompt 建工作流，Manus 自己搭建并运行
- ——在跟 n8n 类自动化平台抢地盘

### 4. Manus Studio（桌面端专业创作环境）

- **视频编辑器**：AI 出初剪后给时间线，片段/图片/文字/动效/音频都是独立素材可手改，改完可导出也可**交回给 Manus 基于修改继续迭代**；Alchemy 模式 = AI 当创意总监（视频+代码混合生成）
- **游戏开发环境**：视频+图像+代码模型齐调（Max Ultra 最佳），可玩模板起步；Edit 面板边玩边改（例：只把村民头发改成银色其余不动）；一键发布网页；点选 Cloud Computer 几步配多人联机
- **Remote Control**：手机语音远程操控自己电脑，实时看桌面操作

### 5. Cue 个人 agent App

- **每个 agent 一套完整独立身份**：自己的邮箱、电话号码、钱包、电脑（云端机器）
- 能在预算内替你付款、替你接电话留摘要、发消息
- **组队**：多个 agent 进群聊共享目标互相交接（A 调研场地 → B 出短名单 → C 起草文稿），你只拍板
- 场景：餐厅扫二维码 agent 代点单/排队
- Early access 邀请制免费，首发码 **MEETCUE**（限量）；网页/桌面已上线，iOS 待 App Store 审核

## 其他

- 国内：正组队开发面向国内市场的产品 + 国产模型（IT之家）
- Manus 按积分计费，成本降 32% 理论上 = 同样积分跑更多任务
- 与唯一身份认证研究直接相关：**agent 有了独立邮箱/手机号/钱包，"证明操作背后是人还是 agent"成为新认证难题**
- Cascade"按需加载省 32% 成本"对 omniscient-agent 路由蓝图（按任务时长选模/按需加载工具）是现成论据
