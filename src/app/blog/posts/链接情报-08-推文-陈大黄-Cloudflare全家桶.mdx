# 陈大黄：Cloudflare 全家桶零成本部署（推文全文）

> 现在做个个人小工具或者出海小产品，不建议买云服务器、配环境、折腾 Nginx，纯属自己给自己找罪受。
>
> 静态前端直接扔给 Cloudflare Pages，连着 GitHub 推送就能自动构建，全球 CDN 一分钱不收。
>
> 后端接口全丢给 Cloudflare Workers，毫秒级冷启动，每天几十万次请求的免费额度。
>
> 数据库用 D1，边缘 SQLite，不用管连接池、不用防端口扫描。
>
> 文件存储用 R2，S3 兼容，出网流量不要钱（云存储大头就是出网）。
>
> 邮件用 Resend，每月 3000 封免费。
>
> （汇总：这样每月零账单运行，还免掉半夜查日志、担心磁盘占满等运维烦恼。）

## 数据（采集时点）

7.9 万浏览、1860+ 收藏。

## 组合清单

| 组件 | 干什么 | 免费点 |
|---|---|---|
| Cloudflare Pages | 静态前端+自动构建 | 全球 CDN 白嫖 |
| Workers | 后端 API | 毫秒冷启动，几十万请求/天 |
| D1 | 边缘 SQLite | 免连接池管理 |
| R2 | S3 兼容对象存储 | 出网流量免费 |
| Resend | 邮件 | 3000 封/月 |

## 与我方的关系

- 直接对标 toolsfox 服务器（n8n 三容器、docker 要 sudo、执行历史 72h、cron 连环失败的"伺候机器"痛点）——个人量级新项目走 CF 全家桶 = 服务器/备案/证书/备份运维链消失
- **边界**：n8n 这类需常驻进程的工作流引擎不适用（serverless 模型不匹配）；有状态大数据库不适用；CF 国内访问速度一般，国内正式业务需备案+自建
