# Manus 2.0 官方公告要点（官方口径整理）

## Cascade（新 agent harness）

- 基于一个根本问题重构："下一代 Manus 应该是什么样"
- 设计理念：项目从一开始保持轻量，**只在工作需要时引入专用能力**；brief、页面、视频、自动化保持为"一个互联项目"的组成部分
- 官方测试数据（同一配置对比旧系统）：**Token -23.2% / 任务完成时间 -28.2% / 运行成本 -32%**
- 机制推断：避免"把每种能力都带进每个任务"（公告在 Studio 部分明说这会让工作"更慢更贵"），上下文更聚焦
- 公告未披露旧 harness 名称和内部细节

## Cloud Computer（云电脑）

- 专用持久运行环境，适用"项目超越单机"场景：笔记本合上仍在线的游戏服务器、需 24h 运行的自动化
- Game Dev 集成路径：Configure → Multiplayer → 选择 Cloud Computer → 购买，几步点击；托管/网络/维护 Manus 全包
- **未披露任何硬件规格与价格**（公告指向 /pricing 页）

## Automations（事件触发自动化）

- 触发源：新邮件、广告数据变化、日历事件、Slack 消息、Notion 更新
- 一句话 prompt 告诉 Manus 监控什么、做什么，它自己搭建并运行工作流

## Manus Studio（桌面 App）

理念：人机共享工作区；按项目需求加载能力。覆盖文档、表格、PDF、幻灯片、网站、代码、游戏和视频。

- **Video Editor**：初剪后给时间线；片段、图片、文字、动效、音频都是独立元素，可换歌/换素材/调动效；可导出也可把时间线交回 Manus 基于修改再迭代。目标场景：30-60 秒产品广告、AI UGC、数据动效、教程、Vlog
- **Alchemy 模式**：从一个想法出发，Manus 担任"创意总监"，视频与代码生成结合；公告称创意更佳、视觉细节把控更严、动作更流畅、剪辑节奏更好
- **Game Dev**：同时调用视频、图像和代码模型（Max Ultra 模式最佳）；可玩模板起步、第一个会话内可玩；Edit 面板观察游戏运行/管理素材/编辑代码，例：只把某村民头发从棕色改银色其余不变；发布为网站链接；多人游戏几步点击配置（选 Cloud Computer 购买）
- **Remote Control 与 Computer Use**：语音指令远程操控你的电脑，手机实时观看桌面操作；在已连接授权会话中于你电脑上自己的可见工作区内工作

## Cue（独立 App）

基于与 Manus 相同基础设施的个人智能体应用（手机+桌面）：

- **独立身份**：每个 agent 有自己的邮箱、电话号码、钱包和电脑；可发消息、在预算内付款、在自己机器上完成任务、接你的来电并在 Cue 中留摘要
- **组建团队**：多个 agent 进群聊、共享目标、互相交接（调研场地→短名单→起草演示文稿）；你定方向并做最终决定
- **对接日常服务**：餐厅扫二维码 agent 代点单或排队
- 可用性：网页/桌面已上线；iOS 待 App Store 审核；early access 凭邀请码免费，**首发码 MEETCUE**（限量先到先得），获邀者可获额外分享码
