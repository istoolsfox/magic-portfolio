# 文章总结：我不得不把才华埋葬在昨天

> 来源：微信公众号「intlsy 的狗窝」｜ 发布：2026-09-14
> 原文：https://mp.weixin.qq.com/s?__biz=MzcwMjI0Mjc0OQ==&mid=2247483692&idx=1&sn=534e145b7b97f9094a721cbf41dde346
> 整理日期：2026-09-21

## 一句话

DeepSeek 前端算子工程师亲历"AI 一年内从助手变成能独立优化算子的大师"，写下自己对被取代的判断：**不会失业，但必须转业——从亲手写算子的人，转去做 Agent 的"机甲驾驶员"**。

## 作者背景

- intlsy，DeepSeek 员工，**DeepSeek v4.1 的主 Attention 算子（head dim=512 的 MQA attention）的编写者**（文末注释[1]澄清：不含 top-k indexer 部分，那部分是其他同事及其 AI Agent 写的）。
- 文中自述从事算子设计/编写/优化，将其比作"打游戏速通"般的热爱。

## 核心内容

### 1. AI 越来越会写算子（直接观察）

- 短短一年，AI 从"查文档、读代码、找 bug 的小助手"蜕变为"能独立阅读 CUDA、PTX 与 SASS 编码、用专业工具分析每条指令停顿时间、进而独立优化算子的算子大师"。
- 作者预判：**再过半年到一年，AI 写的算子大概率与人类写得同样优秀甚至超越**。
- 大背景：ChatGPT 初版（几千 token 上下文）→ o1/R1/K1.5 推理模型只用两年；推理模型→能干活的 Agent 只用一年半。（注：文中提到"DeepSeek v4.1 发布，小模型能力又上一个档次"）

### 2. 为什么明知被取代还继续优化算子（军备竞赛逻辑）

两个原因：
- **热爱**：写算子像打游戏，发明新技术、性能超过厂商官方算子时的激动不亚于速通玩家破纪录。
- **理性的无奈**：自己摆烂甚至下绊子，别家模型也会照常发展、照杀不误。金句："**我当然希望自己不要被革命，但如果非被革命不可的话，我希望革我自己命的人是我自己**。"

### 3. 那我呢：不失业，但必须转业

- 判断依据：凭眼界、判断力、主观能动性与智力**留在时代的牌桌上**——但这只能保证不失业，且实际上鼓励"通过转业来避免失业"。
- 转业含义：放弃深耕且热爱的算子领域，转向做 Agent 的"**机甲驾驶员**"。工业界需求已从"会写高性能算子的人"漂移为"**能用 AI 更快地产出高性能算子的人**"。
- 织毛衣比喻（全文最动人的部分）：手艺人织毛衣又快又美、十里八乡富人排队求购、享受临窗织一下午的意趣 → 机器出现，质量不输速度远超 → 你知道同行用机器就能达到你的水平，所以你不得不用机器 → 凭二十年功力你仍能胜过同行，但**"那份临窗听雨、引针穿线、慢度光阴的意趣，终究还是被机器的轰鸣碾碎了"**。
- 文题来源："**我的手中多了些齿轮，但心中少了些节拍。**"

### 4. 那人们呢（三个社会性担忧）

1. 学生会倾向用 AI 几分钟几毛钱出满分 Lab，而不是苦干八小时 → **工程能力严重不足**（组织代码、构建系统、预设计、抽象能力）。
2. 这些工程能力未来是否还有价值？如果是"理解整套计算机系统"那种永远有价值的，那就危险了——**工程能力差的人配上 AI，产屎山效率是先前的数倍**，给系统埋祸患，"让这个世界变得更加草台"。
3. 未来社会**权力是否会比技术或智商更重要**？

### 5. 结语：共产主义 vs 赛博朋克 2077

- 未来社会趋向两个极端：生产力解放的共产主义，或少数科技公司控制大部分资源、极少数人"机械飞升"、大部分人只有孱弱 AI 的赛博朋克 2077。阶层跨越形成死循环："你得先有最强的 AI，才能跨越阶层"。
- 立场鲜明：**不信任 Anthropic/OpenAI 能普惠最前沿智能**，"不希望 Anthropic 掌握最先进的人工智能或 AGI，夸张点说其严重性不亚于让希特勒先于盟军掌握原子弹技术"。
- 选择留在 DeepSeek 的理由："我们研究强大、快速、普惠的人工智能并将其开源，或许能把世界从 2077 那端拉回来一些。"
- 结尾："愿未来的世界一切安好。May all the beauty be blessed."
