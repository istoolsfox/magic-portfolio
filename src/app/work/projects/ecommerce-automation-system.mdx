## 业务背景

一家走高端路线的跨境服饰电商：订单在 Shopify 产生、在聚水潭 ERP 流转，物流走 4PX，
广告投 Meta，财务在金蝶。系统多、数据散、大量流程靠人肉搬运——这就是我接手时的状态。

我的目标：**让数据自己流动，人只做决策。**

## 自动化版图

```text
Shopify（订单 / 商品 / 客户）
   ↕
n8n 自动化中枢
   ↕
聚水潭 ERP（订单 / 进销存 / 采购 / 商品）
   ↕
4PX 物流 · Meta 广告 · 金蝶财务
```

### ERP 自动化（聚水潭）

- 订单清洗与追踪：自动规整异常订单数据，全程状态跟踪
- 进销存管理：库存流水自动同步，账实一致
- 采购单管理与追踪：按需求与销量驱动原料采购与消耗，减少原料堆积、进一步压缩成本
- 商品管理：商品资料的统一维护与流转

### Shopify 运营链路

- 商品一键上架与商品管理，上新效率大幅提升
- 客户信息管理、客户旅程追踪
- 客户画像分析与归因分析，让运营知道"客户从哪来、为什么买"

### 物流与运费（4PX）

- 物流轨迹自动追踪，问题物流实时预警、及时跟进
- 运费管理与追踪，成本透明可控

### 广告与转化分析（Meta）

- Meta 广告数据自动拉取与分析
- 整合加购、销量、广告等多维数据做统计，输出转化率分析，支撑投放与运营决策

### PR 自动化

- 自动搜寻并追踪合适的博主，持续跟进博主状态与发帖动态
- 实现友好互动，把 PR 从"人肉盯"变成"系统养"

### 财务自动化（金蝶）

- 金蝶财务数据分析与自动化
- 一键报销、财务金额管理与支配

## 效果

- 订单、库存、退货等核心数据自动同步与统一管理，人工处理成本大幅下降
- 延迟发货、物流退回、履约失败等异常场景实现实时监控与通知
- 原料按需采购与消耗，库存堆积显著减少，直接降低成本
- 运营决策从"凭感觉"变为"看数据"：画像、归因、转化率一屏可见
