## 项目定位

工作流自动化解决的是"确定性流程"，但业务里还有大量需要判断、创意和知识的场景。
这个项目用 OpenClaw 构建企业 AI Agent，把这部分"非确定性工作"也交给 AI 协作完成。

## 核心能力

### 自动找博主

- Agent 按品牌调性自动搜寻匹配的博主，评估内容风格与受众
- 持续追踪博主状态与发帖动态，为 PR 合作提供决策依据

### 广告设计

- 结合产品与投放目标，Agent 辅助产出广告创意与设计方向
- 与 Meta 广告数据分析联动，创意迭代有数据反馈

### 开款头脑风暴

- 新款开发前，Agent 结合销量数据、流行趋势做头脑风暴
- 把"拍脑袋"变成"AI 提案 + 人做决策"

### 企业知识库沉淀

- 搭建多个企业知识库，把散落在聊天记录、文档、经验里的知识结构化
- 团队提问即得答案，新人上手成本显著降低

## 技术要点

- **OpenClaw** —— Agent 运行时与编排框架
- **Prompt Engineering** —— 角色设定、任务拆解、输出约束的体系化设计与迭代
- **Tool Calling / MCP** —— 让 Agent 接入业务系统与外部数据
- **多轮对话与上下文管理** —— 保证长任务中的稳定表现

## 效果

- 找博主从人工翻页筛选变为 Agent 持续供给候选名单
- Prompt 体系经过多轮迭代，任务理解准确率与输出质量持续提升
- 知识库成为团队日常工具，重复性咨询大幅减少
